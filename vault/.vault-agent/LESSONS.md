# Lessons

Raw calibration buffer. Read by `update-rules`; `save-lesson` may read only the entry template and pending-entry count.

## Rules

- Capture only reusable signal.
- Skip typos and one-off wording polish.
- Keep each entry compact.
- Do not treat pending entries as rules.
- Promote only after owner approval.

## Entry Template

```markdown
## YYYY-MM-DD — short lesson title
path: note or area that triggered the lesson
agent did: what happened
owner fixed: what the owner corrected or rejected
lesson candidate: reusable lesson in one sentence
domain: rules | style | structure | links | retrieval | patterns
status: pending
```
