# Examples

`obsidian-agent` does not ship personal good/bad note examples.

During onboarding and later calibration, the owner can add examples here:

- `good/` — note shapes worth copying;
- `bad/` — patterns to avoid;
- `mixed/` — useful notes with one known failure mode.

Do not treat this directory as active guidance until the owner has approved examples.
