# Profile

## Владелец

- name: —

## Зачем нужен vault

- цель vault: рабочая база для подготовки видео по теме IT-карьеры
- one-month goal: удобно собирать контент и инфу для видео
- six-month goal: связная база, из которой быстро собирается сценарий любого видео по теме
- текущая боль: 106 готовых заметок без связей и навигации, нужно найти "все мысли про X" быстро
- критерий успеха: запрос "найди все мысли про X" возвращает релевантные заметки и связанные сюжеты

## Главные сценарии

- "найди все мысли про X" → semantic поиск через QMD по `concept`-заметкам
- собрать пакет (история + концепт + цифры) под конкретное видео
- найти дубликат темы перед написанием новой заметки
- найти связи между явлением, типом человека и историей

## Backup и versioning

- Git/GitHub: да, нужен
- сохранять изменения: после крупных правок и перед публикацией нового видео
- что нельзя отправлять в remote: личные заметки про конкретных людей, незапубликованные сценарии (TBD)
- настройка: отложена — запускается через `setup-git` отдельным шагом

## Типы материалов

- `concept` — мысли, принципы, модели (большая часть `10_Философия/Концепции`, отдельные роадмапы как concept-set)
- `source` — transcripts видео и материалов (пока их в vault мало; место под них зарезервировано)
- `reference` — типы людей, типы компаний, явления рынка, платформы, площадки, каналы (`90_References`, плюс существующие подпапки в `10_Философия`)
- `map` — MOC-страницы (`00_Maps`)
- `story` — нарративы и истории к возражениям (`60_Возражения_и_истории`) — расширение базового набора, специфичное для контент-канала

## Как владелец ищет

- recall pivot: название
- typical query: "найди все мысли про X"
- entry point: агностично — папка/MOC/поиск/backlinks по контексту
- `description` пишет агент, владелец одобряет
