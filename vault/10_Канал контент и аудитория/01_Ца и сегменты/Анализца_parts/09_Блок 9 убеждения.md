## БЛОК 9: УБЕЖДЕНИЯ

### Позитивные (усиливать)
- "60–80 часов сфокусированной работы реально" 
- "Диплом НЕ НУЖЕН"
- "Собес = навык" (после 5-10 → автопилот)
- "Система взламываема"
- "Backend выгоднее" (Go +30-40%)
- "Junior = Middle по задачам"
- "Внутри не вырасти" (Сбербанк max +30%/год)
- "Накрутка работает" (73% целей, 95%+ ИС)
- "Каждый месяц junior = потеря 150к"
- "AI — инструмент, не замена" (+40%)

### Негативные (разрушать)
- "Ещё не готов" → чек-лист готовности, мок-собес
- "Накрутка = обман" → аутсорсы крутят СИСТЕМНО
- "Рынок умер" → Go = дефицит
- "Слишком старый/молодой" → кейсы 18-30+
- "Без опыта никуда" → накрутка + легенда
- "Менторство = курсы" → не курс, а подготовка к собесам
- "Не справлюсь" → 95%+ прошли ИС, задачи = CRUD
- "AI заменит" → AI = подрядчик
