### 🖥 Frontend-разработчик
**Что делает:** Создаёт визуальную часть сайтов и приложений — всё, что видит пользователь
**Зарплаты (Москва, 2026):** Стажёр 0–50К (часто символическая), Junior 50–150К (вакансий мало, конкуренция запредельная), Middle 150–300К, Senior 300–500К. Цель входа — middle-оффер, не стажёрская ставка.
**Порог входа:** Средний (ниже, чем у backend)
**Конкуренция:** Очень высокая

**Стек:** HTML, CSS, JavaScript → React (доминирует в РФ) или Vue → TypeScript → Next.js / Nuxt

**Roadmap:**
1. HTML + CSS (10–20 часов сфокусированной работы)
2. JavaScript (40–60 часов) — самая важная фаза
3. React или Vue 
4. TypeScript 
5. Git, Vite/Webpack, REST API, GraphQL (параллельно)
6. Next.js или похожий мета-фреймворк (20–40 часов)

**Ресурсы:**
- The Odin Project (foundations + JavaScript track)
- freeCodeCamp (Responsive Web Design + JavaScript Algorithms)
- YouTube: Traversy Media, Net Ninja, Kevin Powell (CSS), Theo, Jack Herrington
- RU: Покатилов, Владилен Минин, Ulbi TV

**Плюсы:**
- Быстрая визуальная обратная связь — ты видишь результат сразу
- Огромное количество вакансий
- Универсальность (React Native для мобилки, Electron для десктопа)
- Самое большое сообщество

**Минусы:**
- Высокая конкуренция 
- «Фреймворк-усталость» — экосистема меняется каждые 2 года
- Зарплата ниже, чем в Go-бэке

**Аналогия:** Frontend — как ремонт квартиры. Все видят результат сразу. Бэкенд — как прокладывать трубы: никто не видит, но если протечёт — все в курсе.
