### ⚙️ Backend-разработчик
**Что делает:** Серверная логика, базы данных, API, интеграции
**Зарплаты:** Стажёр 0–50К (часто символическая), Junior 90–160К (вакансий мало), Middle 200–350К, Senior 350–600К. Цель входа — middle-оффер, не стажёрская ставка.
**Порог входа:** Средне-высокий
**Конкуренция:** Средняя (зависит от языка)

**Стеки:**

| Стек | Когда выбирать |
|---|---|
| **Go** (Gin/Echo, gRPC) | Высоконагруженные системы, микросервисы. Зарплаты выше среднего, конкуренция среди джунов ниже. На валютных удалёнках $6–15K |
| **Python** (FastAPI / Django) | Универсальность, ML-смежные продукты. Огромная конкуренция среди джунов |
| **Node.js** (Express/Fastify/NestJS) | Когда уже знаешь JS из фронта — естественный переход в fullstack |
| **Java** (Spring Boot) | Корпоративный сегмент, банки, энтерпрайз. Высокий порог, выше зарплаты |
| **C#/.NET** | Корпоратив, gamedev (Unity). Меньше вакансий в РФ, чем у Java |
| **PHP** (Laravel/Symfony) | Старые проекты, агентства. На уход рынка |
| **Ruby on Rails** | Стартапы (особенно международные). На уход в РФ |
| **Rust** | Системное, инфраструктура. Очень мало позиций |

**Roadmap (универсальный):**
1. Язык (Python / JS / Go / Java) — 2–3 мес
2. Базы данных (SQL, основы PostgreSQL) — 1 мес
3. Фреймворк — 2 мес
4. REST API, JSON, HTTP — 1 мес
5. Docker, Git — 1 мес
6. Тестирование (unit, интеграционные) — параллельно
7. Очереди (Kafka/RabbitMQ), кэш (Redis) — 1 мес
8. Основы Linux, CLI — параллельно
9. Архитектура (микросервисы, паттерны) — middle уровень

**Плюсы:**
- Высокие зарплаты
- Глубокие интересные задачи
- Возможность роста до архитектора
- Меньше «фреймворк-усталости»

**Минусы:**
- Выше порог входа
- Сложнее увидеть результат сразу
- Дежурства, on-call для production-сервисов

**Какой стек выбрать в 2026** (если ты совсем новичок):
- Хочешь быстрее войти и есть JS-опыт → **Node.js**
- Хочешь высокие зарплаты, готов учить непростой язык → **Go**
- Хочешь универсальность для ML → **Python**
- Хочешь стабильный энтерпрайз → **Java**
