### Лайфхак: попробуй перед выбором

Потрать 1–2 недели на каждое подходящее направление:
- **Frontend:** свёрстать страницу на HTML/CSS, добавить интерактив на JS
- **Backend:** написать простое API на Python (FastAPI) или Go
- **QA:** протестировать любой сайт вручную, записать баги; написать первый тест в Postman
- **DevOps:** поднять Docker-контейнер с Postgres + Node-приложением
- **Data Science:** разобрать датасет в Jupyter Notebook, сделать визуализации в pandas/matplotlib
- **Кибербез:** пройти 2–3 простые лабы на TryHackMe

После этого выбор будет очевиден. Не выбирай по «престижности» — то, что не нравится, не вытерпишь годами.

## Что общего у всех направлений в 2026

1. **Английский B1+** — без него отрезано 80% контента и валютных вакансий
2. **Git** — must для любого направления (GitHub-профиль как карьерная витрина переоценён, рекрутёры туда почти не заходят — это миф; вкладывайся в Git как инструмент, а не в «прокачку профиля»)
3. **Linux CLI основы** — даже QA и frontend сейчас работают в терминале
4. **Понимание HTTP/REST** — все интегрируются с API
5. **AI как инструмент** — Copilot/Claude/Cursor стали частью workflow. Уметь использовать — преимущество. Уметь объяснить и проверить выход AI — критично
6. **Готовность к собесам — отдельный навык** — на каждом из направлений есть свой пул типовых вопросов и live coding-задач. Учиться надо **под этот пул**, а не «по программе курса»

## Зарплаты — что реально в 2026

Цифры выше — **медианы Москвы**. Реальные офферы зависят от:

- **Города:** Москва > Питер > регионы (-20–30%) > валютные удалёнки (+100–300% в долларах)
- **Сегмента:** бигтех (Yandex, VK, Сбер, T-Bank) > продукт > аутсорс
- **Стек:** Go/Java/ML > Python > JS > QA manual
- **Грейда:** Senior > Middle > Junior с разрывом 1.5–2x на каждом шаге
- **Способа найма:** прямые офферы > через рекрутёра > через джоб-борды
