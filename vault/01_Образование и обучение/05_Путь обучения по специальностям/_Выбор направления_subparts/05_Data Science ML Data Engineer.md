### 📊 Data Science / ML / Data Engineer

**Data Scientist**
- **Что делает:** Анализ данных, статистика, A/B тесты, ML-модели
- **Зарплаты:** Стажёр 0–50К (часто символическая), Junior 100–180К (вакансий мало), Middle 250–400К, Senior 400–700К. Цель входа — middle-оффер.

**ML Engineer**
- **Что делает:** Внедрение ML-моделей в продакшн, MLOps
- **Зарплаты:** Middle 300–500К, Senior 500–900К
- **Порог:** Высокий — DS + Backend + DevOps на стыке

**Data Engineer**
- **Что делает:** Пайплайны данных, ETL, хранилища (DWH), Spark, Airflow
- **Зарплаты:** Middle 300–500К, Senior 500–800К
- **Порог:** Средне-высокий — SQL очень глубоко, Python, распределённые системы

**Roadmap (для DS):**
1. Python (numpy, pandas) — 40 часов сфокусированной работы
2. Математика (линейная алгебра, статистика) — 40–60 часов
3. SQL — 20 часов
4. Классический ML (sklearn, sklearn-методы) — 40 часов
5. Deep Learning (PyTorch / TensorFlow) — 60+ часов
6. Один проект на Kaggle / на хорошем датасете — параллельно
7. **С 2024 — отдельная ниша LLM-инженеров**: prompt engineering, RAG, fine-tuning

**Ресурсы:**
- Kaggle Learn — короткие практические треки
- «Hands-On Machine Learning» Géron — настольная книга
