## СЦЕНАРИЙ Б: С НУЛЯ В ПРОГРАММИРОВАНИЕ (6–9 МЕСЯЦЕВ)

### Месяц 1: База программирования

Не Go. Сначала база. Иначе синтаксис Go проглотишь, но не поймёшь, что вообще такое функция, переменная, цикл.

- **Курс:** Tour of Go (для синтаксиса) + любой интерактивный туториал по Python/JS если синтаксис Go вообще не заходит
- **Практика:** 30–50 простых задач на Stepik / Exercism — без алгоритмических зачётов, цель — наработать руку на циклах, функциях, структурах данных
- К концу месяца: пишешь FizzBuzz, реверс строки, поиск дубликатов в массиве не задумываясь

> Алгоритмические задачники (LeetCode, Codewars hard) на этом этапе не нужны — это переоценённая часть подготовки. На реальной работе ты используешь готовые структуры из стандартной библиотеки, а на собесах в продуктовых компаниях алгоритмов либо нет, либо они формальные. Время лучше потратить на синтаксис и первый pet-проект.

### Месяц 2: Основы Go глубже

Повтор всего из "Сценария А, Неделя 1–2", но медленнее. По 1 теме в 2–3 дня вместо 1 дня.

Дополнительно:
- **Книга:** Кёрниган и Донован "Язык программирования Go" (432 стр., читать с пометками)
- **Практика:** 100 задач Exercism на Go

### Месяц 3: Основы веба

Чтобы писать бэкенд, надо понимать веб.

- HTTP/1.1, HTTP/2 — методы, статус-коды, заголовки
- REST API — что такое, как проектировать
- JSON — формат, парсинг
- TCP/UDP базово
- Базы данных:
  - SQL до уровня JOIN, GROUP BY, индексы
  - PostgreSQL поднять, написать 20 запросов
  - Транзакции, ACID

### Месяц 4: Первый Go-сервер + БД

Повтор "Сценария А, Неделя 2" + Месяц 4 = пиши URL-shortener.

К концу месяца у тебя есть один пет-проект — для собесного рассказа, не для GitHub-витрины (туда никто не зайдёт).

### Месяц 5: Конкурентность

Повтор "Сценария А, Неделя 3" + углубление:
- Книга/курс: "Concurrency in Go" (Katherine Cox-Buday)
- Все паттерны: pipeline, fan-in, fan-out, generator, bridge channels
- Решить 30 задач на конкурентность

### Месяц 6: Второй проект + инфраструктура

Второй проект — микросервис побольше: например, мини-маркетплейс с двумя сервисами (users + orders), общающимися через gRPC.

Параллельно:
- Docker — пишешь Dockerfile сам, multi-stage
- Docker Compose — поднимаешь postgres + redis + свой сервис
- Базовый Kubernetes (kind или minikube локально)
- CI/CD — GitHub Actions для своего проекта (тесты + сборка)

### Месяц 7: Углубление + Kafka

- Kafka на практике (poke locally, producer + consumer)
- Архитектура: Clean / Hexagonal на пальцах + рефактор своего проекта
- Понимаешь Service Discovery, Load Balancing, Circuit Breaker

### Месяц 8: Подготовка к собесам

- Топ-100 вопросов на Go-собесах — отвечать на каждый письменно
- Live coding — решение задач на скорость (10 минут каждая)
- System Design — 10 задач (URL shortener, лента новостей, чат, такси, нотификации, поиск, рекомендации, биллинг, коллаборативная доска, video streaming)
- 10 мок-собесов

### Месяц 9: Реальные собесы

50–100 откликов. 5–15 собесов. Цель — middle-оффер 200–400К (junior-вакансий супер мало, конкуренция запредельная). При плохом раскладе — стажировка 0–50К на 3–6 месяцев и параллельный поиск middle.
