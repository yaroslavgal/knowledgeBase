# AI-ментор как продукт — архитектура из 17 файлов на Claude Code

Не «настрой ChatGPT с промтом». Полноценная обучающая платформа поверх Claude Code. Структура из 17 markdown-файлов, превращающая CLI в персонального ментора с памятью, прогрессией и квизами.

Реальный пример — GoMentor AI. Архитектура переносится на любой стек.
