## Инструменты

### ChatGPT (chat.openai.com)
- **Бесплатная версия:** GPT-4o-mini, ограничения по запросам
- **Plus ($20/мес):** GPT-4o, GPT-4 Turbo, ограничения щадящие
- **Лучше для:** объяснений, ревью кода, генерации задач, прохождения teaching-сценариев

### Claude (claude.ai)
- **Бесплатная версия:** базовый Claude
- **Pro ($20/мес):** Claude Opus, Sonnet
- **Лучше для:** длинных кодовых задач, разбора больших файлов, нюансов архитектуры

### Claude Code
- **Что это:** агент, работающий в твоей файловой системе через CLI
- **Цена:** $20/мес (Pro) или $200 (Max)
- **Лучше для:** обучения с реальным проектом — Claude видит файлы, помогает структурно
- **Уникальное:** может хранить прогресс, читать твой код, выполнять тесты

### Cursor
- **Что это:** IDE с встроенным AI (форк VS Code)
- **Цена:** $20/мес
- **Лучше для:** ежедневной работы с кодом, автодополнения, чата прямо в редакторе
- **Минус:** легко скатиться в «accept-кнопку» вместо обучения

### GitHub Copilot
- **Цена:** $10–19/мес
- **Лучше для:** автодополнения в проф-работе. Для обучения — слабее ChatGPT/Claude.
