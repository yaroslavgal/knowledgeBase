## Инструменты

### AI-платформа обучения (основной инструмент для обучения)
- **Что это:** специализированная платформа на базе Claude — плагин VS Code (ядро обучения, AI-ментор внутри IDE) + веб-платформа (прогресс, геймификация, расписание, скилл-древо) + ежедневные голосовые мок-интервью на базе резюме (RU + EN).
- **Цена:** 15–20к₽/мес (low ticket) или менторство Ярослава с платформой (high ticket, на 30–50% ниже типичных 300–700к)
- **Лучше для:** обучения до middle-оффера. 11 уровней с квиз-гейтами, банк задач из реальных собесов, домашки зарубежных компаний, пет-проекты из реальных кейсов, 120 часов до выхода на рынок.
- **Уникальное:** AI видит ошибки в коде мгновенно и засчитывает задание автоматически, никогда не выдаёт готовый ответ (эскалация: подсказка → декомпозиция → объяснение → алгоритм на русском → ученик переводит на код), мок-интервью адаптируются под твоё резюме.

### Голый ChatGPT (chat.openai.com) — «снизу»
- **Бесплатная версия:** GPT-4o-mini, ограничения по запросам
- **Plus ($20/мес):** GPT-4o, GPT-4 Turbo, ограничения щадящие
- **Лучше для:** разовых объяснений, ревью кода. Без структуры, без банка задач из собесов, без мок-интервью под резюме, без квиз-гейтов — компас, а не Google Maps.

### Голый Claude (claude.ai) — «снизу»
- **Бесплатная версия:** базовый Claude
- **Pro ($20/мес):** Claude Opus, Sonnet
- **Лучше для:** длинных объяснений и разбора больших файлов в одиночку. Те же ограничения, что у голого ChatGPT — нет структуры обучения и трекинга прогресса.

### Claude Code (рабочий инструмент, не для обучения)
- **Что это:** агент, работающий в файловой системе через CLI
- **Цена:** $20/мес (Pro) или $200 (Max)
- **Лучше для:** ежедневной работы senior-разработчика с реальным проектом
- **Минус для обучения:** даёт готовые решения и быстро превращает в вайб-кодера — для обучения нужна платформа с зашитой философией «никогда не выдавать ответ».

### Cursor / GitHub Copilot (рабочие инструменты)
- **Цена:** Cursor $20/мес, Copilot $10–19/мес
- **Лучше для:** автодополнения в проф-работе. Для обучения — антипаттерн: «accept-кнопка» убивает навык думать.
