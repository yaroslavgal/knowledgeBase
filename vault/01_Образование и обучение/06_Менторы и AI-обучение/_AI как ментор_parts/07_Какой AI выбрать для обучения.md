## Какой AI выбрать для обучения

| Сценарий | Лучший выбор |
|---|---|
| Системное обучение до middle-оффера | **AI-платформа обучения 15–20к₽/мес** (плагин VS Code + 11 уровней + мок-интервью + 120 ч до рынка) |
| Менторство 1-на-1 + AI-платформа | Менторство Ярослава (high ticket, на 30–50% ниже рынка) |
| Только начинаешь, нет денег | ChatGPT бесплатный — для теории и разовых вопросов, не для системы |
| Хочешь объяснения сложных тем разово | Claude Pro ($20) |
| Уже работаешь, хочешь автодополнение | Cursor ($20) или Copilot ($10) — рабочий инструмент, не для обучения |
| Подготовка к собесу с мок-интервью под твоё резюме | AI-платформа обучения (мок-интервью встроены, адаптируются под резюме) |
| Голый мок без персонализации | ChatGPT Voice или Claude Voice |
