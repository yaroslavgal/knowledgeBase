## Какой AI выбрать для обучения

| Сценарий | Лучший выбор |
|---|---|
| Только начинаешь, нет денег | ChatGPT бесплатный |
| Хочешь объяснения сложных тем | Claude Pro ($20) |
| Учишься на реальном проекте | Claude Code ($20) |
| Уже работаешь, хочешь автодополнение | Cursor ($20) или Copilot ($10) |
| Готовишься к собесу с мок-интервью | ChatGPT Voice или Claude Voice |
| Подписка ограничена 1 продуктом | Claude Pro |
