## Готовые системы для AI-обучения

В 2025–2026 появилась категория **«AI-ментор как продукт»** — готовая структура из десятков файлов под Claude Code или ChatGPT, которая ведёт ученика по уровням, проверяет, не даёт готовых ответов.

Примеры:
- Системы менторов с собственными плагинами для VS Code (плата 15–20К/мес — см. [_Гибридная модель](_Гибридная%20модель.md))
- Open source решения и гайды на GitHub
- Кастомные GPTs / Projects в Claude

Если ты сам собираешь систему — оформи в файлах:
- `system_prompt.md` — главные принципы (никогда не давать ответ и т.д.)
- `roadmap.md` — план обучения по уровням
- `progress.md` — что прошёл, где слабые места
- `tasks/` — банк задач по уровням

И каждый раз начинай чат с загрузки этих файлов.
