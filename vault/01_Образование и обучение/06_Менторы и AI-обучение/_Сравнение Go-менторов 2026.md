# Сравнение Go-менторов на рынке РФ (2026)

Все Go-менторы рунета работают по одной и той же воронке: лид-магнит, консультация, курс с предоплатой. Внутри — общий паттерн, индивидуальный анализ каждого канала и сравнительная таблица.

## Общий паттерн менторов на рынке

Практически все менторы работают по единой воронке:

```
Обучение (модули/спринты) → Практика (проект/задачи) → Легенда + Резюме →
→ Мок-собесы → Массовые отклики → Записи реальных собесов + разбор →
→ Торг за ЗП → Оффер → Поддержка на ИС (2–3 мес.)
```

Различия — в глубине этапов и инфраструктуре. Ментор — бутылочное горлышко на каждом этапе. При масштабировании качество падает. Стандартный цикл код-ревью: ученик отправил в GitLab → 2 дня ждёт → ментор комментирует → ещё итерация → закрытие модуля.

## Системные слабости менторской модели

1. **Масштабируемость.** 1 ментор на десятки учеников. Белман (135+), Лукьянов (100+) неизбежно теряют глубину. Бадди-система — костыль, не гарантирует качество.
2. **Копипаст-обучение.** Задача → ученик не справляется → ментор (или бадди) даёт решение → ученик копирует логику → на собесе не может решить похожую задачу сам.
3. **Доступность ментора.** Ученик застрял в 11 вечера — ментор спит. Следующий созвон через 2 дня. Momentum теряется.
4. **Субъективная оценка готовности.** Ментор решает «готов / не готов» по ощущению от мок-собеса. Нет объективной системы.
5. **Цена.** Большинство 300к–700к с постоплатой. VEU до 950к+. Козорезов ~639к.
6. **Медленная обратная связь.** Цикл «отправил в GitLab → ждёшь 2 дня → комментарии → ещё итерация» — типичная норма.
7. **Теория без практического фундамента.** Многие дают блоки теории под зубрёжку. На собесе зазубренный ответ звучит «из учебника» — интервьюер слышит мгновенно.

## Базовые ожидания рынка (есть у всех)

- Легенда + резюме
- Мок-собесы с живыми людьми
- Поддержка на ИС 2–3 мес
- Массовые отклики / автоотклики
- Банк записей реальных собесов
- Боты для прогресса / пар / моков (есть у Карася, Романовича, Лукьянова, Нияза)

## Вывод для выбора ментора

Сравнивать стоит не по «количеству трудоустроенных», а по:
1. Скорости обратной связи на код
2. Доступности ментора между созвонами
3. Объективности оценки готовности
4. Цене относительно рынка
5. Подходу к обучению — практика vs зубрёжка теории

Большое количество устроенных у одного ментора часто означает потерю глубины внимания. Качество ≠ количество.
