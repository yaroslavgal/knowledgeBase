# Архитектура AI-платформы обучения (на примере системы Ярослава)

Архитектура AI-платформы обучения на примере системы Ярослава: двухуровневая модель — low-ticket AI-платформа за 15–20к/мес и high-ticket менторство сверху. Внутри — экономика, продуктовая логика и как платформа усиливает менторство.

## Двухуровневая бизнес-модель

**Уровень 1: AI-платформа (low ticket)**
- Цена: 15–20к руб/мес
- Цикл: 120 часов сфокусированной работы (при 4–5 ч/день — около месяца, при 2 ч/день — около двух)
- Формат: плагин VS Code + веб-платформа
- ЦА: новички, свитчеры, вход в Go Backend / Frontend
- Созвоны с ментором: 1 раз в неделю (1-на-1)
- Роль в воронке: прогрев и конверсия в менторство

**Уровень 2: Менторство + платформа (high ticket)**
- Формат: ментор лично ведёт + AI работает между синками
- ЦА: прогретые с платформы + прямые (после курсов, junior, свитчеры)
- Цикл: 80–120 часов сфокусированной работы — техника + легенда/собесы
- Синки каждые 2 дня по 20–30 мин
- Включает: ведение ментором, AI-обучение, мок-собесы (AI + живые), резюме и легенда (с 3-го уровня), массовые отклики, поддержка на ИС
- Цена: на 30–50% ниже среднерыночной

## Три компонента системы

### 1. Плагин VS Code (ядро обучения)

- Вшит весь флоу — все 10–11 уровней, ученик идёт по ним постепенно
- AI (Claude) встроен внутрь: мгновенно видит ошибки в коде, подчёркивает, подсказывает по best practice
- Автоматически засчитывает задание, когда оно реализовано корректно
- **Никогда не даёт готовый ответ** — ведёт к решению пошагово
- Всё, что ученик делает в плагине, автоматически подтягивается на веб-платформу

### 2. Веб-платформа (дашборд ученика)

- Визуализация прогресса с геймификацией
- Расписание: ближайший синк, дедлайны, оставшиеся задачи на сегодня
- Счётчик: сколько часов осталось до выхода на рынок (из 120)
- Данные подтягиваются с БД автоматически — никакого ручного ввода

### 3. AI мок-интервью

- Доступен с 3-го уровня (когда уже сделано резюме)
- В систему загружается резюме → AI формирует вопросы персонально под кандидата
- Полный банк вопросов, которые спрашивают на Go-собесах / Frontend
- Голосовой формат: русский + английский
- Для новичков: функция показа идеального ответа в реальном времени (с учётом резюме — AI берёт примеры оттуда)
- По мере прогресса функция отключается — ученик отвечает сам
- Claude выбирает рандомные сложные вопросы, адаптирует сценарий если ученик «плавает»

## Ядро AI-системы

- **17 файлов конфигурации:** 10 — база задач и теории с реальных собесов из 5+ источников, 7 — процессы, квизы, прогресс-трекинг
- **11 уровней с чёткой градацией:**
  - Lv1–3: синтаксис, минимум теории + задачи. Резюме уже на Lv3
  - Lv4–6: конкурентность, каналы, контексты — ядро Go (800+ строк по конкурентности)
  - Lv7–9: пет-проекты из реальных кейсов компаний + домашки зарубежных компаний (вилки $10–15к) + system design
  - Lv10: мок-интервью с адаптивным Claude + полная теоретическая подготовка
  - Lv11: финальная подготовка, выход на рынок
- **Философия «никогда не давать готовый ответ»:** декомпозиция → построчное объяснение → алгоритм на русском → перевод на Go → аналогии
- **Квиз-гейт между уровнями** — объективная воспроизводимая оценка готовности
- **Адаптивный онбординг:** определяет уровень, предыдущий опыт, аналогии с другими языками
- **Полный прогресс-трекинг:** всё фиксируется и используется для персонализации следующих уровней

## Процесс обучения на high ticket — флоу

```
Синк с ментором каждые 2 дня (20–30 мин):
  Ментор видит пройденные уровни →
  Спрашивает то, что спросят на реальном собесе →
  Копает в глубину как настоящий интервьюер →
  С 3-го уровня: задачи на лайв-кодинг + system design →
  Спрашивает про опыт, ученик объясняет →
  Личный контроль и давление, не даёт «забить»

Между синками (AI работает на ученика):
  Ученик решает задачи в VS Code (4–5 ч/день) →
  AI мгновенно подчёркивает ошибки, подсказывает best practice →
  Автоматически засчитывает задания →
  Прогресс подтягивается на платформу →
  Ежедневно: 30 мин мок-интервью с AI (голосом, по резюме)

Итог: ученик проходит десятки итераций «собеса» за 120 часов сфокусированной работы.
```

## Резюме делается рано — с 3-го уровня

В отличие от классического подхода (резюме в конце обучения):
- Мок-интервью с AI строятся на базе резюме (персонализация)
- Ученик с первых недель видит, к какому результату идёт
- Легенда формируется параллельно обучению, а не в конце

## Подготовка к 90% задач на работе

Задачи в системе включают и простые, и сложные. Сложные ученик может рассказать на собесе как «свою самую сложную задачу», а потом использовать на работе. Это снимает страх «а что делать в первый день».

## Сравнение: ментор без AI vs ментор + AI

| Параметр | Обычный ментор | Ментор + AI-платформа |
|---|---|---|
| Роль ментора | Даёт материал, ревьюит, иногда созванивается | Лично проверяет знания каждые 2 дня как интервьюер |
| Между синками | Ученик один (чат, бадди) | AI-платформа: практика 24/7, мгновенный фидбек, мок-интервью |
| Инфраструктура | Notion / TG / LMS отдельно | Плагин VS Code + веб + AI — единая система |
| Обратная связь по коду | Ревью через 2 дня в GitLab | AI видит ошибки мгновенно, засчитывает автоматически |
| Время до готовности | 3–6 месяцев (абстрактно) | 120 часов (конкретно) сфокусированной работы |
| Мок-интервью | 2–5 моков за весь курс | Ежедневно, голосом, по резюме, RU + EN |
| Доступность | 1–3 раза/нед + чат | AI 24/7 + синки каждые 2 дня |
| Подход | Теория → практика → ревью | 100% практика, теория запоминается через задачи |
| Помощь когда застрял | Дать ответ | Никогда не давать ответ, вести пошагово |
| Уровней | 4–6 модулей | 11 уровней с квиз-гейтами |
| Оценка готовности | Субъективная | Объективная (квиз-гейты + часы) |
| Резюме | В конце обучения | С 3-го уровня, используется для мок-интервью |
| Прогресс-трекинг | Ручной / частичный | Автоматический: плагин → БД → платформа |
