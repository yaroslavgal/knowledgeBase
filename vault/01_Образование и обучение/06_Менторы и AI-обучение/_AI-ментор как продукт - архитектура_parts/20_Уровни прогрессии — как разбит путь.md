## Уровни прогрессии — как разбит путь

11 уровней. Каждый — это конкретный навык + квиз для перехода.

| Уровень | Тема | Часов сфокусированной работы | Что прошёл |
|---|---|---|---|
| 1–2 | Синтаксис, типы, циклы | 10–15 ч | Можешь писать Hello World, базовый CLI |
| 3 | Функции, структуры, интерфейсы, ошибки | 10–15 ч | Идиоматичный Go (не Python на Go) |
| 4 | **Конкурентность** | 20–30 ч | Горутины, каналы, sync без deadlock |
| 5 | net/http, encoding/json, io | 10 ч | Простой HTTP API |
| 6 | Паттерны, тестирование | 10 ч | Table-driven tests, DI через интерфейсы |
| 7–8 | Пет-проекты на основе реальных кейсов | 20 ч | REST API + БД + Docker |
| 9 | Take-home задания с реальных собесов (3–4 ч) | 5–10 ч | Готов к домашкам зарубежных компаний |
| 10 | Теория + полное мок-интервью на 60 мин | 5 ч | Пройдёт скрининг |
| 11 | System Design сеньорного уровня | по запросу | L5–L6 в FAANG-аналогах |

Уровень 4 (Конкурентность) — самый объёмный, ~800 строк контента. Именно тут ломается большинство.
