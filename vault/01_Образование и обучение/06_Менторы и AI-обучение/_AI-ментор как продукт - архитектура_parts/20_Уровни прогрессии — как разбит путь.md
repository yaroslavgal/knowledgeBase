## Уровни прогрессии — как разбит путь

11 уровней. Каждый — это конкретный навык + квиз для перехода.

| Уровень | Тема | Длительность | Что прошёл |
|---|---|---|---|
| 1–2 | Синтаксис, типы, циклы | 3–5 дней | Можешь писать Hello World, базовый CLI |
| 3 | Функции, структуры, интерфейсы, ошибки | 5–7 дней | Идиоматичный Go (не Python на Go) |
| 4 | **Конкурентность** | 7–10 дней | Горутины, каналы, sync без deadlock |
| 5 | net/http, encoding/json, io | 5 дней | Простой HTTP API |
| 6 | Паттерны, тестирование | 5 дней | Table-driven tests, DI через интерфейсы |
| 7–8 | Пет-проекты на основе реальных кейсов | 10 дней | REST API + БД + Docker |
| 9 | Take-home задания с реальных собесов (3–4 ч) | 1–2 недели | Готов к домашкам зарубежных компаний |
| 10 | Теория + полное мок-интервью на 60 мин | 1 неделя | Пройдёт скрининг |
| 11 | System Design сеньорного уровня | по запросу | L5–L6 в FAANG-аналогах |

Уровень 4 (Конкурентность) — самый объёмный, ~800 строк контента. Именно тут ломается большинство.
