## Зачем 17 файлов вместо одного промта

Промт в чате — это **stateless**. Каждый новый чат — с нуля. AI не помнит ни прогресс, ни слабые места, ни какой ты уровень.

Файловая система — это **persistent**. Claude Code читает файлы при старте, пишет в них прогресс. Память живёт между сессиями.

| Параметр | Чат с промтом | Система файлов |
|---|---|---|
| Прогресс между сессиями | Теряется | `progress.md` сохраняется |
| Слабые места | Не помнит | Записаны в файл |
| Адаптация под уровень | Каждый раз заново | Один онбординг — навсегда |
| Квизы и проверки | Невозможно | Квиз-гейты между уровнями |
| Банк задач | В контексте — съедает токены | Файлы, грузятся по требованию |

Цитата из обсуждений 2024: «Самая большая проблема ChatGPT — деменция. Он не помнит прошлый урок, не знает системные ошибки.» Файловая система решает это **архитектурно**.
