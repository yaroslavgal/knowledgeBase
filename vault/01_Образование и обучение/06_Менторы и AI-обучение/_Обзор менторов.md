# Обзор менторов на русскоязычном рынке (2026)

Ниже — обзор основных менторов по Go и Frontend. Информация — из их публичных каналов, сайтов и Telegram-постов. Цены могут меняться, проверяй актуальное.

> **Дисклеймер:** обзор не является рекомендацией. Это карта, чтобы было понятно, что вообще есть на рынке. Цифры о трудоустройстве — заявленные самими менторами, не верифицированы независимо.

> ⚠️ **Сравнивай менторов через регламент:**
> - **Этап 1 (основы языка):** что включено? обычно — небольшая часть программы или входной фильтр
> - **Этап 2 (подготовка к собесу — главная фаза):** банк вопросов, количество мок-интервью, база записей реальных собесов, take-home задания — это **главное**, на что смотреть
> - **Этап 3 (1–2 пет-проекта):** ревью кода, помощь с легендой
> - **Финал:** массовые отклики, разбор реальных собесов, поддержка ИС
>
> Ментор без сильного этапа 2 — даёт растянутую теорию, а не путь к офферу.

## Frontend (React, Vue, TypeScript)

### Frontend Alliance, Davidka, Veu, KOZOREZOV, IT Mountain
В сегменте Frontend менторов больше, ситуация фрагментированнее. Цена обычно 200–500К₽, кейсов 30–100, средний оффер 250–350К.

Конкретику ищи на:
- Telegram-каналах менторов
- Сайтах с агрегацией (мнения)
- Групповых чатах выпускников

### Что общего у Frontend-менторов
- Программа: HTML/CSS → JS → React/Vue → TypeScript → проект → собесы
- 60–120 часов сфокусированной работы — типичный срок
- Резюме делается ближе к концу (у некоторых — раньше)
- Мок-собесы: 5–15 за весь курс
- Поддержка ИС: 2–3 мес

## Общие наблюдения по рынку 2026

### Стандартный паттерн менторства
```
Обучение (модули) → Практика (проект) → Резюме + легенда → Мок-собесы →
→ Массовые отклики → Записи реальных собесов + разбор → Торг за ЗП →
→ Оффер → Поддержка на ИС (2–3 мес)
```

### Системные слабости массовых менторов

1. **Масштабируемость.** 1 ментор + 100+ учеников — неизбежно теряется глубина. Бадди-система — компромисс.
2. **Доступность.** Застрял в 11 вечера — ментор спит. Следующий созвон через 2 дня.
3. **Копипаст-обучение.** Задача → застрял → бадди / помощник по сути даёт решение → ученик копирует → на собесе сам не может.
4. **Субъективная оценка готовности.** Ментор по ощущению решает «готов / не готов».
5. **Цена.** 300–700К — норма, премиум до 950К+. Высокий финансовый риск.
6. **Медленная обратная связь.** Отправил код в GitLab → ментор ревьюит через 2 дня → итерация → закрытие.

### Что фишки рынка ожидают как стандарт (2026)
- ✅ Легенда + резюме
- ✅ Мок-собесы с живыми людьми
- ✅ Поддержка на ИС 2–3 месяца
- ✅ Массовые отклики или их настройка
- ✅ Банк записей реальных собесов
- ✅ Бот для прогресса / пар / моков
- ✅ Постоплата 30–70%

Если у ментора чего-то из этого нет — это либо «новый ментор без отлаженных процессов», либо «не очень».

### Что отличает топовых менторов 2026
- Своя платформа (не Notion-ссылки)
- AI-инструменты для ежедневной практики (между созвонами)
- Голосовые мок-интервью с AI
- Прогресс-трекинг с метриками
- Записи 100+ реальных собесов
- Чёткая, измеримая программа (например, «120 часов до рынка»)
- Команда (помощник, сорсеры, бадди), но с фокусом ментора на ключевые этапы

## Альтернативы массовому менторству

| Формат | Цена | Когда подходит |
|---|---|---|
| **Часовая консультация с senior'ом** | 5–10К/час | Разовая помощь, ревью пет-проекта |
| **Микро-менторство (2–4 созвона/мес)** | 10–30К/мес | Когда ты сам учишься, нужна сверка |
| **AI-платформа обучения** ([_AI как ментор](_AI%20как%20ментор.md)) | 15–20к₽/мес × 120 часов работы | Когда нет 200К на курс — плагин VS Code, 11 уровней с квиз-гейтами, ежедневные мок-интервью, 120 ч до рынка |
| **Гибрид: ментор + AI** | 200–400К | Лучший КПД на рубль вложенного |
| **Корпоративные программы** (если уже работаешь) | 0₽ | У многих компаний есть менторы для сотрудников |

## Главный вывод

Менторство — рабочий инструмент **на финальной миле** до оффера. Не на старте. Если ты ноль — иди по [бесплатному пути](../01_Платформы%20обучения/Бесплатные/_Бесплатно%20не%20значит%20хуже.md). Когда есть база и понятно, чего не хватает — приходи за стратегией и собесами.

→ Дальше: [_AI как ментор.md](_AI%20как%20ментор.md) — AI-платформа обучения как новая категория: дешевле курсов в 10 раз, быстрее в 3 раза, требует базовой дисциплины (платформа геймифицирует прогресс — счётчик часов до рынка, уровни, квиз-гейты, ежедневные мок-интервью).
