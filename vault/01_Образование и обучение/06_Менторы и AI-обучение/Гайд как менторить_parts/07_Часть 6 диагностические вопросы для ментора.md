## ЧАСТЬ 6: ДИАГНОСТИЧЕСКИЕ ВОПРОСЫ ДЛЯ МЕНТОРА

Список вопросов для первой сессии с новым менти (создатель курсов/школы):

### Бизнес-метрики:
```
1. Сколько посещений сайта / бота в месяц?
2. Сколько анкет / лидов в месяц?
3. Сколько звонков в месяц?
4. Конверсия звонков в продажи (в %)?
5. Средний чек?
6. Откуда приходит трафик (по каналам, в %)?
7. Есть ли UTM-метки по всей воронке?
```

### Продукт и аудитория:
```
8. Кто твоя целевая аудитория (опиши конкретно)?
9. Какая основная задача/боль у каждого сегмента?
10. Что является ПРИЧИНОЙ этой задачи (не сама задача, а почему она появилась)?
11. Кто делает продажи (ты сам / менеджер / автоматически)?
12. Есть ли скрипты по сегментам?
```

### Маркетинг:
```
13. Какие каналы пробовал? Что сработало?
14. Какие каналы хочешь попробовать?
15. Какой бюджет на маркетинг?
16. Есть ли контент-план? Кто делает контент?
```
