## ИТОГ: ЧТО ДЕЛАЕТ ХОРОШЕГО МЕНТОРА

| Хороший ментор | Плохой ментор |
|----------------|---------------|
| Слушает, потом задаёт вопросы | Сразу даёт советы |
| Указывает на разрыв между ожиданием и реальностью | Соглашается со всем |
| Объясняет механизм проблемы | Называет проблему без объяснения |
| Даёт конкретные следующие шаги | Даёт общие рекомендации |
| Расставляет приоритеты | Пытается решить всё сразу |
| Признаёт правоту менти | Всегда противоречит |
| Использует аналогии | Говорит только терминами |
| Указывает на пропущенные данные | Принимает данные менти без проверки |
