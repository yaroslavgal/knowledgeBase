## ЧАСТЬ 5: МАРКЕТИНГОВЫЕ ФРЕЙМВОРКИ ДЛЯ МЕНТИ-СОЗДАТЕЛЕЙ КУРСОВ

*(Из сессии с Ником — советы Антона по маркетингу онлайн-школ)*

### Воронки vs. Telegram-каналы

**Если один Telegram-канал:**
- Разные воронки внутри него под разные сегменты
- Каждый лид-магнит ведёт в свою автоматическую воронку
- Можно делать запуски на всю базу по общим темам

**Если разные продукты с разными аудиториями:**
- Отдельные Telegram-каналы под каждый сегмент
- Иначе: убиваешь охваты, ломаешь алгоритм, база смешивается

### YouTube-стратегия
- **Первые продажи** — через ~1 год после старта
- **Консистентность аудитории** — снимай для одного типа зрителя (нельзя миксовать "для начинающих" и "для сеньоров" в одном канале)
- **Алгоритм YouTube** — показывает ролик твоей аудитории → если хорошо смотрят → lookalike → lookalike lookalike

### Работа с анкетами
- Каждый вопрос должен быть инструментом продажи, не просто статистикой
- Информацию из анкеты использовать на звонке: "Я вижу вы [пункт из анкеты]..."
- Чем больше вопросов — тем ниже конверсия заполнения анкеты. Компромисс нужен.
