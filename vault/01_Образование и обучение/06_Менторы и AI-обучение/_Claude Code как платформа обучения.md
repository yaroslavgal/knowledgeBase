# Claude Code как платформа обучения (а не вайб-кодинга)

Большинство знают Claude Code как инструмент для генерации кода. Реально это **обучающая среда** — потому что в отличие от ChatGPT он работает с файлами на диске.

## Главное архитектурное отличие от ChatGPT

| Параметр | ChatGPT | Claude Code |
|---|---|---|
| Память между сессиями | Нет (контекст чата) | **Файлы на диске** |
| Прогресс ученика | Забывает | `progress.md` сохраняется |
| Слабые места | Не помнит | Записаны в файл |
| Результаты квизов | Теряются | Хранятся структурно |
| Адаптация под уровень | Каждый раз заново | Один онбординг — навсегда |

«Самая большая проблема ChatGPT — у него деменция. Это не преподаватель. Он не помнит прошлый урок, что задал, какие у ученика системные ошибки» — комментарий, отражающий главную боль.

Claude Code эту проблему **архитектурно решает** — данные в файловой системе, а не в контекстном окне.

## Структура AI-ментора как продукта

Минимальный набор файлов:

```
mentor/
├── CLAUDE.md            # точка входа, правила ментора
├── onboarding.md        # определение уровня ученика
├── roadmap.md           # план уровней
├── progress.md          # что пройдено, слабые места
├── quiz_results.md      # история квизов
├── tasks/
│   ├── level_01.md
│   ├── level_02.md
│   └── ...
└── system_prompt.md     # «никогда не давать ответ»
```

Каждую сессию Claude читает CLAUDE.md → progress.md → знает где ты.

## Уровни прогрессии — пример для Go

11 уровней с квиз-гейтами (нельзя перескочить):

| Уровень | Тема | Часов сфокусированной работы |
|---|---|---|
| 1–2 | Синтаксис, типы, циклы | 10–15 ч |
| 3 | Функции, структуры, интерфейсы, ошибки | 10–15 ч |
| 4 | Конкурентность (горутины, каналы, sync) | 20–30 ч |
| 5 | Стандартная библиотека (net/http, json) | 10 ч |
| 6 | Паттерны, тестирование | 10 ч |
| 7–8 | Пет-проекты на основе кейсов | 20 ч |
| 9 | Take-home задания с реальных собесов | 5–10 ч |
| 10 | Теория + мок-интервью | 5 ч |
| 11 | System Design сеньорного уровня | по запросу |

Переход — через **квиз + решение самой сложной задачи уровня**. Иначе остаёшься.

## Принцип «5-шаговый каскад подсказок»

Ключевое отличие от ChatGPT, который сразу даёт код. Ментор работает по уровням:

1. **Общая идея:** «Какая структура хранит пары ключ-значение?»
2. **Декомпозиция:** «Тебе нужна map. Сначала объяви её.»
3. **Алгоритм на русском:** «Создай map[string]int. Прочитай массив. Для каждого элемента — увеличь значение.»
4. **Псевдокод** — если совсем не идёт.
5. **Готовый код** — только если застрял на 30+ минут (и почти никогда).

Прыгнул сразу на 5 — не учишься.

## Адаптация под бэкграунд

На онбординге AI спрашивает: какие языки знаешь?

- Python → аналогии с asyncio, list comprehensions
- Java → ExecutorService для горутин
- JS → Promise / event loop для каналов
- Без бэкграунда → бытовые аналогии (портал, ресторан, кассир)

Это меняет подачу всего курса. Курс из коробки этого не делает.

## Mock-интервью встроены в каждый уровень

После завершения уровня — обязательный режим mock interview по теме:
- 3–5 вопросов
- follow-up на каждый ответ
- разбор слабых мест

На уровне 10 — полное мок-собеседование на 60 минут.

Это снимает «иллюзию знания»: можешь знать, но не уметь сформулировать.

## Стоимость vs живой ментор

| Опция | Цена | Доступность | Скорость фидбэка |
|---|---|---|---|
| Живой ментор 1-на-1 | 300–700К за путь | 1–3 раза/неделю | 1–2 дня (ревью в GitLab) |
| ChatGPT Plus / Claude Pro (голый) | 1.8K ₽/мес | 24/7 | мгновенно, но «деменция», без структуры |
| **AI-платформа обучения (low ticket)** | **15–20K ₽/мес × 120 часов работы** | **24/7** | **мгновенно, с памятью прогресса, мок-интервью под резюме, квиз-гейты, 120 ч до рынка** |
| Менторство Ярослава + AI-платформа (high ticket) | На 30–50% ниже рынка vs 300–700К | Синки каждые 2 дня + AI 24/7 между сессиями | Мгновенно (AI) + личный разбор каждые 2 дня |

Аналогия: голый ChatGPT/Claude — спросить дорогу у прохожего. AI-платформа обучения с плагином VS Code, банком задач из реальных собесов и встроенными мок-интервью — нанять гида с картой, журналом и тренажёром.

## Что AI-платформа НЕ заменит

Не путать с антипаттерном «AI вместо ментора»:

- стратегию под конкретную ситуацию (кому идти, в какую компанию)
- знание реального рынка вакансий
- упаковку резюме и легенды
- эмоциональную поддержку
- связи и рекомендации

Это всё остаётся за живым человеком. AI-платформа — на уровне ежедневной практики.
