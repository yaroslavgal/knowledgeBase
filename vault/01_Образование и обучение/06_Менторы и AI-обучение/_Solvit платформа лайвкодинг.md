# Solvit — платформа подготовки к лайвкодингу

Платформа с задачами из реальных собесов BigTech. Можно фильтровать по компании.

## Что это

Платформа с задачами **из реальных собесов BigTech**. Можно фильтровать по компании.

> «Solvit упомянут как инструмент с задачами из реальных собесов BigTech — фильтр по компании.»

---

## Чем отличается от LeetCode

| LeetCode | Solvit |
|---|---|
| Универсальные задачи | Из конкретных компаний |
| Самостоятельная сортировка | Готовые наборы по компаниям |
| Решения от пользователей | Решения с разбором |
| Без mock-сценария | Mock-сценарий собеса |
| Бесплатно (с ограничениями) | Платно (есть пробный) |

---

## Как использовать

### 1. Выбираешь целевые компании
- Например: Yandex, Ozon, Avito (для РФ)
- Или: Google, Stripe, Datadog (для международки)

### 2. Решаешь типичные задачи этой компании
- Каждая задача — из реального собеса (анонимизированно)
- Видишь паттерны: какой тип задач любит компания
- Готовишься к их специфике

### 3. Mock-сценарий
- Симуляция собеса с таймером
- Проговаривание решения вслух
- Разбор после

## Альтернативы Solvit

| Платформа | Что |
|---|---|
| **LeetCode** | Универсальные задачи, дешёво |
| **HackerRank** | Соревновательное программирование + интервью |
| **Pramp** | Бесплатные mock-собесы с другими разработчиками |
| **Interviewing.io** | Платно, но с senior FAANG инженерами |
| **AlgoExpert** | Платно, технические задачи + System Design |
| **Educative.io** | Курсы Grokking System Design |
| **Excalidraw** | Для тренировки System Design рисования |

---

## Стратегия комбинирования

### Junior → Middle (3–6 месяцев)
1. **LeetCode Top 100 Easy** — базовые паттерны
2. **LeetCode Top 50 Medium** — типовые задачи
3. **Pramp 5–10 mock-интервью**

### Middle → Senior (6–12 месяцев)
1. **LeetCode Top 150 Interview** (Easy + Medium + начало Hard)
2. **System Design Primer** + **ByteByteGo**
3. **Solvit / AlgoExpert** для специфики компаний
4. **Interviewing.io** 3–5 платных mocks с FAANG

### Senior → Staff (1+ год)
1. **LeetCode Hard 50+ задач**
2. **«Designing Data-Intensive Applications»** (Kleppmann)
3. **Множество System Design кейсов** (10+)
4. **Behavioral подготовка** (Amazon LP, leadership stories)

## AI как ментор для подготовки

### Использование Claude Code / ChatGPT

```
Промпт: «Я готовлюсь к собесу в Ozon на Senior Go.
Сгенерируй 5 типовых задач из их собесов с разной сложностью.
Для каждой задачи дай:
1. Условие
2. Скелет решения (без полного кода)
3. Ключевые подвохи
4. Ожидаемая сложность

Темы: конкурентность, паттерны микросервисов, базы данных.»
```

### Mock-собес с AI

```
Промпт: «Веди со мной mock-собес на Senior Go в Ozon на 60 минут.
Структура:
- 10 мин: introduction + behavioral
- 30 мин: лайвкодинг (одна Medium задача)
- 15 мин: System Design (короткий)
- 5 мин: вопросы кандидату

Я буду писать код в чате. Веди как реальный senior-инженер.
Задавай follow-up вопросы. Подвохи — стандартные для Ozon.»
```

## Чек-лист подготовки к лайвкодингу

- [ ] LeetCode Top 100 Easy решены
- [ ] LeetCode Top 50 Medium решены
- [ ] 5+ задач Hard разобраны
- [ ] Solvit / Pramp mock-сценарий пройден 5+ раз
- [ ] System Design 5+ кейсов
- [ ] Behavioral 10+ STAR-историй
- [ ] AI mock-собес 3+ раз
- [ ] Реальный mock с senior-инженером 2+ раз
- [ ] Привычка проговаривать решение вслух
- [ ] Готов: 1 Easy + 1 Medium / час (Senior)
