## Шаг 2: Выбери первый язык

Нет «лучшего» или «плохого» языка. Есть популярные и подходящие под твою цель.

| Хочу делать                                 | Стек первого языка                                                                                                          |
| ------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------- |
| **Веб-сайты и веб-приложения (frontend)**   | HTML + CSS + JavaScript → потом React / Vue / Next                                                                          |
| **Бэкенд**                                  | JavaScript (Node), Python, Go или Java                                                                                      |
| **Финтех, банки, корпоратив, стабильность** | **Java** — кроссплатформенность, огромное комьюнити, стабильно в топ-3 по TIOBE, нужен везде от мобильных игр до финсектора |
| **iOS**                                     | Swift                                                                                                                       |
| **Android**                                 | Kotlin                                                                                                                      |
| **Кросс-платформенный мобайл**              | React Native или Flutter                                                                                                    |
| **Игры**                                    | Unity (C#) или Unreal Engine (C++)                                                                                          |
| **AI / ML**                                 | Python + математика (статистика, линейная алгебра). Библиотеки: TensorFlow, PyTorch, scikit-learn                           |
