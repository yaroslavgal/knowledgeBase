## Главное

Регламент:
- **1–2 месяца — основы языка** (синтаксис, типы, функции, ООП).
- **2–3 месяца — подготовка к собесу** (банк вопросов + мок-интервью + лайв-кодинг). Это **основа** обучения.
- **Параллельно — 1–2 пет-проекта**. Не 10. Один сильный достаточно.
- **Дальше — реальные собесы.** Каждый = бесплатное обучение.

Дополнительно:
1. **Научись учиться** — это база. Без этого никакой курс не поможет.
2. **Ответь себе: ЧТО хочу делать и ПОЧЕМУ** — это ответ на «какой язык».
3. **Выбери первый язык под цель**, не «модный». HTML/CSS/JS для веба, Java для энтерпрайза, Python для AI, Swift/Kotlin для мобайла, C# для игр.
4. **Используй ресурсы по делу**, не залипай в гайдоят.
5. **Найди мотивацию-зацепку** на старте, дисциплину выработаешь потом.
6. **Просто начни** — теория без практики мертва. Первый калькулятор > десять курсов.
