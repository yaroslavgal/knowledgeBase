# organize-vault

Используй для folder, MOC, parent, topology, split/merge и note-boundary решений.

## Читать сначала

- `.vault-agent/RULES.md`
- `.vault-agent/PROFILE.md`
- `.vault-agent/STRUCTURE.md`
- `.vault-agent/PATTERNS.md`

## Принципы

- Folders — устойчивые области.
- MOCs — curated routes.
- `parent` — основной навигационный позвоночник.
- Links — механизмы, не замена папок.
- Tags — не главный слой навигации.

## Workflow

1. Определи структурный вопрос.
2. Проверь files, folders, MOCs, parents и backlinks.
3. Используй QMD, если важны semantic duplicates или cross-cluster recall.
4. Предложи самую маленькую полезную структуру.
5. Объясни tradeoffs и approval boundary.
6. Применяй только после explicit approval.

## Output

- current state;
- proposed state;
- affected paths;
- expected navigation gain;
- risk;
- rollback path.
