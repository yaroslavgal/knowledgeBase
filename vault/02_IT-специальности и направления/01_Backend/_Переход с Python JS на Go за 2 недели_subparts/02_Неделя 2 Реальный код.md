### Неделя 2: Реальный код

| День | Тема | Результат |
|---|---|---|
| 8 | net/http — сервер на стандартной библиотеке | GET/POST эндпоинты |
| 9 | encoding/json, валидация | API возвращает структуру в JSON |
| 10 | database/sql + pgx, простые запросы к Postgres | CRUD через БД |
| 11 | Структура проекта: cmd/, internal/, слои | Handler → service → repository |
| 12 | Тесты: testing, table-driven | Покрытие 50%+ |
| 13 | Конкурентность: errgroup, sync.WaitGroup | Параллельная обработка списка |
| 14 | Сборка: Dockerfile, multi-stage, бинарь | Контейнер с приложением |

К концу 14-го дня — простой HTTP API с БД и тестами в Docker. Этого достаточно, чтобы начать ревьюить Go-код в чужом проекте.
