### 1. Указатели

В Python всё передаётся «как бы по ссылке». В JS объекты — по ссылке, примитивы — по значению. В Go по умолчанию — копия структуры. Хочешь менять оригинал — передавай указатель.

```go
func birthday(u User)   { u.Age++ }   // меняет копию, оригинал не изменится
func birthday(u *User)  { u.Age++ }   // меняет оригинал
birthday(&user)
```

Аналогия: указатель — ссылка на Google Doc (можно редактировать оригинал). Значение — скачанный PDF (правишь только свою копию).
