### 2. `if err != nil` вместо try/catch

В Go нет исключений. Ошибка возвращается рядом с результатом, и ты обязан её обработать (компилятор не даст забыть).

Это многословно, но прозрачно: каждая точка отказа явная.

```go
data, err := json.Marshal(user)
if err != nil {
    return fmt.Errorf("marshal user %d: %w", user.ID, err)
}
```
