### 6. Интерфейсы определяются у потребителя

В Python/Java/TS интерфейс — отдельный файл, реализуется явно. В Go интерфейс определяется ТАМ, где используется (`type Storage interface { Save(ctx, item) error }`), и любая структура с подходящими методами автоматически его реализует.

---

## AI в обучении (Claude Code, Cursor)

LLM ускоряют этот переход в разы. Конкретные приёмы:

- В системном промпте: «Я знаю Python (или JS). Объясняй Go-концепции через аналогии с моим языком».
- Просишь объяснить чужой Go-код на привычных тебе понятиях.
- Просишь конвертировать твой Python/JS-код в идиоматичный Go.
- Просишь типичные ошибки начинающих в конкретной теме (горутины, указатели).

LLM — не замена обучения, а ускоритель. Tour of Go всё равно нужно пройти — но с AI каждая концепция занимает не 2 часа поиска по докам, а 10 минут диалога.

## Кейс из транскриптов

Дмитрий, 27 лет, 2 года React/TypeScript, ЗП 180к. Решил перекатиться в Go-бэкенд из-за AI-конкуренции на фронте.

Стандартные туториалы не работали — «читаю доку, всё чужое». Подключил Claude Code с указанием «знаю TypeScript». AI объяснял Go через TS-аналогии.

- Неделя 1: Tour of Go + CLI-утилита для рабочих задач
- Неделя 2: HTTP API на стандартной библиотеке
- Месяц 2: подготовка к собесам по roadmap.sh/golang

Через 2 месяца — оффер Go-бэкендером в финтех на 350к. Грейд не потерял (мидл).

## Чек-лист после 2 недель

| # | Умеешь? |
|---|---|
| 1 | Написать HTTP-сервер на net/http без фреймворков |

| 3 | Объяснить разницу значение vs указатель |

6+ из 8 — переход успешен. Дальше — 1–2 месяца на пет-проекты и подготовку к собесам.
