### Как пишет джун

```go
type UserService struct {
    repo *PostgresUserRepository // жёстко привязан к Postgres
}

func (s *UserService) GetUser(id int) (*User, error) {
    return s.repo.FindByID(id)
}
```

Не подставишь мок. Не сменишь БД без переписывания. На собесе не покажешь работу с интерфейсами.
