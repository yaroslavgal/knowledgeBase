### Как пишет джун

```go
result, _ := db.Query("SELECT * FROM users")
```

Игнорирование через `_` — красный флаг. Вопрос интервьюера: «А что будет, если БД не ответит?»

```go
data, err := json.Marshal(user)
if err != nil {
    log.Println(err) // залогировал и пошёл дальше
}
```

В мониторинг ничего не пришло. Контекста нет — где сломалось, на каком пользователе.
