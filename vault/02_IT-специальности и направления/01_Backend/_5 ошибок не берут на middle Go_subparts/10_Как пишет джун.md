### Как пишет джун

```go
func processNotifications(notifications []Notification) {
    for _, n := range notifications {
        go func() {
            sendNotification(n) // БАГ: замыкание на переменную цикла
        }()
    }
    // функция завершилась, горутины ещё работают, никто их не ждёт
}
```

Два бага:
1. Замыкание на `n` (классика, в Go 1.22+ исправлено в языке, но паттерн надо знать)
2. Утечка горутин — функция вернулась, никто их не ждёт
