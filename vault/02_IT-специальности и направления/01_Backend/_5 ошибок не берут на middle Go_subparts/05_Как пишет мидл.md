### Как пишет мидл

```
/cmd
  /api
    main.go              // только запуск сервера

/internal
  /handler               // HTTP
    user.go
  /service               // бизнес-логика
    user.go
  /repository            // работа с БД
    user.go
  /model                 // структуры данных
    user.go

/pkg                     // переиспользуемые пакеты для внешних
```

Принципы:
- `handler` не знает про БД
- `service` не знает про HTTP
- `repository` не знает про бизнес-логику
- Слои общаются через интерфейсы
