### Как пишет джун

```go
var db *sql.DB
var notificationChan = make(chan Notification, 100)
var configs = map[string]Config{...}

func handleSendNotification(w http.ResponseWriter, r *http.Request) {
    rows, _ := db.Query("SELECT ...")
}
```

Три беды сразу:
1. Замокать `db` для теста невозможно — нужно поднимать реальную БД
2. Race condition на глобальном канале при параллельных запросах
3. На ревью читается за секунду
