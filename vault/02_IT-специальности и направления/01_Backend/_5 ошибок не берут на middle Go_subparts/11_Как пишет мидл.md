### Как пишет мидл

```go
func processNotifications(ctx context.Context, notifications []Notification) error {
    g, ctx := errgroup.WithContext(ctx)

    for _, n := range notifications {
        n := n // локальная копия
        g.Go(func() error {
            select {
            case <-ctx.Done():
                return ctx.Err()
            default:
                return sendNotification(ctx, n)
            }
        })
    }

    return g.Wait()
}
```

Три ключа:
- `errgroup` — ждёт все горутины, собирает первую ошибку
- `n := n` — локальная копия для замыкания
- `ctx` — отменяемость, горутины не висят вечно
