## Когда каналы, когда mutex, когда WaitGroup — фреймворк выбора

Один из самых частых вопросов на собесах. Простое правило:

- **Передать данные** между горутинами → каналы
- **Защитить общую переменную** → mutex (или atomic для простых)
- **Просто дождаться** N горутин без данных → WaitGroup

```go
// Одна задача — два решения

// Через mutex
var mu sync.Mutex
sum := 0
for i := 0; i < 5; i++ {
    wg.Add(1)
    go func() {
        defer wg.Done()
        result := work()
        mu.Lock()
        sum += result
        mu.Unlock()
    }()
}
wg.Wait()

// Через канал — короче и без mutex/WG
ch := make(chan int, 5)
for i := 0; i < 5; i++ {
    go func() { ch <- work() }()
}
sum := 0
for i := 0; i < 5; i++ { sum += <-ch }
```

Каналы выигрывают, когда нужна и передача, и синхронизация одновременно.
