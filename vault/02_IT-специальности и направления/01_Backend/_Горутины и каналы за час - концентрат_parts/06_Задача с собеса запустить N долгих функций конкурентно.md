## Задача с собеса: запустить N долгих функций конкурентно

Типовая. Доказывает, что ты понимаешь горутины.

«Есть `doWork()`, работает 1–5 секунд. Вызови 100 раз конкурентно. Main должен уложиться в ~5 сек, не в ~250.»

```go
func main() {
    start := time.Now()
    ch := make(chan int, 100)

    for i := 0; i < 100; i++ {
        go func() { ch <- doWork() }()
    }

    total := 0
    for i := 0; i < 100; i++ { total += <-ch }

    fmt.Printf("Main: %v\n", time.Since(start))   // ~5s
    fmt.Printf("Total work: %d сек\n", total)     // ~250s
}
```

Сэкономили 245 секунд тем, что запустили в горутинах. Один канал — без WaitGroup, без mutex.
