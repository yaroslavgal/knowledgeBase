## Топ-7 ловушек, которые ловят на собесе

| # | Ловушка | Признак | Фикс |
|---|---|---|---|
| 1 | WaitGroup по значению | `Wait` не дожидается | По указателю всегда |
| 2 | Замыкание на `i` в for | до Go 1.22 — печатает 5 5 5 5 5 | `go func(v int){}(i)` или Go 1.22+ |
| 3 | Запись в небуф канал без читателя | deadlock / утечка | Буферизированный или вторая горутина |
| 4 | Запись в закрытый канал | panic | Закрывает только writer; через `defer close` |
| 5 | `counter++` без синхронизации | Data race, теряются инкременты | atomic.Int64 / sync.Mutex |
| 6 | Копирование структуры с Mutex | go vet copylocks | По указателю; явное поле `mu sync.Mutex` |
| 7 | Embedding `sync.Mutex` | Lock/Unlock уходят в публичный API | Явное приватное поле |
