## Fork-Join модель — почему «горутина не работает»

Любой `go func()` — это **fork**. Программе нужна **join** — точка, где основная горутина ждёт. Без join — main завершается раньше, ничего не печатается.

```go
// НЕПРАВИЛЬНО — main выходит до того как горутина допечатает
func main() {
    go func() { fmt.Println("hi") }()
    // тут пусто
}

// ПРАВИЛЬНО — WaitGroup как join
func main() {
    var wg sync.WaitGroup
    wg.Add(1)
    go func() {
        defer wg.Done()
        fmt.Println("hi")
    }()
    wg.Wait()
}
```

**Главное правило WaitGroup:** ВСЕГДА передавай **по указателю**. Передал по значению — копия, `Wait()` никогда не дождётся. Классика, на которой горят на собесах.

Аналогия: горутина = курьер. `go` = «иди». Уехал из офиса до возвращения — результат не получишь. `wg.Wait()` = «жду тут».
