## Каналы — портал из рук в руки

Канал — способ передачи данных между горутинами. Операции **блокирующие**: запись ждёт читателя, чтение ждёт писателя.

```go
// DEADLOCK — некому читать пока main блокирован на записи
ch := make(chan int)
ch <- 1
val := <-ch

// fatal error: all goroutines are asleep - deadlock!
```

**Фикс:** запись из горутины, чтение в main (или наоборот):

```go
ch := make(chan int)
go func() { ch <- 1 }()
val := <-ch // разблокировка когда горутина запишет
```

Заметь: **WaitGroup не нужен**. Чтение из канала само блокирует main. Канал и синхронизирует, и передаёт данные.

### Небуферизованный vs буферизованный

| | Unbuffered | Buffered (N) |
|---|---|---|
| Запись | ждёт читателя | НЕ ждёт пока буфер не полон |
| Чтение | ждёт писателя | НЕ ждёт пока буфер не пуст |
| Зачем | строгая синхронизация «отдал → принял» | producer и consumer с разной скоростью |
| Аналогия | портал — из рук в руки | портал с полочкой на N предметов |

```go
ch := make(chan int, 1) // буфер на 1
ch <- 42                // НЕ блокирует
val := <-ch
```

### Таблица: nil vs закрытый канал

| Действие | Nil chan | Закрытый |
|----------|---------|----------|
| Чтение | блок навсегда | zero value, ok=false |
| Запись | блок навсегда | **panic** |
| Закрыть | panic | panic |

Nil-канал в `select` — способ «выключить» ветку.
