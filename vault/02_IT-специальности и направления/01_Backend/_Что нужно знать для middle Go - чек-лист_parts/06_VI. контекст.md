## VI. КОНТЕКСТ

### Junior
```go
func GetUser(id int) (*User, error) {
    return db.Query("SELECT ... WHERE id = ?", id)  // нет контекста
}

func handler(w http.ResponseWriter, r *http.Request) {
    rows, _ := db.Query(...)  // не использует r.Context()
}
```

### Middle
```go
func GetUser(ctx context.Context, id int) (*User, error) {
    return db.QueryContext(ctx, "SELECT ... WHERE id = ?", id)
}

func (s *Server) Handler(w http.ResponseWriter, r *http.Request) {
    user, err := s.userService.GetByID(r.Context(), userID)
    // graceful shutdown работает, отмена запроса работает
}
```

**Ключи:** Все внешние вызовы (DB, HTTP, gRPC) принимают `ctx`. Никогда `context.Background()` внутри запроса — только `r.Context()`. Понимаешь `context.WithTimeout`, `context.WithCancel`, `context.WithValue` (последний — только для request-scoped значений типа request_id).
