## XI. НАБЛЮДАЕМОСТЬ

- Структурированные логи (`slog` или `zerolog`/`zap`)
- Уровни: Debug / Info / Warn / Error
- `request_id` в каждом логе через context
- Метрики через `prometheus/client_golang`
- Трейсинг через OpenTelemetry
- Health-check эндпоинты (`/health`, `/ready`)
