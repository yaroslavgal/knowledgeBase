## II. СТРУКТУРА ПРОЕКТА

### Junior
```
/myproject
  main.go    # 1200 строк — всё в одном файле
  go.mod
```

### Middle
```
/cmd
  /api
    main.go             # ТОЛЬКО запуск сервера
/internal
  /handler              # HTTP-обработчики
  /service              # Бизнес-логика
  /repository           # Работа с БД
  /model                # Структуры данных
/pkg                    # Переиспользуемый код для других проектов
```

**Принцип:** handler не знает про БД. Service не знает про HTTP. Repository не знает про бизнес-логику. Общаются через интерфейсы.

**Standard Go Project Layout:** `/cmd`, `/internal`, `/pkg`. `/internal` — пакеты, которые нельзя импортировать извне модуля.
