## IX. HTTP

### Junior
```go
http.Post("https://api.example.com/users", "application/json", body)
// дефолтный клиент = БЕЗ ТАЙМАУТОВ — может висеть вечно
```

### Middle
```go
client := &http.Client{
    Timeout: 30 * time.Second,
    Transport: &http.Transport{
        MaxIdleConns:        100,
        MaxIdleConnsPerHost: 10,
        IdleConnTimeout:     90 * time.Second,
    },
}
req, err := http.NewRequestWithContext(ctx, http.MethodPost, url, body)
// + retry logic + circuit breaker
```

**Ключи:** Свой HTTP-клиент с таймаутами. `io.LimitReader` для ограничения тела ответа. Проверка статус-кода. Retry с экспоненциальной паузой. Понимаешь idempotency.
