## XIII. ЭКОСИСТЕМА БЭКЕНДА

Минимальный набор, который должен быть в активной памяти:

| Категория | Технологии |
|-----------|------------|
| БД | PostgreSQL (основа), Redis (кэш), ClickHouse (аналитика), MongoDB (опционально) |
| Очереди | Kafka (must), RabbitMQ или NATS |
| RPC | REST + gRPC (с protobuf) |
| Архитектура | Clean Architecture / Hexagonal, DDD-light |
| Паттерны | CQRS, Outbox, Saga (для микросервисов) |
| Балансировка | nginx, traefik |
| Linux | базовые команды, top/htop, journalctl, systemd |
