# Переход с Python / JS на Go за 2 недели

Если ты знаешь Python или JavaScript, ты уже знаешь 70% Go. Просто не подозреваешь об этом.

## Главный тезис

Большинство концепций Go — те же, что и в твоём языке, но под другим именем. Переход не «учить с нуля», а «перевести с одного языка на другой через аналогии».

2 недели — реалистичный срок для синтаксиса и базовых паттернов. Полное освоение продакшен-уровня — 2–3 месяца. Этот файл — про первый рывок.

---

## Кому подходит этот план

- Python-бэкендеру с 1–3 годами опыта (Django/FastAPI)
- JS/TS-фронтендеру с базой Node.js или просто хорошим JS
- Любому, кто понимает HTTP, REST, JSON, базы данных

Не подходит:
- Полному новичку без базы программирования
- Тем, кто не освоил собственный язык на уровне асинхронности и типов
