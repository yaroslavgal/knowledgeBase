## Чек-лист перед PR

- [ ] Все тесты проходят (`go test -race ./...`)
- [ ] Linter чист (`golangci-lint run`)
- [ ] Имя коммита по conventional (feat/fix/docs/chore/refactor/test)
- [ ] PR description: что сделал, зачем, ссылка на тикет
- [ ] Скриншоты (если UI / API изменения)
- [ ] Тесты добавлены / обновлены
- [ ] Нет debug-логов / `fmt.Println`
- [ ] Нет magic numbers — константы
- [ ] Errors wrapped (`fmt.Errorf("...: %w", err)`)
- [ ] Логирование структурированное (slog)
- [ ] Pointer receivers где нужна мутация
- [ ] Mutex с pointer receiver
- [ ] Графический shutdown реализован (для серверов)
- [ ] README обновлён
