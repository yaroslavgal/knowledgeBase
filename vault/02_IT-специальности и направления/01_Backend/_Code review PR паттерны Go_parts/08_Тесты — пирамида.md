## Тесты — пирамида

```
        ┌──────────┐
        │   E2E    │  ← 5%   (HTTP сервер + полный flow)
        └────┬─────┘
       ┌─────┴──────┐
       │ Integration│  ← 25%  (на storage с реальной БД)
       └─────┬──────┘
   ┌─────────┴──────────┐
   │      Unit          │  ← 70%  (на domain модели и утилиты)
   └────────────────────┘
```

### Test naming

```go
// ❌ Плохо
func TestUserCreate(t *testing.T) { ... }

// ✅ Хорошо
func TestUser_Create_ValidInput_ReturnsUser(t *testing.T) { ... }
func TestUser_Create_EmptyName_ReturnsError(t *testing.T) { ... }
```

### Test structure (AAA)

```go
func TestService_GetUser(t *testing.T) {
    // Arrange
    repo := mockRepo{user: &domain.User{ID: 1}}
    svc := NewService(repo)

    // Act
    user, err := svc.GetUser(1)

    // Assert
    require.NoError(t, err)
    require.Equal(t, 1, user.ID)
}
```
