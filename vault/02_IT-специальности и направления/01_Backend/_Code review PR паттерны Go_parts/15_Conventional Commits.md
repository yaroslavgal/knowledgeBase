## Conventional Commits

```
feat: add user authentication
fix: resolve race condition in cache
docs: update README
chore: bump dependencies
refactor: extract validation to separate package
test: add integration tests for user service
```

Сайт: [conventionalcommits.org](https://conventionalcommits.org)

Преимущества: автоматическая генерация changelog, понятная история, semver автоматический.
