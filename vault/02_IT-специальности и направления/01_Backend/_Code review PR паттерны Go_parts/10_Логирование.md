## Логирование

### ❌ Антипаттерн

```go
log.Println("user created:", user)  // ← никаких уровней, формат не структурированный
```

### ✅ Правильно (slog с Go 1.21+)

```go
import "log/slog"

slog.Info("user created",
    "user_id", user.ID,
    "email", user.Email,
)

slog.Error("failed to fetch user",
    "user_id", id,
    "error", err,
)
```

**Уровни:** Debug (детали разработки) / Info (события) / Warn (нештатное) / Error (требует внимания).
