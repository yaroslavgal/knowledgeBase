## Структура проекта

### ❌ Антипаттерн: всё в `main.go`

```
.
├── main.go        ← 2000 строк
└── go.mod
```

### ✅ Правильно: idiomatic structure

```
.
├── cmd/
│   └── api/
│       └── main.go        ← entry point
├── internal/              ← приватный код
│   ├── domain/            ← бизнес-сущности
│   ├── usecase/           ← бизнес-логика
│   ├── handler/           ← HTTP/gRPC handlers
│   ├── repository/        ← БД
│   └── infrastructure/    ← конфиг, логгер, метрики
├── pkg/                   ← публичные пакеты (если есть)
├── deployments/           ← Dockerfile, helm
├── scripts/               ← миграции, генераторы
├── go.mod
└── README.md
```

**Не использовать монорепо-структуру если у тебя один сервис.**
