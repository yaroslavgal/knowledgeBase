## Главный тезис

Выбираешь не язык — выбираешь направление работы. Язык — инструмент, направление определяет твою карьеру на 3–5 лет вперёд.

Питонист и фронтендер — две разные профессии, даже если оба «бэкендеры». Учитывай это до того, как тратишь полгода на курсы.

## Frontend (JS/TS + React)

**Кому подходит:** визуалам, тем кто кайфует от мгновенного результата, тем кто уже знает HTML/CSS, перфекционистам.

**Плюсы:**
- Виден результат — написал, открыл браузер, кайф
- Универсальность — JS работает в браузере, Node.js, мобиле (RN), десктопе (Electron)
- Самое большое комьюнити, любая проблема уже решена
- 60–70% всех frontend-вакансий — React + TypeScript + Next.js, стек предсказуем

**Минусы:**
- «Фреймворк-усталость» — экосистема меняется каждые 2 года
- Зарплаты джуна ниже, чем в Go-бэке
- AI хорошо генерирует UI-компоненты — джуновская работа исчезает быстрее всего

**Когда брать:** если уже что-то умеешь во фронте, если работаешь в команде, где можно вырасти в fullstack.

**Когда не брать с нуля в 2026:** если нет HTML/CSS-опыта и нет конкретной мотивации именно к интерфейсам — стартовать здесь сейчас не лучшая идея.

---

## Python (FastAPI / Django)

**Кому подходит:** универсалам, тем кто хочет потом уйти в Data Science / ML, любителям читаемого кода.

**Плюсы:**
- Самый простой синтаксис для новичка — читается как английский
- Огромная экосистема — любая задача уже решена через библиотеку
- Один язык открывает три направления: web (FastAPI/Django), DS/ML, скрипты/автоматизация
- Django — мощнейший фреймворк «из коробки»

**Минусы:**
- ОЧЕНЬ высокая конкуренция среди джунов — каждые курсы рекомендуют Python
- 100–200 резюме на одну джун-вакансию
- Медленный (GIL ограничивает многопоточность)
- В высоконагруженных бэкендах теряет позиции Go и Java

**Когда брать:** если цель — DS/ML/AI Engineering, если готов учить Python + математику + специализацию параллельно.

**Когда не брать как голый «Python web»:** в 2026 это самая забитая ниша. Идти сюда без связки с ML — значит идти в самую конкурентную часть рынка.

## Go (Golang)

**Кому подходит:** бэкендерам, тем кто хочет максимальный спрос/предложение, тем кто переходит с другого языка с базой бэкенда.

**Плюсы:**
- Дефицит специалистов — берут даже без Go-опыта, если есть другой язык
- Зарплаты выше — средняя по рынку 340к
- Простой язык (25 ключевых слов) — за 2 недели можно начать писать
- Конкурентность из коробки (горутины, каналы) — идеально для микросервисов
- Один бинарь — деплой простой, без зависимостей
- Используется в Авито, Озон, Тинькофф, ВК, Яндексе

**Минусы:**
- Чистых джун-вакансий мало — обычно ищут переходящих с другого стека
- Меньше библиотек, чем в Python/JS — иногда приходится допиливать пакеты с GitHub
- Меньше туториалов и контента для новичков
- Многословная обработка ошибок (`if err != nil` на каждом шагу)

**Когда брать как первый язык:** только если есть наставник или ты дисциплинированный самоучка с базой программирования.

**Когда брать как второй язык (рекомендация):** если ты фронтендер, питонист, джавист — переход даёт +30–50% к ЗП и 5–10x вакансий.

---

## Алгоритм выбора за 3 шага

1. **Цель — деньги быстро?** Go (если есть база программирования) или Python+ML (если готов учить долго).
2. **Цель — войти за 4–6 месяцев с нуля без бэкграунда?** Frontend или QA Manual → потом перекат.
3. **Цель — стабильность энтерпрайза?** Java/Kotlin Backend.

«Учи что нравится» — плохой совет, если не понимаешь, что это значит. Лучший: попробуй каждое направление по 1–2 недели. После Tour of Go, FastAPI tutorial и React tutorial — выбор станет очевиден.

## Чек-лист выбора

| Вопрос | Ответ → стек |
|---|---|
| У меня уже есть опыт во фронте | Fullstack или перекат в Go |
| Я люблю математику и хочу в ML | Python + DS-трек |
| Я хочу деньги и есть база программирования | Go |
| Я хочу войти максимально быстро без бэкграунда | QA Manual → автоматизация |
| Я хочу стабильность и большие компании | Java/Kotlin |
| Мне важен мгновенный визуальный результат | Frontend |
| Я просто читаю советы и не выбираю год | Любой, но НАЧНИ |
