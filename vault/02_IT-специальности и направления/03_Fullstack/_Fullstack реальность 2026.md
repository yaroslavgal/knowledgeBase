# Fullstack — реальность 2026

«Fullstack одинаково хорошо знает фронт и бэк» — это маркетинг. По факту fullstack — это **бэкендер с продвинутым фронтом** или **фронтендер с базой бэка**, перевес на одну сторону всегда есть. Чисто симметричных fullstack-инженеров на рынке мало, и в основном это сеньоры с 5+ лет в обоих стеках.

## Реальность 2026

**Кому нужен fullstack:**
- Стартапы 5–30 человек — один человек закрывает фичу end-to-end.
- Mid-size компании на узких командах — когда отдельный фронт-разработчик нерентабелен.
- Аутсорс/агентства — клиенту проще платить одному человеку.

**Кому НЕ нужен fullstack:**
- Bigtech (Яндекс, Сбер, Авито, Озон) — там разделение фронт/бэк строгое, fullstack в вакансиях встречается редко и на средне-низких ставках.
- Продуктовые компании 100+ человек — специализация даёт глубину.

**Зарплаты в Москве 2026:**
- Стажёр: 0–50к (символическая).
- Junior fullstack (вакансий мало): 70–140к.
- Middle: 180–350к.
- Senior: 350–600к.
- Lead: 500–800к+.

**Сравнение со специализированными грейдами:**
- Middle fullstack ≈ middle frontend (150–300к) или чуть выше.
- Middle fullstack ниже middle Go (200–400к).
- На стажёра/junior fullstack — конкуренция выше, чем на узкие специальности (50+ резюме на вакансию).

## Стек 2026

**Основной стек fullstack для входа:**
- **TypeScript + Node.js + NestJS + React/Next.js** — самый популярный, один язык на обе стороны, найм в стартапах.
- **Python (FastAPI/Django) + React** — тоже работает, чаще в data-heavy продуктах.
- **Go + React/Next.js** — реже, но платят выше за счёт Go.

**Что должно быть в наборе:**

Backend:
- Один язык (Node.js / Python / Go) — синтаксис, async, стандартная библиотека.
- HTTP, REST, JSON, базовая API-разработка.
- PostgreSQL — индексы, транзакции, JOIN, ORM (Prisma / SQLAlchemy / GORM).
- Authentication: JWT, session-based, OAuth basics.
- Docker, docker-compose.
- Базовое понимание очередей (Redis, RabbitMQ).

Frontend:
- React или Vue (один из двух).
- TypeScript — обязателен в 2026.
- State management: Redux Toolkit / Zustand / Pinia.
- Next.js или Nuxt (SSR, SSG понимать).
- CSS: Flexbox, Grid, Tailwind или CSS-in-JS.
- HTTP-клиент (fetch / axios), error handling.

Cross-cutting:
- Git, pull requests, code review.
- Тесты: Jest/Vitest на фронте, минимум unit-тесты на бэке.
- CI/CD basics: GitHub Actions.
- Деплой: Vercel/Netlify (фронт), Railway/Render/Fly.io (бэк), или Docker на VPS.

## Когда брать fullstack как стратегию входа

**Бери fullstack, если:**
- У тебя уже есть HTML/CSS/JS-опыт и не хочешь идти в чистый бэк.
- Цель — стартап (валютный или РФ).
- Готов 6–9 месяцев на серьёзный вход (вместо 4–6 на узкий стек).
- Любишь видеть фичу от UI до базы.

**НЕ бери fullstack, если:**
- Только начинаешь программировать (распыляешься, не достигаешь глубины ни в чём).
- Цель — Bigtech (нужна специализация).
- Хочешь максимальную ставку (Go-бэк или senior frontend дают больше).

## Реалистичный путь fullstack-входа

Канон обучения — через практику с AI. Никаких лекций «впрок», AI как ментор 24/7 (намёк → декомпозиция → объяснение, **никогда готовый код**). См. [[01_Образование и обучение/06_Менторы и AI-обучение/_Философия обучения через практику|Философия обучения через практику]].

**Месяц 1–2: HTML/CSS + JavaScript базы**
- The Odin Project / freeCodeCamp.
- 10–15 простых страниц вручную (вёрстка из Figma).
- Чистый JS без фреймворков — DOM, fetch, события.

**Месяц 2–4: React + TypeScript + базовый Node**
- React: hooks, state, context. Один пет-проект (todo, погода, чат).
- TypeScript: типы, generics, утилитарные.
- Node.js + Express/Nest: один REST API c CRUD + auth.
- PostgreSQL + ORM (Prisma).

**Месяц 4–6: продакшен-уровень**
- Объединяешь фронт и бэк в один проект — fullstack-приложение с auth, БД, деплоем.
- Docker, GitHub Actions для CI.
- Деплой на Vercel + Railway/Render.
- 1–2 пет-проекта продакшен-уровня.

**Месяц 6–9: подготовка к собесу + поиск middle-оффера**
- Банк вопросов по обоим стекам (бэк + фронт).
- Лайвкодинг — типовые задачи fullstack-собеса: API endpoint с валидацией, React-компонент с состоянием, простой CRUD. LeetCode-гринд под fullstack-middle бесполезен — там почти не бывает алгоритмической секции, кроме bigtech.
- System Design базовый (URL shortener, лента новостей).
- Параллельный поиск 15–20 компаний.

## Антипаттерны

❌ **Распыление с первого дня.** Учишь React + Vue + Angular + Next + Nuxt + Express + Nest + Django одновременно. Не выучишь ничего.
**Решение:** один стек. Например: TypeScript + Next.js + NestJS + Prisma + PostgreSQL. Закрепляй до собесного уровня.

❌ **«Знаю всё на mid-уровне».** На собесе спрашивают по **одной** теме глубоко (горутины, или React reconciliation, или индексы БД). Поверхностное знание не даёт пройти.
**Решение:** иметь одну сторону (фронт или бэк) глубже остальной — это нормально, в этом сила fullstack.

❌ **Идти в Bigtech на fullstack-вакансию.** Их там почти нет, конкуренция запредельная, ставки ниже специализированных.
**Решение:** в Bigtech идёшь как frontend или backend. В стартапы — как fullstack.

❌ **Игнорировать DevOps-минимум.** Fullstack без Docker и CI/CD — не fullstack.
**Решение:** Docker + GitHub Actions + один деплой-таргет (Vercel или VPS) с первого пет-проекта.

## Чек-лист готовности к middle-собесу fullstack

- [ ] React/Vue + TypeScript: понимаю reconciliation, hooks, performance optimization.
- [ ] Один backend-фреймворк (Nest / FastAPI / Express+TS) до уровня «могу спроектировать REST API с auth».
- [ ] PostgreSQL: индексы, транзакции, JOIN, EXPLAIN ANALYZE.
- [ ] Auth: JWT vs sessions, OAuth flow, refresh tokens.
- [ ] Docker, docker-compose — поднял локально fullstack-приложение.
- [ ] CI/CD: GitHub Actions с тестами и деплоем.
- [ ] Один деплой в продакшене (Vercel/Netlify + Railway/Render/Fly).
- [ ] Тесты: unit + integration хотя бы на бэке.
- [ ] System Design базовый: URL shortener, чат, лента новостей.
- [ ] 1–2 fullstack пет-проекта с деплоем (живой URL) — это работает, в отличие от ссылки на GitHub. На сам GitHub-профиль почти никто не зайдёт, важен факт работающего продукта.
