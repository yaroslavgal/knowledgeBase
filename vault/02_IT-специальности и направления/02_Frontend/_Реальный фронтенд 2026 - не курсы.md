# Реальный фронтенд 2026 — не то, чему учат на курсах

## Кто реально сидит на фронт-вакансиях 2026

**Junior-вакансий чистого фронта почти нет.** Если есть — на ней 1000 откликов за день.

---

## Стек, за который реально платят в 2026

### React + TypeScript + Next.js — 60–70% всех вакансий

Без TypeScript — даже не смотрят. Не "знание JS" — а ежедневная работа с типами, generics, conditional types, mapped types.

**Next.js стал дефолтом** — Server Components, App Router, Server Actions. Не "React + что-нибудь для роутинга". Конкретно Next 14+.

### Vue 3 + TypeScript + Nuxt 3 — 20–25% вакансий

Меньше вакансий, меньше конкуренции. Зарплаты сопоставимы. Composition API + script setup — обязательно.

### Angular — корпоративный сектор (банки, телеком)

10% рынка, но платят выше среднего. Сложнее найти, легче пройти (меньше конкуренция). Кто там — годами сидит и не уходит.

### Svelte / Solid / Qwik — почти 0%

Хайп в Twitter ≠ вакансии на HH. Учить как побочный навык, ставить в основной стек — нельзя.

## За что палят джуна-фронта на собесе 2026

### 1. Не знаешь, как работает event loop в браузере

Не "что такое промис" — а конкретно: микротаски vs макротаски, в каком порядке выполнится `setTimeout(fn, 0)` vs `Promise.resolve().then(fn)` vs `queueMicrotask(fn)` vs `requestAnimationFrame(fn)`.

### 2. Не понимаешь, что такое замыкание на практике

Не определение из учебника. А: дать кусок кода с `useEffect` и состоянием — сказать, какое будет выведено и почему. Stale closure — больная тема React-собесов.

### 3. Никогда не оптимизировал рендер

`React.memo`, `useMemo`, `useCallback` — это знают все. А вот когда они **не работают** (если пропсы — объекты/функции без правильных deps) — это уже мидл-уровень.

### 4. Ничего не знаешь про CLS/LCP/FCP/TTI

Core Web Vitals. Lighthouse. Bundle splitting. Tree shaking. Если ты не оптимизировал ни один проект под 90+ Lighthouse — на хорошие вакансии не пойдёшь.

### 5. CSS — это "нечеловеческое"

`flexbox` и `grid` — обязательно. CSS-переменные. Specificity. Z-index stacking context. На собесе спросят — ты должен ответить за 30 секунд, не гуглить.

### 6. Никогда не писал тесты

Jest + React Testing Library — минимум. Storybook — плюс. Cypress / Playwright (e2e) — плюс. Тесты должны быть в твоём опыте на собесе (рассказать, что писал, как настраивал) — на GitHub-профиль никто не полезет, это миф.

## Что реально делает фронтендер на работе (а не на курсе)

| Курс учит | Реальная работа |
|-----------|-----------------|
| Создать TODO-app с нуля | Найти баг в чужой кодовой базе на 50К строк |
| Отрисовать форму | Интегрировать форму с 6 разными API, обработать race condition |
| `useState` для счётчика | Управление сложным состоянием через Zustand/Redux Toolkit/TanStack Query |
| Адаптив через media query | Адаптив + тёмная тема + a11y + RTL для арабского рынка |
| Загрузить картинку | Lazy loading, `<picture>`, AVIF/WebP, CDN, оптимизация LCP |
| `fetch` с `.then()` | Обработка отмены запроса при размонтировании, retry logic, error boundaries |
| 1 раз сделать форму | Десять раз отрефакторить ту же форму, потому что бизнес 10 раз менял требования |

## AI и фронтенд — кого заменят первым

Claude / Cursor / v0 / Bolt — реально собирают лендинги за минуту. Это пугает.

Реальность:
- **Простые лендинги, статичные сайты** — да, AI делает за секунды. Эта работа уйдёт.
- **Сложные SPA с состоянием, интеграциями, оптимизацией** — AI помогает, но не заменяет
- **Дизайн-системы, accessibility, performance** — AI бесполезен без человека-эксперта

Что делать:
1. **Не учи "просто React"** — этого недостаточно
2. **Углубляйся** — performance, a11y, тесты, архитектура состояния
3. **Используй AI как инструмент** — кто будет писать на React + AI быстрее всех, тот выживет

## Карьерные пути из фронта 2026

### Путь 1: Глубже в фронт (узкая специализация)

Performance-инженер фронта. UI-инженер дизайн-системы. Анимация (GSAP, Framer Motion). WebGL/Three.js. Платят выше среднего, конкуренции почти нет.

### Путь 2: Фулстек (мост к бэку)

React + Node.js / + Go / + Python. Самый востребованный профиль 2026 — компании ищут именно фулстеков. Зарплаты те же, что у фронтендера, но вакансий в 3 раза больше.

### Путь 3: Перекат в Go-бэкенд

См. отдельный файл `_Перекат с фронтенда в Go.md`. Реалистичный срок — 3–6 месяцев. Прирост ЗП — +30–40%.

### Путь 4: Менеджмент / тимлид / PM

Если ты 5+ лет во фронте и устал кодить — путь в управление. Зная фронт изнутри, ты понимаешь, что просить от команды. Сильный профиль для менеджера фронт-команды.

## Когда фронт — твоё

Если все пункты — да:
- Кайф от визуального результата (открыл — увидел)
- Не бесит работа с дизайнером и продактом (а будет много)
- Готов быстро менять стек каждые 2–3 года
- Готов конкурировать с большой толпой кандидатов

Если хотя бы 2 — нет, рассмотри Go или Fullstack.
