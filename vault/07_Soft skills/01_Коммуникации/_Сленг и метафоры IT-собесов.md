# Сленг, метафоры и язык IT-собесов

Словарь рабочей лексики для тех, кто готовится к собесам в IT (Go Backend / Frontend, рынок РФ + валютная удалёнка).

## Базовый сленг ниши

| Слово | Что значит |
|---|---|
| Собес | Собеседование |
| Оффер | Предложение о работе с ЗП и условиями |
| Стек | Набор технологий, на которых работаешь |
| Удалёнка | Удалённая работа, full-remote |
| Джун / junior | Начинающий разработчик (0–2 года) |
| Мидл / middle | Самостоятельный (2–5 лет) |
| Сеньор / senior | Эксперт (5+ лет) |
| ATS | Applicant Tracking System — робот, который сканирует резюме |
| HR | Рекрутер |
| Теха | Технический собес |
| Мок-собес | Тренировочное собеседование |
| Пет-проект | Личный проект |
| System Design | Собеседование по проектированию систем |
| Live-coding | Решение задачи кодом во время собеса |
| Фронт / бэк | Frontend / Backend |
| Легенда | Подготовленная история твоего опыта |
| Накрутка | Преувеличение опыта в резюме |
| Take-home / домашка | Тестовое задание дома, потом защита |
| Деклайнят | Отказывают |
| Поинты | Очки, по которым оценивают на собесе |
| Интурьер | Интервьюер (сленг) |
| ИИшка | AI-помощник (ChatGPT, Claude и т.д.) |

## Go-специфика

- **Горутина** — лёгкий поток в Go
- **Канал** — примитив для синхронизации горутин
- **Контекст** — механизм для отмены и передачи дедлайнов
- **GMP** — модель планирования горутин (Goroutine, Machine, Processor)

## Метафоры из контента (рабочие, переиспользуемые)

### Про природу собесов
- **«Собесы = dating / брачные танцы»** — обе стороны притворяются, оценивают, торгуются
- **«Собеседование = игра в сапёра»** — не знаешь, на каком вопросе подорвёшься
- **«ChatGPT vs Claude-платформа = компас vs Google Maps»** — оба про навигацию, но разной зрелости

### Про систему найма
- **«HR = робот за 50к, который решает судьбу позиции за 300к»** — асимметрия квалификации
- **«HH в ккал превратился»** — про пустые отклики и низкое качество
- **«Помойка / чёрная дыра»** — про job-платформы, куда уходят резюме

### Про обучение
- **«Сначала 2 года учишься, потом 2 года ищешь»** — про неработающий «честный путь»
- **«Ментор с 100 учениками = врач с 100 пациентами в день»** — про потерю глубины при масштабе
- **«Отправил код в GitLab → ждёшь 2 дня vs AI подчёркивает ошибку за секунду»** — про скорость обратной связи
- **«Горутина из учебника vs горутина из опыта»** — теория vs практика, разница звучания на собесе
- **«ИИшка решит задачу за тебя, но объяснить — это другой левел»** — про границы AI-помощников

### Про переговоры
- **«Хер без соли vs чёрную икру»** — про крайности офферов
- **«Творчески работать с фактами»** — про легенду

## Триггерные темы (вызывают дебаты в комментариях)

1. Накрутка опыта — этично или нет
2. Junior vs Middle — реальна ли разница
3. Курсы vs менторство vs AI-менторство vs самообучение
4. Frontend vs Backend (Go) — что выгоднее
5. Возраст в IT — поздно или не поздно
6. Рынок мёртв или жив
7. Удалёнка vs офис
8. Синдром самозванца — реальность или отмазка
9. AI-помощники на собесах — спасут или подставят?
10. Теория vs практика — что реально проверяют?
11. AI заменит менторов?
12. 120 часов до рынка — реально или развод?
