# Claude Code Adapter

Claude Code loads `CLAUDE.md`, `.claude/settings.json`, `.claude/skills`, `.claude/agents`, and `.mcp.json`.

`AGENTS.md` and `CLAUDE.md` are intentionally identical.

Claude Code does not install slash-command files here; use the same scenarios in natural language or name the skill.

Use skills automatically:

- setup -> `onboard-vault`
- create note -> `create-note`
- improve note -> `improve-note`
- structure -> `organize-vault`
- links -> `find-links`
- diagrams -> `visual-diagram`
- git/github -> `setup-git`
- check -> `check-vault`
- lesson -> `save-lesson`
- reflection -> `update-rules`
