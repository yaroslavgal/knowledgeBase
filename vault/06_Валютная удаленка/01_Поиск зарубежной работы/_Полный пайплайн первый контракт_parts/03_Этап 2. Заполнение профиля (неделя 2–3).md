## Этап 2. Заполнение профиля (неделя 2–3)

### Чек-лист
- [ ] Язык EN primary, RU удалён
- [ ] Профессиональное фото (или хотя бы стоковое нейтральное)
- [ ] Тематическая обложка (код / город / технологии)
- [ ] Локация: Berlin / London / Warsaw / Amsterdam (НЕ Россия)
- [ ] Headline по формуле: главная технология + grade + 2–3 доп. скилла
- [ ] About с контактом Telegram/WhatsApp + конкретные достижения
- [ ] Experience: каждая позиция с метриками, главная технология везде
- [ ] Skills: топ-3 максимально релевантные
- [ ] LinkedIn Skill Assessment по топ-3 скиллам пройден
- [ ] Featured Section: загружено PDF-резюме на 2 страницы
- [ ] Certifications с media (если есть)
- [ ] 2–3 Recommendations попрошены

См. подробно: `_LinkedIn_заполнение_профиля.md`
