## Этап 1. Технический setup (неделя 1)

### Чек-лист
- [ ] Резидентский прокси нужной страны (~$4–8/мес)
- [ ] @gmail.com почта
- [ ] eSIM Airalo / Holafly (~€10–15)
- [ ] Браузер с отключённым WebRTC, timezone EU
- [ ] Антидетект (AdsPower / Dolphin Anty) если планируешь мультиакки
- [ ] Проверка fraud_score IP на ipqs.com (близок к 0)
- [ ] Создан свежий Google-аккаунт с произвольным именем
- [ ] LinkedIn зарегистрирован через Google auth с европейского IP
- [ ] 2–4 дня просто листать ленту, ничего не делать
- [ ] Сменить имя на своё

### Бюджет: ~$100 единоразово + $30/мес
