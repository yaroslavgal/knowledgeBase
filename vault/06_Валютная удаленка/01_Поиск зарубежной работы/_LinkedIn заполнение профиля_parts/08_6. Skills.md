## 6. Skills

### Что добавлять

- **Основные языки**: Go, Python, Java + весь твой стек
- **Инфраструктура**: Docker, Kubernetes, Terraform, AWS, GCP, Azure
- **Паттерны**: Design Patterns, Concurrency Patterns, SDLC, Microservices, gRPC
- **Инструменты**: Git, REST, GraphQL, Kafka, Redis, PostgreSQL
- **Методологии**: Agile, Scrum, Kanban — HR-боты их ищут

### Порядок важен

- Главный скилл — **первым** (LinkedIn даёт перетаскивать)
- **Первые 3 скилла видны без скролла** — сделай их самыми релевантными (Go, Kubernetes, AWS, а не Git)

### Buzzwords-источник

`easyoffer.ru/analytic/golang_developer` — список ключевых слов по специальности (есть для разных стеков).

### LinkedIn Skill Assessment (15 вопросов)

- Дают значок «certified»
- **Реально влияют на поисковый ранг профиля** (проверено)
- Проходи обязательно по топ-3 скиллам
- Endorsements от случайных людей не сильно влияют, **тесты — влияют**
