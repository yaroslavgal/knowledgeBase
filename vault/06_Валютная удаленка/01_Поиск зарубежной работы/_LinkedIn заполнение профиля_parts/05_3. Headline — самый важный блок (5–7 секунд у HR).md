## 3. Headline — самый важный блок (5–7 секунд у HR)

### Формула

```
[Основной язык] [Grade] | [Доп. скилл 1] | [Доп. скилл 2] | [N years]
```

### Реальные примеры (работают):

```
Principal Go Engineer | Kubernetes | AWS | Microservices
Senior Java Backend Developer | Java Software Engineer | 5 years FinTech
Senior Golang Developer | PostgreSQL | Redis | Kafka | AWS
Golang Blockchain Engineer | DeFi | Smart Contracts | Web3
```

### Правила

- Главная технология — **в самом начале и везде**
- Можно **дублировать** через `|`: «Senior Python Developer | Senior Software Engineer | Python Expert»
- **Перед публикацией**: поищи свой headline на LinkedIn Jobs. Нет вакансий по нему → меняй на самую популярную формулировку
- Используй каноническое название роли («Senior Product Analyst», а не «Growth Analytics Specialist»)

### Что НЕ писать

- ❌ «Looking for opportunities» — никакой конкретики
- ❌ «Full-Stack Developer» без указания языков — на западном рынке плохо продаётся, нужно затачивать под стек
- ❌ Смешивать роли: «Product Analyst / Data Engineer / PM» — выбери ОДНО направление
- ❌ Russia / Uzbekistan — убрать полностью
- ❌ Шуточные тайтлы вроде «23 y.o., dead inside, depressed, Senior Android Developer» — забавно, убивает поиск
