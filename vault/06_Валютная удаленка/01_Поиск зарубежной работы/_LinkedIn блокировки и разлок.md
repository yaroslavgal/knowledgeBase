# LinkedIn — блокировки и алгоритм разблокировки

> «Снятие блокировки на LinkedIn — это вообще отдельная боль. У всех, кто только-только завёл аккаунт, постоянно блочат.»

## Масштаб проблемы

Участники чатов АйТи Красавчик разблокировали аккаунты **по 4–5 раз** — это нормально, не сдавайся. У одного «3 раза банили и 3 раза разбанивали».

---

## Причины блокировки

- Новый аккаунт + много инвайтов сразу
- VPN/прокси с высоким fraud score
- Несовпадение геолокации (IP vs номер vs локация в профиле)
- Смена ФИО после регистрации
- Подтверждение компании, в которой ты не работаешь
- Массовые одинаковые сообщения при коннекте
- Посты со спам-словами/ссылками

---

## Как определить shadow ban (не явный блок, но видимости нет)

- Опубликуй пост — если за неделю **<20–30 просмотров** → shadow ban
- Попроси знакомого с другого акка найти тебя в поиске по имени
- Кнопка «Repost» пропала → признак shadow ban
- Все инвайты висят в pending по неделям

При shadow ban нужно поменять поведение, не плодить активность ещё больше — переждать 2–4 недели.

## Алгоритм разблокировки

### Шаг 1: Верификация через загранпаспорт (face recognition)

- Только через мобильное приложение
- Загранпаспорт РФ — работает
- Внутренний паспорт РФ — иногда работает
- Face recognition — крутишь головой в стороны
- Альтернативный канал верификации: **сервис Persona** (отдельный инструмент LinkedIn)

### Шаг 2: Если «вы уже отправили запрос»

- Жди 3–7 дней и попробуй снова
- Трюк: «Forgot password» → введи **другой email** → напиши что хочешь общаться через основной → они свяжутся через основной

### Шаг 3: Формы поддержки (по очереди)

| URL | Что | Что писать |
|---|---|---|
| `linkedin.com/help/linkedin/ask/ppq` | Общая форма | **Откровенно**, VPN не отрицать, говорить что корпоративный VPN |
| `linkedin.com/help/linkedin/ask/TS-RHA` | Восстановление аккаунта | Подтверждение работы по карьере |
| `linkedin.com/help/linkedin/ask/TS-F-APPEAL` | Обжалование блокировки | Альтернативный канал |

### Шаг 4: Если отказали — не финал

- Отказ ≠ невозможность разблокировки
- Поменяй поведение (проанализируй что делал до блока)
- Повтори через **2–4 недели**
- Многие восстановили акк только с **3–4 попытки**

## Amnezia VPN — особый случай

Несколько участников чата сообщают: **Amnezia VPN с русским сервером** как точкой выхода помог снять рестрикции.

Гипотеза: LinkedIn видит «чистый» российский IP без признаков прокси, и при наличии других косвенных признаков «обычного пользователя» снимает подозрения. Не системное решение, но иногда срабатывает там где остальные методы не работают.

## Anti-detect браузеры для мультиакков

- **Dolphin Anty** — рабочий, проверен
- **AdsPower** — рабочий, проверен
- Один браузерный профиль = один LinkedIn аккаунт
- Cookies, fingerprint, шрифты, WebGL — всё разное

При попытке зайти под двумя акками с одного браузера — гарантированный fingerprint match → блок обоих.

## Если контракт требует быть в конкретной стране

Кейс: «Контракт с UK-агентством, должен находиться в Сербии, сам в Москве».

**Как детектируют реальное местоположение:**
- **RTT (Round Trip Time):** пакеты Москва → DE-сервер ~60ms, DE → DE ~10ms. Параноидальный работодатель может запустить тест.
  - *Алиби:* «На мобильном интернете / плохой канал» — не вызывает прямой проверки
- **WPS (Wi-Fi Positioning):** если смартфон с GPS подключался к твоему Wi-Fi и слил телеметрию в Google → можно сопоставить MAC роутера
- **«Без VPN зашёл хоть раз»** — Slack/Teams/браузер запомнили IP

**Практический вывод (Aleksey Bondarev):**
> «Если у них цель спалить — спалят. Если просто общие меры подстраховки — глубоко проверять не будут. Юр. лицо не РФ, IP не РФ — этого достаточно в большинстве случаев.»

**Минимальный сетап для «строгого» работодателя:**
- VPN на уровне роутера (не клиента) — все устройства идут через него
- Telegram, Slack, Teams — только через VPN (никогда без)
- Никогда не заходил в корпоративные сервисы без VPN

## Подводные камни

- Бывали кейсы когда просили показать «вид из окна» / «вид с улицы» для подтверждения локации
- ВНЖ спрашивают редко, но иногда (АйТи Красавчик имеет ВНЖ Азербайджана — иногда показывает)
- Паспорт в большинстве случаев не спрашивают вообще

## Чек-лист разблокировки

1. [ ] Сначала — мобильная верификация через загранпаспорт + face recognition
2. [ ] Не получилось → 3–7 дней пауза
3. [ ] Через «Forgot password» с другим email
4. [ ] Параллельно подаём 3 формы поддержки (TS-RHA, ppq, TS-F-APPEAL)
5. [ ] В тексте: VPN не отрицать, говорить «корпоративный»
6. [ ] Если отказали — пауза 2–4 недели
7. [ ] Поменял поведение → повтор
8. [ ] Если 4-я попытка не сработала → новый акк (старый можно держать «спящим»)
