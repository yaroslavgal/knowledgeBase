# Счета в Армении, Грузии, ОАЭ

Популярные банки: Ардшинбанк, Ameria Bank, Evocabank, IDBank, ACBA Bank.

## Армения

**Популярные банки:** Ардшинбанк, Ameria Bank, Evocabank, IDBank, ACBA Bank.

**Открытие:** Очно — стандартно, несколько дней. Удалённо — по доверенности через помогаторов, срок до 2 месяцев. Некоторые помогаторы запрашивают оффер-письмо от работодателя для открытия счёта ИП.

**Что нужно для счёта физика:** Загранпаспорт. Иногда — подтверждение источника дохода.

**Что нужно для счёта ИП:** Свидетельство о регистрации ИП. Ардшинбанк — без прописки в Армении по отзывам.

**Переводы в РФ:** Работают в некоторые российские банки. Не все принимают из Армении — проверяй до открытия. Некоторые банки РФ открыли прокладки для приёма из Армении.

**Автообмен с РФ:** Есть. CRS — налоговая РФ видит армянские счета. Нужно уведомлять ФНС об открытии в течение месяца.

**Нюансы 2026:** С нового года введён налог на обязательное медицинское страхование для ИП. Социальный взнос 5000 драмов в месяц.

## Грузия

**Популярные банки:** TBC Bank, Bank of Georgia (Solo — премиум), Liberty Bank.

**Открытие очно:** За один день. В юстицию за ИП — на входе стоят помогаторы, берут 100 лари, делают всё. Через несколько дней забираешь выписку, банковскую карту, покупаешь симку Magti.

**Открытие удалённо:** Через Espero — только Bank of Georgia. Через Register in Georgia — очно, вызывают доверие по отзывам.

**Переводы в РФ:** Прямых нет. Только через крипту P2P или через другую страну.

**Автообмен с РФ:** Официально нет. Но по опыту из чата — счёт в Грузии может появиться в приложении налоговой РФ. Либо Армения передала данные, либо Грузия — через другие каналы. Не паникуй, это не означает автоматических проблем.

**Риск блокировки:** Банки блокируют за P2P-крипто операции. Позвонят, спросят экономический смысл — и не дожидаясь ответа заблокируют. Используй отдельную карту для крипто.

## ОАЭ

Счёт физика — нужен ВНЖ или резидентская карта. Без этого сложно.

ООО в ОАЭ — от $5000 на открытие. 0% налог. Для сумм $100k+ в год — имеет смысл. Для старта — нецелесообразно.
