## Схема 1: Deel + крипта (0% де-факто, серая)

```
Компания → Deel → USDT/USDC → P2P → рубли (или хранение в крипте)
```

| Параметр | Значение |
|---|---|
| Ставка налога | **0% де-факто** |
| Прозрачность | Серая (формально нарушение — доход в крипте без декларирования) |
| Сложность | Низкая |
| Риски | Блокировка карты для P2P, проблемы с ФНС если массово, возможные санкции |

**Для кого:** небольшие суммы (до $20–30K/год), высокая толерантность к риску.
