## Чек-лист «Что выбрать»

**Открой Самозанятость, если:**
- [ ] Доход <200к/мес
- [ ] Не работаешь и не работал последние 2 года в компании, которая будет клиентом
- [ ] Нужен минимум бюрократии
- [ ] Нет ИП в данный момент

**Открой ИП на УСН 6%, если:**
- [ ] Доход >100к/мес стабильно
- [ ] Хочешь свободу выбора клиентов
- [ ] Планируешь рост >2.4М/год
- [ ] Нужен пенсионный стаж
- [ ] Готов к лёгкой бухгалтерии

**Совмести (если возможно):**
- ИП для основного второго потока + НПД для разовых проектов
