## Краткое сравнение

| Параметр | Самозанятость (НПД) | ИП на УСН 6% |
|----------|---------------------|--------------|
| Налог | 4% (физ) / 6% (юр) | 6% от дохода |
| Лимит дохода в год | 2.4М ₽ | 200М ₽ (УСН) |
| Можно ли с компанией-бывшим работодателем | Только через 2 года после увольнения | Можно сразу |
| Социальные взносы | 0 (добровольно) | ~50к/год обязательные |
| Бухгалтер нужен | Нет | Желательно (4–6к/мес) |
| Может ли быть твой бывший/текущий ТК-работодатель клиентом | НЕТ (запрет 2 года) | ДА |
| Пенсионный стаж | Не идёт без добровольных взносов | Идёт |
| Ответственность | Только доход | Всё имущество ИП-шника (но не личное жильё) |
| Скорость регистрации | 5 минут через приложение «Мой налог» | 3–5 рабочих дней через Госуслуги/банк |
