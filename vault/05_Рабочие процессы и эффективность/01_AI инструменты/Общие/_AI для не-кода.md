## Где AI реально экономит время IT-специалисту

### Коммуникации
- Написать письмо/сообщение на английском
- Переформулировать жёсткий фидбек в конструктивный
- Подготовить повестку встречи

### Документация
- Написать README по коду
- Составить техническое задание
- Описать API

### Ресёрч и обучение
- Объяснить незнакомую концепцию простым языком
- Сравнить технологии/подходы
- Подготовить вопросы для интервью с кандидатом

### Планирование
- Разбить большую задачу на шаги
- Найти слепые пятна в плане
- Оценить риски

### Контент
- Написать пост в блог/LinkedIn
- Подготовить презентацию (структуру)
- Резюме статьи/книги

## Принцип работы с AI

1. Дай контекст → конкретный промпт
2. Получи черновик → отредактируй
3. Не публикуй без проверки

Время экономии: 30–70% на рутинных текстовых задачах.
