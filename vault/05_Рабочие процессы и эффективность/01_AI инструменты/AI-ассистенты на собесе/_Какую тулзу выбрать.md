# Какую тулзу выбрать на собесе

Инструмент вторичен. Если ты не понимаешь, что делаешь, ни один AI тебя не вытащит — на первом же уточняющем вопросе всё развалится. AI помогает не застрять, но отвечаешь на собесе ты.

## Главный вывод сразу

Данные [interview.io](https://interview.io): на стандартных LeetCode-вопросах AI-помощники проходят 73% случаев vs 53% без AI. На кастомных, нестандартных вопросах — только 25%.

## Критерии выбора

- Скорость ответа (всё, что больше 3-4 секунд — палево)
- Качество объяснений кода (не только решение, но и «почему»)
- Незаметность при шеринге экрана
- Распознавание контекста экрана (скриншоты задач)
- Качество распознавания речи интервьюера
- Цена и наличие бесплатного тира

## Универсальные AI (для подготовки)

### Claude (Anthropic)
- Сильный в объяснениях и рассуждениях
- Хорош для алгоритмических задач с пояснением хода мысли
- Голосовой режим — лучший для мок-интервью
- Веб-интерфейс или API

### ChatGPT (OpenAI)
- Большая база знаний, GPT-4/5 хорош в коде
- Голосовой режим бесплатный — главный инструмент мок-интервью
- При выборе мужского голоса — реально стрессово, ближе к реальному собесу

### GitHub Copilot
- Встроен прямо в IDE
- Автодополнение кода в реальном времени
- Наименее заметен для интервьюера, если собес в твоей IDE

### Cursor
- Fork VS Code с глубокой AI-интеграцией
- AI видит весь контекст проекта
- Удобен если собес проходит в своей среде

## Специализированные тулзы (real-time на собесе)

### LockedIn AI
**Что это:** Десктоп-оверлей поверх экрана. Не виден при шеринге даже целого экрана.

**Фичи:**
- Автоматический захват аудио — слышит вопрос интервьюера, генерирует ответ
- Захват экрана — скриншоты областей с задачами
- Поддержка 42 языков
- Загрузка резюме и описания вакансии для персонализации
- Выбор тона (профессиональный/разговорный) и формата (STAR для поведенческих)
- Отдельный режим для кодинга: подсветка кода, тест-кейсы, time/space complexity
- Можно пригласить друга — он видит интервью и шлёт подсказки в приложение
- Click-through режим (Ctrl+Shift+X) — клики проходят сквозь оверлей

**Цена:** Pro — $69/мес или $35/мес при годовой подписке.

**Реальность:**
- Заявленная задержка 116 мс — маркетинг. По факту — несколько секунд на теорию, дольше на код.
- На теорию отвечает нормально. На контекстных задачах среднего уровня — выдаёт неправильные ответы или теряется.
- Скриншоты задач плохо распознаёт.

### Final Round AI
**Что это:** Главный конкурент LockedIn по фичам.

**Цена:** $148/мес за 4 сессии. Годовая подписка — $96/мес, но $288 вперёд.

**Реальность:**
- Задержка 8-10 секунд — заметно на собесе.
- Generic responses без персонализации, повторяющиеся формулировки.
- Технические вопросы лучше, чем поведенческие.
- Один обзорщик называет ценообразование «ценовым безумием».

### Cluely
**Что это:** Оверлей поверх любого приложения.

**Настройка для Zoom:** Settings → Демонстрация экрана → Расширенные → «Расширенный захват изображения с фильтрацией окон». Тогда не палится.

**Реальность:**
- Скрытый режим стал платным — пользователи в ярости.
- Без скрытого режима Cluely — просто оболочка над ChatGPT, видна на экране, бесполезна.

### Interview Coder
**Что это:** Создан студентом, отчисленным из Колумбийского университета за этот проект. Технически сделано круто.

**Как работает:**
- Cmd+H — скриншот задачи (до 5 за раз для длинных условий)
- Cmd+Enter — извлекает условие, генерирует решение
- Решение в прозрачном оверлее поверх редактора
- Переключение видимости НЕ сбивает курсор и активную вкладку — интервьюер не видит скачков фокуса
- Решение приходит с «мыслями вслух» — фразами для зачитывания типа «Окей, тут думаю можно использовать хэш-мапу»
- Комментарии к каждой строке кода + анализ сложности

**Цена:** 50 решений/мес в подписке + $10 за 50 дополнительных.

### Программа от «Не Твой Ментор» (RU)
**Как работает:** Десктопное приложение, слышит вопрос → выдаёт ответ. Не видна при показе экрана. Запускаешь заранее, указываешь API-ключ + начальный промт.

**Фичи:** Автоскриншоты экрана каждые 5 секунд — даже кнопку нажимать не надо.

**Реальность:** Задержка ~20 секунд на ответ. На реальном собесе 20 секунд молчания = палево. Сам автор говорит: «лично я против этого, лучше честно пройти интервью».

### Open-source альтернативы
**Что это:** Бесплатные клоны на GitHub. Локально + свой API-ключ от OpenAI.

**Заявляют:** обход всех AI-детекторов компаний.

**Реальность:** Баги. Жалобы: «после ввода API-ключа и резюме приложение зависает и просто показывает 'listening'».

## Пять ключевых выводов по тулзам

1. **Задержка** — даже самые быстрые дают несколько секунд. Лайфхак из комментариев: «Пока генерируется ответ, говори "хороший вопрос" и тяни резину». Но если каждый вопрос «хороший» — это тоже подозрительно.

2. **Шаблонные ответы** — независимые обзоры единодушны: все тулзы выдают generic responses. Опытный интервьюер считывает за секунду. Цитата HR: «Все ответы — это сухие термины. Собеседование — это не request-response, это диалог как вебсокет».

3. **Кодинг работает лучше теории** — на стандартных LeetCode помогают (73%), на нестандартных/модифицированных — ломаются (25%).

4. **Цены кусаются** — для безработного, ищущего работу, $35-148/мес за негарантированный результат — ощутимо.

5. **На уточняющих вопросах сливаются** — «А с какой конкретно проблемой ты столкнулся при использовании этого паттерна?» — и AI всё, потому что у него нет твоего личного опыта.
