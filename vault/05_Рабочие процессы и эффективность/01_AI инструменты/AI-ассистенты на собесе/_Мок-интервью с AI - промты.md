# Мок-интервью с AI — конкретные промты

Самый мощный бесплатный способ подготовки к собесу. 10 тренировок снимут 80% стресса.

## Метод 1: Голосовой мок-интервью

Голосовой режим ChatGPT (бесплатный) или Claude. Промт:

```
Ты — Senior Frontend разработчик с 10-летним опытом.
Проводишь техническое собеседование на позицию Middle Frontend Developer.
Компания — финтех стартап, стек: React, TypeScript, Next.js.
Задавай вопросы по одному. Жди мой ответ.
Давай честную обратную связь — не подлизывайся.
Если ответ слабый — скажи прямо.
Длительность — 15 минут.
В конце — резюме с оценкой по 10-балльной шкале.
```

**Лайфхак:** выбери мужской голос — стрессовее, ближе к реальному собесу. Цитата:
> «мне сложнее проходить интервью с мужиками из-за внутреннего соперничества, поэтому для максимально некомфортной подготовки я выбираю мужской голос»

**Структура промта тренажёра:**
- Базовые настройки (роль интервьюера, уровень сложности)
- Тип интервью (техническое / софт / смешанное)
- Параметры уточняющих вопросов для естественного диалога
- Выбор голоса для максимального стресса

## Метод 2: Подготовка историй для поведенческих вопросов

```
Я — Middle Frontend разработчик, 3 года опыта.
Последний проект — маркетплейс на React + Node.js, команда 8 человек.
Помоги подготовить ответы в STAR-формате на вопросы:
1. "Расскажи о самом сложном баге"
2. "Конфликт в команде — как решал?"
3. "Почему ушёл с прошлого места?"
Ответы должны быть на 1-2 минуты, с конкретными цифрами и результатами.
Не приукрашивай — пусть звучит реалистично.
```

**Фишка:** AI не выдумывает за тебя — он структурирует твой РЕАЛЬНЫЙ опыт. Был баг? Был. Но описываешь размыто. AI вытаскивает конкретику: что произошло, что сделал, какой результат.

## Метод 3: Разбор задач после провала

Не прошёл live coding? Запомни задачу, скинь в Claude:

```
На собесе мне дали задачу: [описание].
Я написал вот такое решение: [твой код].
Оно не прошло / работало медленно / я не смог объяснить.
Покажи: 1) что не так, 2) оптимальное решение,
3) как это объяснить интервьюеру шаг за шагом.
```

Лучшая подготовка к следующему собесу. Каждый провал → урок.

## Метод 4: Разбор алгоритмов с пояснением

```
Объясни решение задачи [описание] как будто я Junior, который видит
это впервые. Покажи brute force → оптимальное решение.
Для каждого шага объясни ПОЧЕМУ, а не просто ЧТО.
```

## Метод 5: Стиль речи — анти-«учебниковость»

Загрузи в нейронку 3-5 примеров своих ответов (можно из переписки или транскрипта). Промт:

```
Вот примеры моей речи: [тексты].
Перепиши учебниковый ответ "[ответ]" в моём стиле,
с моими словами-паразитами и манерой объяснять.
Должно звучать как от живого человека, не из учебника.
```

Это снимает главную метку AI-читера — гладкость и шаблонность.

## Принципы

- Prompt engineering: малейшие отклонения дают разные ответы — экспериментируй
- AI помогает СТРУКТУРИРОВАТЬ опыт, не выдумывать
- Тренируй «думание вслух» — проговаривание хода мыслей даже когда не знаешь
- Прогоняй 10+ сессий — стресс снимается через повторение
