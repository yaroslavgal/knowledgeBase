# Промты и приёмы для Claude Code

Конкретика: промты, hooks, MCP, экономия токенов. Без них Claude Code = дорогой автокомплит.

## Экономия токенов — где жгут впустую

| Что жжёт | Что делать |
|---|---|
| Длинные промпты в каждой сессии | Переноси в `Skills` (progressive disclosure) |
| Один длинный чат на день | `/clear` после каждой фазы |
| Claude перечитывает один файл 5 раз | Гриппи в системный промпт «cache file reads» |
| Перегруз CLAUDE.md (>500 строк) | Резать до 300, выносить детали в skills |
| Поиск по проекту через grep тулу повторно | Использовать subagent с собственным контекстом |

Подписка Max $200 без оптимизации улетает за 4–5 дней. С — на месяц.

---

## Промт для CLAUDE.md (Go-сервис)

Ставится один раз, потом Claude читает каждую сессию:

```markdown
# Rules
- Be extremely concise. Sacrifice grammar for concision.
- Never write code without a plan first.
- Always run validation loop after edits.
- Ask 1-2 clarifying questions before complex tasks.
- If unsure about codebase patterns — search first, then ask.

# Architecture
- Layered: handler → service → repository
- Handlers in internal/handler/, queries in internal/repository/
- No ORM. Raw SQL via sqlx.

# Validation
1. go build ./...
2. go test ./... -count=1
3. golangci-lint run
```

Всё. Лишнее — мусор в контексте.

## Промт для рефакторинга легаси-функции

```
Задача: рефакторинг функции [path:function].
План:
1. Изучи функцию и все её вызовы (grep)
2. Определи 3 проблемы (читаемость, тестируемость, производительность)
3. Покажи план рефакторинга — НЕ пиши код
4. Жди подтверждения
5. Выполни рефакторинг с сохранением сигнатуры
6. Прогон тестов после
```

## Промт для нового фронтенд-компонента (с дизайном)

Без референсов Claude рисует «топорный» UI. С ними — нормально.

```
Создай React-компонент [name].
Контекст:
- Tailwind v3, дизайн-система в src/design/tokens.ts
- Прикладываю скриншот референса: [drag&drop image]
- Использует useQuery (TanStack Query), не fetch напрямую

НЕ делай:
- Inline стили
- Свои цвета вне токенов
- Дефолтные shadcn-компоненты без обёртки
```

Drag & drop скриншотов в CLI работает с октября 2025.

## Hooks — автоматизация

Hooks триггерят действия на события. Кейсы:

- **on_task_complete:** звук + push-уведомление (длинные задачи)
- **on_file_save:** автоматический `gofmt` или `prettier`
- **on_error:** запись в локальный лог для разбора
- **before_commit:** прогон `golangci-lint`

Конфиг в `.claude/settings.json`. Не путать с Husky — это hooks внутри Claude Code.

## MCP-серверы — что реально полезно

| MCP | Польза | Кейс |
|---|---|---|
| Context7 | Свежая документация библиотек | Claude перестаёт галлюцинировать API |
| Playwright | Браузерная автоматизация | E2E-тесты, скриншоты |
| Postgres | Прямой доступ к БД | Запросы голосом, аналитика |
| Filesystem | Расширенная работа с файлами | Стандартный, чаще всего достаточно |

Антипаттерн: ставить 10 MCP «на всякий случай». Каждый — токены в контексте при старте.

## Локальные модели для экономии (LM Studio)

Связка:
- **Планирование** — Claude Opus (дорого, но точно)
- **Простые задачи** — Qwen 3 Coder локально (бесплатно)
- **Финальное ревью** — Claude Opus

Снижает счёт на 50–70% для тех, кто живёт в CC.

## StatusLine — чтобы не угадывать

Кастомная строка в терминале с:
- текущей моделью (Opus / Sonnet)
- использованными токенами в сессии
- режимом (plan / edit / accept)
- лимитами до сброса

Без StatusLine ты слепой — узнаешь о превышении лимита, когда уже поздно.

---

## Антипаттерны

- **«Accept All» в Cursor / автопринятие в CC** — путь в мусор-кодинг.
- **Длинный системный промпт + длинный CLAUDE.md** — bloat, точность падает.
- **Один чат на спринт** — деменция гарантирована.
- **Просить «сделай красиво»** на UI — дай референс или фоткой, или линком на компонент.
- **Делать рефакторинг без тестов** — Claude уверенно сломает то, что нечем проверить.

## Голосовой ввод — недооценённый бустер

Печатаешь промпт = режешь контекст. Диктуешь = добавляешь нюансы.
Whisper Flow / macOS dictation. На длинных задачах сокращает время постановки задачи в 3–4 раза.
