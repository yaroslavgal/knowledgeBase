# Cursor vs Claude Code vs VS Code + расширения

Что это: Fork VS Code с глубокой интеграцией AI

## Cursor

**Что это:** Fork VS Code с глубокой интеграцией AI 

**Плюсы:**
- AI видит весь контекст проекта
- Команды на естественном языке прямо в редакторе
- Хорош для рефакторинга и генерации целых файлов

**Минусы:**
- Платный (есть free tier)
- Ещё один инструмент для изучения

---

## Claude Code (Anthropic)

**Что это:** CLI-инструмент для агентного кодинга от Anthropic.

**Плюсы:**
- Работает в терминале, понимает структуру проекта
- Может выполнять многошаговые задачи автономно
- Хорош для написания тестов, рефакторинга, документации

**Минусы:**
- Требует API-ключ
- Меньше визуальной интеграции

---

## VS Code + Copilot / расширения

**Что это:** Привычный редактор с AI-расширениями.

**Плюсы:**
- Минимальное изменение привычного воркфлоу
- Copilot хорошо работает «на лету»

**Минусы:**
- Меньше контекста чем у Cursor
- Менее мощные агентные возможности
