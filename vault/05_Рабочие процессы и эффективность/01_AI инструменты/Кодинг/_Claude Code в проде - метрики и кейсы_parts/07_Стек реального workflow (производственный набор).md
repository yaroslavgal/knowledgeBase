## Стек реального workflow (производственный набор)

Что используют разработчики, которые получают окупаемость:

| Слой | Инструмент | Зачем |
|---|---|---|
| Терминал | iTerm2 + tmux | Несколько сессий параллельно |
| StatusLine | Кастомный | Видеть лимиты до того как кончатся |
| CLAUDE.md | ~300 строк | Корпоративная память проекта |
| Skills | 3–7 на проект | Типовые задачи без повторения промтов |
| Hooks | on_task_complete (звук) | Уведомления о завершении длинных задач |
| MCP | Context7 + Postgres | Свежая документация + прямой доступ к БД |
| Голос | Whisper Flow / macOS dictation | Длинные промты диктуем, не печатаем |
| План-хранилище | GitHub Issues | Мультифазные планы, не теряются после /clear |
