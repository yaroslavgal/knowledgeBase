## Главная метрика: 40% больше задач в спринте

Кейс от инженера-практика (Mid Go-разработчик в финтех-компании, 3 года опыта):

**До:** Спринты 2 недели, всегда задач больше чем времени. Первый месяц с Claude Code — тратил больше времени на правку AI-кода, чем экономил.

**После настройки** (CLAUDE.md, Plan Mode, skills для типовых задач):
- Закрывает на **40% больше задач в спринте**
- Код проходит ревью с минимальными правками
- Подписка Max за $100 окупается за 2 дня работы

Что именно поменялось:
1. Бойлерплейт, который раньше занимал час → 5 минут
2. Тесты, которые ленился писать → пишутся в validation loop
3. Архитектурные решения остаются за человеком, исполнение — за AI

Главный инсайт: **архитектура — твоя, исполнение — AI. Как подрядчик по чертежу.**
