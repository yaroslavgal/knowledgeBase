## Топ-7 техник работы

### 1. `/clear` перед каждой новой задачей

**Главное правило:** обнулять контекст между задачами.

Иначе:
- Предыдущий диалог забивает контекст
- Claude путает текущую задачу с прошлой
- Качество ответов падает в 2–3 раза

```
/clear
[пишешь новый промпт]
```

### 2. Указатель файлов через `@`

```
@src/handler.go исправь ошибку с rate limiting
```

Без `@` — Claude будет угадывать файлы. С `@` — точно знает что читать.

### 3. Git как must-have

- Команда `rewind` есть, но **не доверять**
- Commit'ить **часто** (каждые 30–60 минут работы)
- Перед сложной задачей — обязательно commit
- При регрессе — `git checkout HEAD~1`
