## Правила для Claude

- Никогда не запускай `npm run dev` — у меня уже запущено
- Запускай `npm run build` после изменений
- Стиль кода: Prettier + ESLint
- Не используй классы — функциональный подход
- Тесты в Vitest (не Jest)
- Все файлы в `src/`, не в корне

### 6. Декомпозиция задач

❌ **Плохо:**
> «Сделай авторизацию с JWT, refresh токенами, password reset, email confirmation»

✅ **Хорошо:**
> «Сделай endpoint `POST /login` который принимает `email + password`, валидирует через bcrypt и возвращает JWT»

Потом следующий промпт:
> «Добавь refresh токены через cookie HttpOnly»

И так далее.

### 7. Промпт как наёмный программист

❌ **Плохо:**
> «Что-то не работает, посмотри»

✅ **Хорошо:**
> «Запустил `npm run dev`, открыл http://localhost:3000/users, получил 500. В логе:
> ```
> TypeError: Cannot read property 'id' of undefined at handler.go:45
> ```
> Посмотри handler.go и user_service.go, найди где может быть undefined.»

**Главное правило:** «если бы вы сами делали эту задачу, смогли бы без уточнений? Если нет — что нужно уточнить? Добавьте это в промпт.»
