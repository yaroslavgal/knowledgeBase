## Ограничения и подводные камни

### Контекст загрязняется быстро

После 30+ сообщений в одной сессии Claude начинает:
- Забывать ранние требования
- Путать файлы
- Возвращаться к старым ошибкам

**Решение:** `/clear` каждые 30 минут или после завершения подзадачи.

### Запускает свой `npm run dev` параллельно

Claude может запустить `npm run dev` **на другом порту** (3001) и не заметить что у тебя уже запущен. Решение:
- В `CLAUDE.md` правило: «Не запускай `npm run dev`, я сам управляю»
- Или давай команду явно: «не запускай dev сервер»

### Странные интерпретации без детального описания

> «Помидор-эмодзи нагромождение» — Claude нагенерил странный визуал когда я не описал словами что нужно.

**Решение:** **явно описывай визуал**:
- «Минималистично, как Apple Music»
- «Цвет primary — #1A73E8 (Google blue)»
- «Шрифт SF Pro Display»
- «Кнопки rounded 12px»

### Без Git может что-то поломать

`rewind` ненадёжный. Claude иногда **удаляет** файлы или ломает структуру. Регулярные коммиты — единственная страховка.
