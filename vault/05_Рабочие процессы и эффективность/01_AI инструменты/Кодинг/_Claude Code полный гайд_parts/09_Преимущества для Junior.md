## Преимущества для Junior

- Заменяет код-ревью от ментора на простых вещах
- Помогает с лайвкодингом-подготовкой (Solvit платформа — задачи из реальных собесов BigTech, фильтр по компании)
- Объясняет «почему так» — лучшая методичка чем книги

**Минусы для Junior:**
- Лишает базового опыта борьбы с компилятором
- Создаёт иллюзию понимания (выкатил код, не понял почему работает)
- При собесе без AI — провал

**Совет:** используй AI для **рефакторинга / документации / тестов** (где результат проверяешь), но **алгоритмы и базу пиши сам** для опыта.
