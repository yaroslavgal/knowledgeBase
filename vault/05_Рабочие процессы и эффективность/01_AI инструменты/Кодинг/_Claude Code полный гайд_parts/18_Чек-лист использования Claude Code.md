## Чек-лист использования Claude Code

- [ ] Установлен `@anthropic-ai/claude-code`
- [ ] Тариф $20/мес (фиксированный)
- [ ] `CLAUDE.md` создан в корне каждого проекта
- [ ] `/clear` после каждой подзадачи
- [ ] Указываешь файлы через `@`
- [ ] Git commit'ы каждые 30–60 минут
- [ ] Декомпозируешь задачи на минимальные
- [ ] Промпты детальные (визуал, стек, ограничения)
- [ ] Junior: алгоритмы пишешь сам, AI для рефакторинга/тестов
- [ ] Mock-собес без AI прошёл — для оценки реального уровня
