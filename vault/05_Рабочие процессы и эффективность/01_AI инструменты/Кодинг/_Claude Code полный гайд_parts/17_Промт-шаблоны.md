## Промт-шаблоны

### Bug fix
```
Проблема: [описание]
Воспроизвести: [шаги]
Ошибка в логе: [текст]

Файлы которые могут быть связаны: @[file1] @[file2]

Найди причину и предложи фикс. Не делай изменений до моего OK.
```

### Новая фича
```
Задача: [описание фичи]

Принять во внимание:
- Текущая структура: @[file]
- Тесты должны пройти: @tests/

Декомпозируй на 3-5 подзадач, спроси меня по каждой
прежде чем кодить.
```

### Refactor
```
Файл: @[file]

Цель рефакторинга: [например, выделить общую логику в утилиту]

Не меняй public API. Тесты в @tests/[file]_test.go
должны проходить без изменений.
```
