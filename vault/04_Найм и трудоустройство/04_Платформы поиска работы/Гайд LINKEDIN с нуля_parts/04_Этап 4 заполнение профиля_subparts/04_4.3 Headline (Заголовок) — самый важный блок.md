### 4.3 Headline (Заголовок) — САМЫЙ ВАЖНЫЙ БЛОК

У HR есть **5-7 секунд** чтобы решить — смотреть дальше или закрыть.

**Формула headline:**
```
[Основной язык] [Grade] | [Доп. скилл 1] | [Доп. скилл 2] | [N years]
```

**Реальные примеры из чатов:**
```
Principal Go Engineer | Kubernetes | AWS | Microservices
Senior Java Backend Developer | Java Software Engineer | 5 years FinTech
Senior Golang Developer | PostgreSQL | Redis | Kafka | AWS
Golang Blockchain Engineer | DeFi | Smart Contracts | Web3
```

**Правила headline:**
- Главная технология — в самом начале и везде
- Можно дублировать через `|`: "Senior Python Developer | Senior Software Engineer | Python Expert"
- По данным чата это реально работает — HR ищет по ключевым словам
- **Перед тем как писать — проверь**: поищи свой заголовок на LinkedIn Jobs. Если по нему нет вакансий — поменяй на более распространённый вариант
- Используй **самую популярную формулировку** должности (например, "Senior Product Analyst", а не "Growth Analytics Specialist")

**Что НЕ писать:**
- "Looking for opportunities" — никакой конкретики
- "Full-Stack Developer" без языков — слишком размыто (фуллстэк плохо продаётся на западном рынке — затачивай под конкретный стек)
- **НЕ смешивай разные роли:** "Product Analyst / Data Engineer / Project Manager" — выбери ОДНО направление
- Uzbekistan, Russia — убирать из профиля полностью (даже если university там)
- Шуточные title вроде "23 года, dead inside, depressed, Senior Android Developer" — забавно, но убивает поисковую выдачу
