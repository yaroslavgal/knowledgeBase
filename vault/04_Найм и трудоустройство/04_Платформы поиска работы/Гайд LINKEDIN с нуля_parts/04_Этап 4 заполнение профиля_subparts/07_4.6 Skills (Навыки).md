### 4.6 Skills (Навыки)

**Наполнение из чата:**
> "Это для HR пишется. Он ищет совпадения со списком от техдира."

Добавляй даже "очевидное":
- Основные: Go, Python, Java + весь твой стек
- Инфраструктура: Docker, Kubernetes (K8s), Terraform, AWS, GCP, Azure
- Паттерны: Design Patterns, Concurrency Patterns, SDLC, Microservices, gRPC
- Инструменты: Git, REST, GraphQL, Kafka, Redis
- Методологии: Agile, Scrum, Kanban, daily standups — добавляй если применимо (HR-боты их ищут)

**Порядок скиллов важен:**
- Главный скилл — первым в списке (не вразнобой). LinkedIn позволяет перетаскивать — используй.
- **Первые 3 скилла видны рекрутёрам без скролла** — сделай их максимально релевантными (например: Go, Kubernetes, AWS — а не Git)
- HR ищет совпадения с техзаданием, первые 3-5 скиллов видны без скролла

Ресурс для анализа buzzwords по специальности: **easyoffer.ru/analytic/golang_developer** (есть по разным стекам)

**Подтверждение скиллов:**
- **LinkedIn Skill Assessment тесты (15 вопросов)** — дают значок "certified" и **реально влияют на поисковый ранг профиля**. Это проверено — проходи обязательно по ключевым скиллам.
- Endorsements от случайных людей не сильно влияют на конверсию, но **прохождение тестов LinkedIn — влияет**
- Просить коллег сделать Endorsements для важных скиллов — больше для SSI
