## ИТОГОВЫЙ ЧЕКЛИСТ (порядок выполнения)

### Неделя 1: Технический старт
- [ ] Создать @outlook.com почту
- [ ] Зарегистрировать LinkedIn через Google-аккаунт (с любым именем)
- [ ] Купить eSIM нужной страны (Airalo/Holafly)
- [ ] Добавить SIM-номер в профиль LinkedIn
- [ ] Ждать 2-4 дня, просто листать ленту
- [ ] Сменить имя на своё
- [ ] **Переключить язык профиля на английский** (добавить EN → сделать primary → удалить RU)
- [ ] Если заблокировали — верификация по загранпаспорту (до 4-5 попыток — нормально)

### Неделя 2-3: Заполнение профиля
- [ ] Фото: профессиональная фотосессия
- [ ] Обложка: яркая, тематическая
- [ ] Локация: Берлин / Лондон / Варшава / Амстердам
- [ ] Headline: основной язык + 2-3 доп. скилла (проверить что по этому title есть вакансии на LinkedIn)
- [ ] About: стек + достижения с цифрами + контакт Telegram/WhatsApp
- [ ] Experience: каждая позиция с РЕЗУЛЬТАТАМИ и метриками, ключевой язык везде
- [ ] Skills: полный список + buzzwords из easyoffer.ru. **Пройти LinkedIn Skill Assessment** по топ-3 скиллам
- [ ] **Featured section: загрузить PDF резюме**
- [ ] Certifications: добавить всё что есть с media
- [ ] Попросить 2-3 рекомендации
- [ ] Подготовить PDF резюме (2 страницы, ATS-compatible)
- [ ] Open to Work — включить

### Неделя 3-5: Набор 500+ коннектов
- [ ] **Первые 200:** добавляй C-level и senior людей из целевой локации
- [ ] 5 контактов в день / до 80 в неделю
- [ ] Разработчики + бывшие коллеги + участники чатов
- [ ] Попросить в чате ОМ / АйТи Красавчик endorsements для скиллов
- [ ] Удалять непринятые заявки старше 2 недель

### После 500+ коннектов: Целевая работа через LinkedIn
- [ ] Добавлять HR/Recruiter из целевого региона
- [ ] Зарегистрироваться на 10-20 remote job сайтах (с линком на LinkedIn)
- [ ] Запустить LinkedIn Jobs + Easy Apply
- [ ] **Писать нанимающим менеджерам напрямую** через LinkedIn
- [ ] **Писать разработчикам** в целевых компаниях для инсайдерской инфы и рефералов
- [ ] Реферальная стратегия через LinkedIn для приоритетных компаний
- [ ] Отвечать на всех агентских HR — строить сеть прослоек
