# Конверсия, воронка, сроки на международном рынке

Конверсия и сроки на международном рынке отличаются от РФ-рынка кардинально: меньше откликов, больше процентов до оффера, дольше каждый этап. Внутри — таблица сравнения с РФ и реалистичные ожидания по срокам.

## Главное отличие от РФ-рынка

| РФ-рынок | Международный рынок |
|---|---|
| 1000 откликов → 10 собесов → 3–4 оффера | Каждый контакт ведёт к офферу, но **попасть на собес сложно** |
| Воронка широкая на входе | Воронка узкая на входе, широкая после |
| Резюме читают за 5–10 секунд | Резюме читают если попало в выдачу LinkedIn |
| HR звонит первым | Ты пишешь первым (или HR через LinkedIn-поиск) |

> «Самое сложное — попасть на собес. Дальше всё по накатанной.» — большинство до принятия оффера прошло меньше 5 собеседований.

## Реальная конверсия (2025–2026)

### По стратегиям

| Стратегия | Конверсия в ответ |
|---|---|
| Easy Apply «массово» | <0.5% |
| Easy Apply целевой (твой стек точно) | 30–40% |
| Cold message HR | 5–10% |
| Cold message Hiring Manager | 15–25% |
| Cold message разработчику | 30–40% |
| Реферал | 70–90% (хотя бы скрининг) |

### По этапам

| Этап | Конверсия дальше |
|---|---|
| Целевой Easy Apply → ответ HR | 30–40% |
| Ответ HR → скрининг с HR | ~80% |
| Скрининг → техническое интервью | ~70% (раньше было ~80%) |
| Техническое → финальное | ~50% |
| Финальное → оффер | ~50% |

**Итог:** на 20 целевых откликов → 6–8 встреч → 3–4 техсобеса → 1–2 оффера.

## Реальные кейсы из чатов

### Кейс 1: Golang, 6 лет опыта, EU
> «На 20 откликов — 6–8 встреч и 3–4 технических интервью.»

### Кейс 2: SSI 12 → 36 за 3 недели
- Дозаполнил профиль
- Опубликовал 5 постов
- Начали писать 2–3 HR в неделю

### Кейс 3: Назаров (Senior Go)
- SSI = 40/100
- HR пишут с офферами на $10K+/мес
- Главное: правильный профиль + ключевые слова + 500+ коннектов

### Кейс 4: Назаров — оффер без собеса
> «Второй оффер на $10K+ мне принёс на блюдечке HR из прослойки, с которым работал 2 года назад. Взяли без собеседования — только по его рекомендации.»

## Психология поиска

### Если нет результата — это не значит что не работает

> «Ребята, это правда работает. Не сдавайтесь. Мне тоже казалось что ничего не происходит.»

50% людей искали 1–5 месяцев. Дисциплинированные регулярные действия без видимого результата → потом офферы.

### SMART-цели

Конкретные действия каждый день:
- 10–20 откликов
- 1 cold message Hiring Manager
- 10 минут в LinkedIn (лайки/комменты/добавление коннектов)

Заводи в календарь как обязательные задачи. Без этого превращается в «когда-нибудь».

## Тактика «паровозика собеседований»

Группа людей с похожим стеком идёт в одни компании за друг другом.

**Как работает:**
1. Кто-то из чата выяснил: в компании X живой HR и реальная вакансия
2. Прошёл скрининг → поделился с группой («HR такой-то, на что валит, что спрашивают»)
3. Следующий идёт уже подготовленный
4. Конверсия выше чем у случайного отклика

**Где найти такие группы:**
- Чаты по стеку в сообществах (Slack/Discord)
- Telegram-группы по поиску валютной удалёнки
- Чат АйТи Красавчик
- Чат @om_nazarov

## Статистика рынка LinkedIn

- ~15% вакансий в США — **fully remote**
- ~85% — onsite или гибрид
- На каждую вакансию **тысячи кандидатов** через Easy Apply
- Сеньоры с хорошим профилем — меньше, конкуренция ниже

## Чек-лист реалистичных ожиданий

- [ ] Setup профиля + 500 коннектов = 2–3 месяца
- [ ] Первый ответ от HR = 2–4 недели после заполнения профиля
- [ ] Первое техническое интервью = месяц
- [ ] Первый оффер = 1–3 месяца
- [ ] Если ищешь 6+ месяцев без результата — пересмотри:
  - Headline (нет ли «Looking for opportunities» вместо специализации)
  - Локацию (не Россия / не Казахстан)
  - Стек (соответствует ли спросу EU/US 2026)
  - Английский B2+
  - Стратегию (одни Easy Apply без аутрича — слабо)
