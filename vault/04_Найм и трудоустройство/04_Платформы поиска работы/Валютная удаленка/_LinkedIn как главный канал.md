# LinkedIn — главный канал валютной удалёнки

LinkedIn — главный канал входящих от международных рекрутёров: 90% инициативных контактов идут оттуда. Внутри — почему LinkedIn критичен и как сделать профиль так, чтобы тебя находили.

## Почему LinkedIn — главный

- 90% входящих от международных рекрутёров идут оттуда
- Единственная платформа где **прослойки сами тебя ищут**
- Hiring Managers / разработчики целевых компаний доступны напрямую
- Реферальная стратегия работает только через LinkedIn

Без LinkedIn валютной удалёнки практически нет.

## Краткий обзор стратегий

### Пассивная стратегия (основная)

Заполненный профиль + правильные ключевые слова + 500+ коннектов = HR находит сам через LinkedIn-поиск.

Ключевые элементы:
- Локация: **Berlin / London / Warsaw / Amsterdam**
- Headline: главная технология + grade + 2-3 доп. скилла
- Experience с метриками
- Skills: топ-3 самых релевантных + Skill Assessment по ним
- 500+ коннектов с C-level и senior из EU

**Сроки:** первые HR через 2–4 недели после заполнения профиля. Первый оффер: 1–3 месяца.

### Активная стратегия — Easy Apply

- Целевые отклики (твой стек точно совпадает): **30–40% конверсия**
- Массовый спам: <0.5%
- 5–10 откликов в день, follow-up через 5 дней (один раз)

### Активный аутрич — cold messages

| Кому | Конверсия в ответ |
|---|---|
| HR | 5–10% |
| Hiring Manager | 15–25% |
| Разработчик в компании | 30–40% |
| Реферал | 70–90% (хотя бы скрининг) |

### Реферальная стратегия

Самая эффективная для топ-компаний. Без реферала на Spotify/TikTok/Apple — ноль ответов. С рефералом — хотя бы скрининг.

### Прослойки / агентства

Пассивный канал. Агенты сами тебя находят. Накрутка 15–20% от твоей зарплаты идёт ИМ от компании. Ты получаешь обещанное.

> «Сеть прослоек у меня уже 10+ человек. Каждые 2–3 месяца кто-то приходит с оффером.»

## Реальные конверсии (валидированы)

- **20 целевых откликов** → 6–8 встреч → 3–4 техсобеса → 1–2 оффера
- **SSI 30 → 60** за 22 дня (15–30 мин/день активности)
- **Поиск занимает 1–3 месяца** для senior с правильным профилем
- **Парадокс:** сеньорные позиции конвертируются ЛУЧШЕ мидловых — конкуренция ниже

## Чек-лист LinkedIn-стратегии

- [ ] Создан аккаунт через Google auth с европейского IP
- [ ] Профиль заполнен: фото, обложка, локация EU, headline, about, experience с метриками
- [ ] Skill Assessment по топ-3 пройден
- [ ] Featured: PDF-резюме (2 страницы)
- [ ] 500+ коннектов (фаза 0: C-level, фаза 1: senior, фаза 2: HR)
- [ ] SSI 60+ (необязательно, но приятно)
- [ ] Easy Apply целевой 5–10 в день
- [ ] Cold messages 5–10 в день (Hiring Manager + разработчики)
- [ ] Tracker откликов (Notion / таблица)
- [ ] Шаблоны под все типы сообщений готовы
- [ ] Зарегистрирован на 5–10 параллельных площадках (см. `_60_площадок_список.md`)
