# HH-кабинет глазами рекрутера

То, что ты не видишь со стороны кандидата — но видит каждый рекрутер, открывающий твоё резюме. Источник: разборы из реальных видео внутри кабинета HR.

## Что рекрутер видит про тебя

- **Дата последнего обновления резюме** — фильтр по «обновлено за 3-7 дней» включён по умолчанию. Не обновлял месяц — ты вне выдачи.
- **Статус** — «Активно ищу работу» (зелёная плашка) идёт первой. «Рассматриваю предложения» — ниже. «Не ищу» — мёртв.
- **Все твои резюме на HH** — если у тебя на одном аккаунте Go, FE и QA — рекрутер видит всё. Сразу теряешь правдоподобие.
- **Сколько раз и кто открывал твоё резюме** — рекрутер видит активность. Слишком много просмотров без оффера — красный флаг для следующего.
- **Город** — если в РФ-вакансии стоит «Москва (удалёнка)», а у тебя «Самара», часть рекрутеров отсеивает по умолчанию.
- **Цифровые достижения** — HH сам подсвечивает плашкой «есть метрики» наверху карточки. Без метрик — ты слабее.

## Авторазбор HH

HH не показывает вакансии всем. Рекрутер может:
- Скрыть вакансию из поиска — её не видно через обычный поиск.
- Отключить приём автооткликов — твой автоотклик не дойдёт.
- Включить фильтры по навыкам, городу, возрасту, полу, зарплате, опыту — попадание в фильтр = в выдачу.

Логика: рекрутер выбирает навыки из подсказок HH, не выдумывает свои. **Твои навыки в резюме должны совпадать с подсказками HH** — это и есть SEO для HH.

## 6-секундный просмотр

Первый взгляд — 3-4 секунды на:
- Структура (сложная вёрстка → закрыл).
- Фото (есть/нет — спорно, но иногда фильтруют «только с фото»).
- Заголовок (должность).
- Длина (10 страниц → закрыл).

Если зацепило — 20 секунд на:
- Блок «О себе».
- Цифры в опыте.
- Места работы (бренды).

Если и тут зацепило — открывает целиком.

## Чек-лист настройки кабинета

- [ ] Один аккаунт = один стек = одно резюме
- [ ] Telegram прямо в шапке (или в «О себе»)
- [ ] Статус «Активно ищу работу»
- [ ] Город = город целевой вакансии (Москва для удалёнки с московской ЗП)
- [ ] Английский ≥ B2 (рекрутеры массово ставят B2 как фильтр, не понимая что это значит)
- [ ] Все навыки из подсказок HH под целевую вакансию — дословно
- [ ] Зарплата не указана
- [ ] Резюме поднимается 1-2 раза в день (можно через приложение, без платной автонакрутки)
- [ ] В каждом месте работы — 3-5 пунктов с цифрами
- [ ] Фото — нейтральное, чистый фон

## Реальная цитата из транскрипта

> «Поиск работы на ХХ теперь больше напоминает дейтинг приложение, в котором две стороны тратят время, но не могут найти что нужно.»

## Что делать с этой инфой

Не воюй с системой — играй её правилами. Каждое из правил выше — это конкретный фильтр. Закрыл фильтр — попал в выдачу. Не закрыл — невидим.
