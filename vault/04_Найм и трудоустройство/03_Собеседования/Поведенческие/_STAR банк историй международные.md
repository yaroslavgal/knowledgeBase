# Банк STAR-историй для международных собесов

- Situation — контекст (1 предложение) - Task — твоя задача (1 предложение) - Action — что ТЫ сделал (главное! 60–70% времени ответа) - Result — результат с цифрами (1 предложение)

## Метод STAR

- **S**ituation — контекст (1 предложение)
- **T**ask — твоя задача (1 предложение)
- **A**ction — что **ТЫ** сделал (главное! 60–70% времени ответа)
- **R**esult — результат с цифрами (1 предложение)

---

## Топ-15 универсальных STAR-вопросов

Подготовь **10 историй** — они закроют 80% behavioral вопросов через переиспользование.
