### 3. How do you handle conflicts in the team?

**Скелет:**
- S: Конфликт между frontend и backend — frontend винил backend в медленных API, backend винил frontend в неоптимальных запросах
- T: Меня позвали как senior с обеих сторон опытом
- A: Организовал blameless retrospective. Использовал данные (APM-метрики), показал что 70% медленности от backend (slow query на индекс), 30% от frontend (over-fetching). Предложил конкретный план: индекс + GraphQL для frontend.
- R: Через 2 недели API latency упала с 800ms до 150ms. Frontend и backend начали парные сессии раз в неделю.
