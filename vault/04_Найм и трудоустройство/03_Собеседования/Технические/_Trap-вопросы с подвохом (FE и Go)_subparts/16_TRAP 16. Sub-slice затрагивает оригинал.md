### TRAP 16. Sub-slice затрагивает оригинал

```go
s := []int{1, 2, 3, 4, 5}
sub := s[1:3]              // [2 3], cap=4
sub = append(sub, 99)      // запишется в позицию 3
fmt.Println(s)             // [1 2 3 99 5]!
```

**Подвох:** `sub` смотрит на тот же underlying array. Append в пределах cap записывает в общий массив.

Защита: full slice expression `s[1:3:3]` — ограничивает cap, append вынужден реаллоцировать.
