### TRAP 20. Запись в закрытый канал

```go
ch := make(chan int)
close(ch)
ch <- 1   // panic: send on closed channel
```

**Правила**:
- Запись в закрытый → паника
- Чтение из закрытого → zero value, ok=false (без блокировки)
- Закрытие закрытого → паника
- Закрытие nil → паника

Закрывать должен ТОЛЬКО отправитель. Если несколько отправителей — координация через WaitGroup + одна закрывающая горутина.
