### TRAP 22. WaitGroup нельзя передавать по значению

```go
// ❌ Скрытый deadlock
func worker(wg sync.WaitGroup) {
    defer wg.Done()  // Done на КОПИИ
    work()
}

// Где-то в main:
wg.Add(3)
go worker(wg)  // копируем!
wg.Wait()      // вечно ждёт
```

**Подвох:** все sync-объекты (Mutex, WaitGroup, Cond, Once, Pool) **нельзя копировать** после первого использования. Копия имеет своё состояние. `go vet` ловит warning «copies lock value».

Фикс: всегда передавай **указатель** `*sync.WaitGroup`.
