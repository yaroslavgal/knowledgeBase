### TRAP 15. Slice — append не виден снаружи

```go
nums := []int{1, 2, 3}
func appendIt(s []int) { s = append(s, 42) }
appendIt(nums)
fmt.Println(nums)  // [1 2 3] — без 42
```

**Подвох:** slice header передаётся по значению. Внутри функции локальная копия. Если append реаллоцировал — изменения не ушли наружу. Если НЕ реаллоцировал — 42 запишется в underlying array, но caller-ский len = 3, видит только первые 3.

Фикс: `nums = appendIt(nums)`.
