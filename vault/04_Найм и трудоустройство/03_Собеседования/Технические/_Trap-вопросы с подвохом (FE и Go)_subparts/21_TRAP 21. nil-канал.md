### TRAP 21. nil-канал

```go
var ch chan int  // nil
ch <- 1          // блок навечно (не паника!)
<-ch             // блок навечно
close(ch)        // паника
```

**Подвох:** многие думают что чтение/запись в nil-канал = паника. На самом деле — вечная блокировка. Паника только при close.

Применение: «выключить» case в select присвоением `ch = nil`.
