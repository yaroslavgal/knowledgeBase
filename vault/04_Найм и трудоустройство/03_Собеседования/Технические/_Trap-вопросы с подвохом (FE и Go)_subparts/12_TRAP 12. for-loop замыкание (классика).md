### TRAP 12. for-loop замыкание (классика)

```go
for i := 0; i < 5; i++ {
    wg.Add(1)
    go func() {
        defer wg.Done()
        fmt.Println(i)
    }()
}
```

**Ответ:** `5 5 5 5 5` (на Go до 1.22).

**Подвох:** замыкание держит **указатель** на `i`, не значение. К моменту выполнения горутин цикл закончился, i=5.

3 фикса:
1. `go func(val int) { ... }(i)` — передать копию
2. `i := i` внутри цикла — shadow
3. С Go 1.22+ — автоматически фиксится (per-iteration variable)

**Бонус:** покажи аналогичный баг в `range`:
```go
funcs := []func(){}
for _, v := range []int{1, 2, 3} {
    funcs = append(funcs, func() { fmt.Println(v) })
}
for _, f := range funcs { f() }  // 3 3 3 на Go до 1.22
```
