### TRAP 9. nil-интерфейс через nil-указатель в JS-аналоге

В JS такой же подвох с проверкой:
```js
function foo() {
  const arr = [];
  if (arr) console.log("truthy");  // truthy! пустой массив truthy
}
[] == false   // true!  через приведение
[] === false  // false
```

В JavaScript для пустых проверок: `if (arr.length === 0)` или `if (!Array.isArray(arr) || arr.length === 0)`. Не `if (!arr)`.
