### TRAP 18. Defer в цикле — утечка дескрипторов

```go
for _, name := range files {
    file, _ := os.Open(name)
    defer file.Close()  // выполнится только при ВЫХОДЕ из функции!
    process(file)
}
```

**Подвох:** все defer накапливаются и выполняются в конце функции. Если файлов 10000 — 10000 открытых дескрипторов до выхода из функции.

Фикс — вынести в отдельную функцию:
```go
for _, name := range files {
    func() {
        file, _ := os.Open(name)
        defer file.Close()
        process(file)
    }()
}
```
