### TRAP 14. nil-интерфейс != nil

```go
type MyError struct{}
func (*MyError) Error() string { return "bad" }

func doIt() error {
    var err *MyError = nil
    return err
}

if err := doIt(); err != nil {
    fmt.Println("WTF?")  // выведется!
}
```

**Подвох:** интерфейс = пара `(type, value)`. Type != nil (`*MyError`), хотя value = nil → интерфейс != nil.

Фикс:
```go
func doIt() error {
    return nil  // явно nil-интерфейс
}
```
