### TRAP 25. Конкурентный доступ к map

```go
m := make(map[string]int)
go func() { m["a"] = 1 }()
go func() { m["b"] = 2 }()
// → fatal error: concurrent map writes
```

**Подвох:** это **не** обычный data race. Рантайм Go сам детектирует и паникует, чтобы избежать UB. Фикс: `sync.Mutex` или `sync.Map` (для специфических паттернов).
