### TRAP 23. Двойной Lock на одном мьютексе

```go
mu.Lock()
// ...
mu.Lock()  // DEADLOCK!
```

**Подвох:** в Go нет рекурсивных мьютексов. Намеренно. Заставляет чинить кривую архитектуру (не нужно лочить уже залоченное).

Тонкий случай: метод A() лочит, вызывает метод B(), который тоже лочит → deadlock. Решение — внутренний `aLocked()` без блокировки.
