### TRAP 11. React keys = index в редактируемом списке

```jsx
{items.map((item, i) => (
  <input key={i} defaultValue={item.name} />
))}
```

**Что сломается:** при удалении из середины списка — фокус и значения инпутов «переедут» к соседним элементам, потому что React сопоставляет по key (=index). Реальный фикс: `key={item.id}`.
