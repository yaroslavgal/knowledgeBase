### TRAP 10. == vs === с приведением

```js
0 == ""          // true
0 == "0"         // true
"" == "0"        // false  (!)
null == undefined// true
null == 0        // false  (!)
[] == false      // true
[1] == true      // true
[1,2] == true    // false
```

**Подвох:** правила приведения нелогичны. Просто всегда `===`. Единственный правильный кейс `==`: `value == null` — проверка на null И undefined одновременно.
