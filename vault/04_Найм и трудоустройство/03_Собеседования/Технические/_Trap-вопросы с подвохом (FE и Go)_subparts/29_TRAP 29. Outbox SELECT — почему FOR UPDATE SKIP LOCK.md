### TRAP 29. Outbox SELECT — почему FOR UPDATE SKIP LOCKED

```sql
SELECT * FROM outbox WHERE processed_at IS NULL FOR UPDATE SKIP LOCKED LIMIT 10;
```

**Подвох:**
- `FOR UPDATE` — без него параллельные воркеры возьмут одни и те же строки → дубли
- `SKIP LOCKED` — без него воркеры будут ждать освобождения строк → последовательная обработка

Без обоих — либо race, либо все стоят в очереди.
