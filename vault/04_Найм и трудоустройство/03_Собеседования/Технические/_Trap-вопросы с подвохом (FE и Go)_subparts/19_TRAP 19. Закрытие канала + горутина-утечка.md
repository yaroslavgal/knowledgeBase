### TRAP 19. Закрытие канала + горутина-утечка

```go
func slow() string {
    ch := make(chan string)  // НЕбуферизированный
    go func() { ch <- fetchSlow() }()
    select {
    case s := <-ch: return s
    case <-time.After(1*time.Second): return "timeout"
    }
}
```

**Подвох:** если сработал `time.After` — функция вернётся, горутина повиснет на `ch <- ...` навсегда. Никто не читает.

Фикс: `make(chan string, 1)` — буферизированный, горутина запишет в буфер и завершится.
