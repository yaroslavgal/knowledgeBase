### TRAP 13. counter++ без синхронизации

```go
var counter int
var wg sync.WaitGroup
for i := 0; i < 1000; i++ {
    wg.Add(1)
    go func() { defer wg.Done(); counter++ }()
}
wg.Wait()
fmt.Println(counter)  // 937, 952, 981 — каждый раз разный
```

**Подвох:** `counter++` = read+modify+write. Не атомарно. Lost update. Ловится `go run -race`.

Фиксы: `atomic.Int64.Add(1)` или `mutex.Lock()`.

⚡ Подзалёт: «два счётчика — можно atomic?» — НЕТ. Между двумя atomic-операциями вклинится горутина. Только mutex.
