### TRAP 17. Defer и именованный return

```go
func f() (x int) {
    defer func() { x++ }()
    return 1
}
// Вернёт 2!
```

**Подвох:** defer выполняется ДО возврата, но ПОСЛЕ вычисления return. С именованным return defer может менять возвращаемое значение.

Без именованного — не сможет:
```go
func f() int {
    var x int
    defer func() { x++ }()
    return 1  // вернёт 1, не 2
}
```
