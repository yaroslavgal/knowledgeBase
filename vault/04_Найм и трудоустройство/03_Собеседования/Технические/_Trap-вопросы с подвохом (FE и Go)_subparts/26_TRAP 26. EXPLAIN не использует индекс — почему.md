### TRAP 26. EXPLAIN не использует индекс — почему?

```sql
CREATE INDEX idx_email ON users(email);
SELECT * FROM users WHERE LOWER(email) = 'foo@bar.com';
-- Seq Scan! Индекс не используется
```

**Подвох:** функция от столбца — индекс не подхватывается. Фиксы:
1. Функциональный индекс: `CREATE INDEX ON users(LOWER(email))`
2. Использовать `email = 'foo@bar.com'` без LOWER (если данные нормализованы)

Аналогично — приведение типов:
```sql
WHERE id = '42'  -- если id integer, индекс не используется
```
