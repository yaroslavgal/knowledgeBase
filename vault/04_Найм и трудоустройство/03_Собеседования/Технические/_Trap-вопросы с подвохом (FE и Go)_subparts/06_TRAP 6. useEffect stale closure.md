### TRAP 6. useEffect stale closure

```js
function Timer() {
  const [count, setCount] = useState(0);
  useEffect(() => {
    const id = setInterval(() => {
      setCount(count + 1);  // ВСЕГДА 0 + 1 = 1!
    }, 1000);
    return () => clearInterval(id);
  }, []);  // пустой массив!
  return <div>{count}</div>;
}
```

**Подвох:** `count` захвачен по значению при первом рендере, всегда = 0. Каждый тик ставит count в 1, а не инкрементирует. Фиксы:
- `setCount(prev => prev + 1)` — функциональное
- Добавить `count` в deps (но тогда таймер пересоздаётся каждый раз)
