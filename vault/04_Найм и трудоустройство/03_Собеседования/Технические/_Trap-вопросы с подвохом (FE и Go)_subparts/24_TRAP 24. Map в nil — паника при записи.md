### TRAP 24. Map в nil — паника при записи

```go
var m map[string]int  // nil
v := m["key"]   // 0, ok — OK
_, ok := m["key"]   // false, ok — OK
m["key"] = 1    // PANIC: assignment to entry in nil map
```

**Подвох:** чтение из nil map работает (zero value), запись — паника. Всегда `make(map[K]V)` перед использованием.
