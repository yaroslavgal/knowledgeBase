## БЛОК 2: Go deep (6 мин) — выбрать ОДНО

### Цепочка F — Errors и wrapping

1. «Три вызова с ошибками — как оборачивать?»
2. «Разница `%w` и `%v`. Что теряется при `%v`?»
3. «errors.Is vs errors.As — когда что?»
4. ⚡ «`err == sql.ErrNoRows` — гарантированно сработает?» (Нет, после `%w` — нет)
5. ⚡ Nil-интерфейс ловушка:
```go
var err *MyError = nil
return err  // интерфейс error != nil!
```
6. «Что появилось в Go 1.20 для объединения ошибок?» (`errors.Join`)
7. «`defer tx.Rollback()` — что не так?»
8. «Какой HTTP-код отдать клиенту — 400/404/409/422/500? Принцип?»

### Цепочка G — Слайсы

1. «Из чего состоит слайс в памяти? Underlying array?»
2. «Чем `len` от `cap`? Когда append реаллоцирует?»
3. «По какой формуле растёт cap?» (×2 до ~1024, потом ~×1.25)
4. «Почему append возвращает новый слайс?»
5. ⚡ ```go
   func appendIt(s []int) { s = append(s, 42) }
   nums := []int{1,2,3}; appendIt(nums)
   ```
   «Почему nums == [1 2 3]?»
6. ⚡ ```go
   sub := s[1:3]; sub = append(sub, 99)
   ```
   «Что с исходным слайсом?» (затрагивается underlying array)
7. «100k строк из БД в слайс без преаллокации — сколько аллокаций?»
8. «Data race при параллельном чтении `len(slice)`?»

### Цепочка H — Интерфейсы

1. «Как работают интерфейсы? Чем от Java/C# с implements?»
2. «Type assertion — безопасная и небезопасная форма?»
3. ⚡ «Метод `String()` через pointer receiver. `t := T{}`. `t` реализует Stringer? `&t`?»
4. ⚡ Nil-интерфейс из ошибок (повторение в другом контексте)
5. «Принцип «Accept interfaces, return structs». Почему?»
6. «Где определять интерфейс — у реализации или потребителя?» (consumer-side)
7. «`any` — когда оправдан, когда плохой запах?»
8. «Compile-time check что тип реализует интерфейс?» (`var _ Iface = (*T)(nil)`)

### Цепочка I — Sync примитивы

1. «Mutex vs RWMutex. Когда RW реально выигрывает?»
2. «Что если забыть Unlock?»
3. ⚡ «Структуру с Mutex передали в функцию по значению. Что? Ловится?» (`go vet copylocks`)
4. ⚡ «Дважды Lock на одном Mutex одной горутиной?» (deadlock, рекурсивных нет)
5. «`sync.Once` — как устроен? Почему нельзя сбросить?»
6. «`sync.Pool` — какие гарантии? Что отнимет объект?» (GC между вызовами)
7. ⚡ «Embedded Mutex анонимным полем — риск?» (Lock/Unlock в публичном API)
8. «100k RPS, mutex contention. Как доказать?» (pprof mutex profile)
