## Лайвкодинг — частые задачи

### 77. Rate Limiter (Token Bucket) `S`
```go
type Limiter struct {
    tokens chan struct{}
}
func New(rate int) *Limiter {
    l := &Limiter{tokens: make(chan struct{}, rate)}
    go func() {
        ticker := time.NewTicker(time.Second / time.Duration(rate))
        for range ticker.C {
            select { case l.tokens <- struct{}{}: default: }
        }
    }()
    return l
}
func (l *Limiter) Allow() bool {
    select { case <-l.tokens: return true; default: return false }
}
```

### 78. Singleflight (упрощённый) `S`
Когда 100 горутин запрашивают одно значение — реальный запрос делает только первая, остальные ждут результат.
```go
type call struct { wg sync.WaitGroup; val interface{}; err error }
type Group struct { mu sync.Mutex; m map[string]*call }
func (g *Group) Do(key string, fn func() (interface{}, error)) (interface{}, error) {
    g.mu.Lock()
    if c, ok := g.m[key]; ok {
        g.mu.Unlock()
        c.wg.Wait()
        return c.val, c.err
    }
    c := &call{}
    c.wg.Add(1)
    g.m[key] = c
    g.mu.Unlock()
    c.val, c.err = fn()
    c.wg.Done()
    g.mu.Lock(); delete(g.m, key); g.mu.Unlock()
    return c.val, c.err
}
```

### 79. SQL + Go: GetUserOrders `M`
```go
func GetUserOrders(ctx context.Context, db *sql.DB, userID int) ([]Order, error) {
    rows, err := db.QueryContext(ctx, `
        SELECT o.id, o.amount, u.name FROM orders o
        JOIN users u ON o.user_id = u.id
        WHERE o.user_id = $1 ORDER BY o.created_at DESC LIMIT 10`, userID)
    if err != nil { return nil, fmt.Errorf("query: %w", err) }
    defer rows.Close()
    var orders []Order
    for rows.Next() {
        var o Order
        if err := rows.Scan(&o.ID, &o.Amount, &o.UserName); err != nil {
            return nil, fmt.Errorf("scan: %w", err)
        }
        orders = append(orders, o)
    }
    return orders, rows.Err()
}
```
Что проверяют: `defer rows.Close()`, `QueryContext`, `rows.Err()` после цикла, обёртка ошибок через `%w`, не SQL injection.
