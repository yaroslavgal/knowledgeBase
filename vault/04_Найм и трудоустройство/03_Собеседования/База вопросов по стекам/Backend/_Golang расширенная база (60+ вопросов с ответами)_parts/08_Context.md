## Context

### 50. Зачем context первым параметром `M`
Отмена, таймаут, дедлайн, request-scoped метаданные. Сквозная отменяемость через всё дерево вызовов.

### 51. Способы создать context `M`
- `Background` — корневой
- `TODO` — placeholder
- `WithCancel` — ручная отмена
- `WithTimeout` — отмена через N времени
- `WithDeadline` — отмена в момент времени
- `WithValue` — request-scoped значения
- `WithCancelCause` (1.20+), `WithoutCancel` (1.21+)

### 52. ⚡ Почему defer cancel() обязателен `M`
Даже если WithTimeout сработает сам — cancel освобождает таймер и parent-chain. Без него — утечка ресурсов до истечения таймера. Для минутных таймаутов — боль.

### 53. ⚡ context.Background в HTTP-хендлере — почему нельзя `M`
Клиент может отменить запрос (закрыл вкладку, TCP RST). С `r.Context()` — БД-запрос отменится. С `Background()` — БД продолжит выполнять, тратить ресурсы, а клиент уже ушёл.

### 54. context.WithValue — что можно/нельзя `M`
**Можно**: request-scoped (trace id, user id, request id).
**Нельзя**: обязательные зависимости (DB, logger). Теряется type safety, невидимые зависимости, прячется контракт функции.
