## Slices / Maps / Strings

### 29. Slice устройство `J`
Slice header = `{pointer, len, cap}` — 24 байта на 64-bit. View на underlying array. `len` — кол-во элементов, `cap` — ёмкость underlying array.

### 30. Append реаллокация `J`
До ~1024 элементов — рост ×2, потом ~×1.25 (с Go 1.18 алгоритм сглажен). Append возвращает новый slice header, но если cap хватило — underlying array тот же.

### 31. ⚡ Почему append не виден снаружи `M`
```go
nums := []int{1, 2, 3}
func appendIt(s []int) { s = append(s, 42) }
appendIt(nums)
fmt.Println(nums) // [1 2 3] — нет 42
```
Slice header передаётся **по значению**. Внутри функции локальная копия. Если append реаллоцировал — вообще ничего не ушло наружу. Если НЕ реаллоцировал — 42 запишется в underlying array, но caller-ский len = 3, видит только первые 3.

### 32. ⚡ Sub-slice затрагивает оригинал `M`
```go
s := []int{1, 2, 3, 4, 5}
sub := s[1:3]              // [2 3], cap=4
sub = append(sub, 99)      // запишет 99 в позицию 3
fmt.Println(s)             // [1 2 3 99 5] — затронуло!
```
Защита: full slice expression `s[1:3:3]` — ограничивает cap, append вынужден реаллоцировать.

### 33. Map устройство `M`
Хеш-таблица: бакеты по 8 элементов, overflow-бакеты при коллизиях (метод цепочек). Load factor — 6.5 (среднее на бакет), при превышении — эвакуация (incremental, не вся сразу). Порядок обхода **рандомизирован by design**, чтобы код не полагался.

### 34. Map ловушки `J`
- Запись в `nil` map → паника
- Чтение из `nil` map → zero value, ok
- Конкурентный доступ без mutex → паника рантайма (не data race!)
- Нельзя получить указатель на значение в map
- Ключ — любой comparable тип

### 35. Strings — особенности `M`
Строка = иммутабельный slice байт. `len()` — байты, не символы. UTF-8: символ может занимать 1-4 байта. Индексация возвращает байт. Для символов — `range` или `[]rune(s)`. Конкатенация — `strings.Builder`, не `+=`.

### 36. ⚡ Реверс UTF-8 строки `M`
```go
// ❌ Ломает UTF-8
b := []byte(s)
for i, j := 0, len(b)-1; i < j; i, j = i+1, j-1 { b[i], b[j] = b[j], b[i] }

// ✅ Через руны
runes := []rune(s)
for i, j := 0, len(runes)-1; i < j; i, j = i+1, j-1 { runes[i], runes[j] = runes[j], runes[i] }
return string(runes)
```
