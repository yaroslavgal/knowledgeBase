## Defer

### 47. ⚡ Порядок defer и return `M`
```go
func f() (x int) {
    defer func() { x++ }()
    return 1
}
// Вернёт 2! defer меняет именованный return
```
defer вызывается ДО возврата, но ПОСЛЕ вычисления return. С именованным return — может менять.

### 48. Stack of defers `J`
LIFO. `defer A; defer B; defer C` → выполнятся `C, B, A`.

### 49. ⚡ defer в цикле `M`
```go
for _, f := range files {
    file, _ := os.Open(f)
    defer file.Close()  // выполнится только при ВЫХОДЕ из функции, не итерации!
}
```
Утечка дескрипторов. Фикс: вынеси в отдельную функцию или закрывай явно в конце итерации.
