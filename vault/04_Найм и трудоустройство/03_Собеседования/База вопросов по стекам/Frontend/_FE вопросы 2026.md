# FE вопросы 2026 — что реально спрашивают

## Дженерики (90% — спросят почти всегда)

«Зачем generics? Напиши функцию которая возвращает поле объекта по ключу.»

```typescript
function getProperty<T, K extends keyof T>(obj: T, key: K): T[K] {
  return obj[key];
}
```

Что проверяют: понимаешь `keyof`, `extends`, можешь объяснить почему `any` тут зло.

Слабый ответ: «Дженерики — это типы которые можно подставить». Конец.
Сильный: показать `keyof T`, ограничения через `extends`, рассказать про Mapped Types и Utility Types в одну минуту.

## CORS (85%)

«Что такое CORS, зачем нужен, как работает preflight?»

Структура ответа:
1. Same-Origin Policy — браузер блокирует запросы между разными origin (protocol+host+port).
2. CORS — механизм сервера разрешить cross-origin через заголовки `Access-Control-Allow-Origin`.
3. Preflight — для не-simple запросов (PUT, DELETE, кастомные заголовки) браузер сначала шлёт OPTIONS.
4. Связать с XSS (инжект скрипта) и CSRF (запрос от имени юзера).

Слабый ответ: «CORS — это ошибка когда деплоишь, надо заголовок добавить».

## unknown vs any (75%)

`any` отключает TS. `unknown` — «неизвестно что, но проверю перед использованием».

```typescript
function parse(data: unknown) {
  if (typeof data === "string") {
    return data.toUpperCase(); // OK — narrowed
  }
}
```

Бонус: `never` (невозможное значение, exhaustive check), `strictNullChecks` в tsconfig.

## Event Loop (75%)

«Что выведет?»
```javascript
console.log("1");
setTimeout(() => console.log("2"), 0);
Promise.resolve().then(() => console.log("3"));
console.log("4");
```

Ответ: `1 4 3 2`.

Логика: синхронный код → вся microtask queue → один macrotask → опять microtasks.

Microtasks: `Promise.then`, `queueMicrotask`, `MutationObserver`.
Macrotasks: `setTimeout`, `setInterval`, I/O, события.

---

## Closures (70%)

«Что выведет?»
```javascript
for (var i = 0; i < 3; i++) {
  setTimeout(() => console.log(i), 100);
}
```

Ответ: `3 3 3`. `var` — одна переменная на функцию. Фикс: `let` (блочный скоуп) → `0 1 2`.

Бонус: упомянуть утечки памяти — замкнутые переменные не чистятся GC пока жива функция.

---

## React keys (70%)

«Зачем keys в списке? Что будет с index как ключ?»

Reconciliation алгоритм сравнивает элементы по key. С `index` при вставке в начало список перерендерится весь, и состояние компонентов «съедет».

```jsx
{items.map(item => <Item key={item.id} {...item} />)}
```

Бонус: как перерендерить один элемент списка не трогая остальные — стабильный уникальный key + React.memo на дочерний компонент.

---

## this + bind (65%)

5 правил this:
1. `obj.fn()` → `this = obj`
2. `fn()` → `undefined` (strict) / `window`
3. Arrow function — берёт this из лексического скоупа, навсегда
4. `new Fn()` → новый объект
5. `call/apply/bind` — явная привязка

Подвох: `bind` нельзя перебиндить, `bind(a).bind(b)` → `this = a`.

В стрелочных функциях `bind` не работает.

## Что изменилось в 2026

**Тестирование** — спрашивают про Jest, RTL, e2e уже на мидле. На синьора — как покрываешь, что не покрываешь и почему.

**CI/CD** — Docker, GitHub Actions ожидают даже от фронтендера.

**Алгоритмы** — junior могут не спросить, мидл+ почти всегда. Хэш-таблицы, два указателя, базовое DP.

**AI на собесе палится.** Гладкие формулировки + пауза 5-7 секунд + неспособность объяснить написанное = красный флаг.

## Чего НЕ делать

- Учить «всё подряд». Учи топ-10 до автоматизма, потом расширяй.
- Молча кодить на лайвкодинге.
- Цитировать определения слово в слово — палится зубрёжка.
- Отвечать «не знаю» без попытки рассуждения.
