# Что спросят на фронт-собесе

«Как работает event loop в JavaScript?»

## Топ вопросы с объяснениями

### Event Loop

JavaScript однопоточный. Event loop следит за call stack и queue. Когда call stack пустой — берёт задачу из queue.

Microtasks (Promise.then, queueMicrotask) выполняются до следующего macrotask (setTimeout, setInterval).

Почему важно: понимание порядка выполнения async кода.

### Closures

«Что такое closure?»

Функция которая запоминает переменные из внешней области видимости даже после того как внешняя функция завершилась.

Применения: инкапсуляция, мемоизация, partial application, приватные переменные через IIFE.

### React Re-renders

«Когда компонент перерисовывается?»

При изменении state. При изменении props. При перерисовке родительского компонента (если не обёрнут в React.memo).

Как предотвратить лишние рендеры: React.memo для компонентов, useCallback для функций передаваемых как props, useMemo для тяжёлых вычислений. Не оптимизировать всё подряд — только там где это реально нужно.

### useEffect зависимости

Классическая ловушка: функция или объект в зависимостях вызывает бесконечный цикл.

Решение: useCallback для функций, useMemo для объектов, или убрать из зависимостей если функция не меняется.

### TypeScript Generics

«Зачем generics?»

Типобезопасность без потери гибкости. Пишешь один код который работает с разными типами.

```typescript
function first<T>(arr: T[]): T {
  return arr[0];
}
```

Работает с числами, строками, объектами — TypeScript проверяет типы в каждом случае.

### Performance — реальные вопросы

«Как оптимизировать LCP?»

Preload критических ресурсов. Оптимизация изображений (WebP, lazy loading кроме LCP-изображения). Server-side rendering или SSG. Уменьшить render-blocking ресурсы.

«Что такое code splitting?»

Разбивка бандла на части которые загружаются по требованию. Вместо одного большого bundle.js — chunks которые загружаются при навигации на нужный роут.
