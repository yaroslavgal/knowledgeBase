## Angular (минимум)

### 64. Change Detection: Default vs OnPush
- Default — Angular проверяет всё дерево при каждом событии
- OnPush — обновляется только при: (1) изменился @Input по ссылке, (2) сработал async pipe, (3) markForCheck()

### 65. Signals (Angular 16+)
```ts
const count = signal(0);
const double = computed(() => count() * 2);
effect(() => console.log(`Count: ${count()}`));
count.set(5);
```
Реактивные примитивы для синхронного состояния. Проще RxJS для локального стейта.
