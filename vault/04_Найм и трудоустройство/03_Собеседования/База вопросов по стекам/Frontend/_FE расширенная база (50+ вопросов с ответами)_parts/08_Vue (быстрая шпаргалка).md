## Vue (быстрая шпаргалка)

### 61. ref vs reactive
- `ref(value)` — обёртка для любого. Доступ через `.value`. Для примитивов и гибкости
- `reactive(obj)` — глубоко реактивный объект через Proxy. Без `.value`. Деструктуризация теряет реактивность — `toRefs()`

### 62. Composition vs Options API
Options — логика по опциям (data, computed, methods). Composition (`<script setup>`) — логика группируется по фичам. Composition — рекомендуется для нового кода.

### 63. computed vs watch vs watchEffect
- `computed` — производное значение, кэшируется
- `watch` — реакция на конкретный источник, доступ к старому/новому
- `watchEffect` — авто-отслеживание зависимостей, как useEffect без deps
