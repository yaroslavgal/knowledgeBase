## React

### 31. Virtual DOM `J`
JS-представление DOM. State → новый VDOM → diffing → минимальный патч в реальный DOM. Зачем: прямые операции с DOM дорогие, React группирует.

### 32. ⚡ Почему useState не обновляется сразу `M`
```js
setCount(count + 1);
setCount(count + 1);
setCount(count + 1);
// count = 1, не 3!
```
`count` — замыкание зафиксированное при рендере. Все три вызова используют одно и то же старое значение. Решение: `setCount(prev => prev + 1)`.

### 33. useEffect зависимости `M`
- Без массива → каждый рендер
- `[]` → один раз при mount
- `[deps]` → при изменении

Типичный баг: пустой `[]` + обращение к стейту в коллбэке = stale closure. Решение: функциональное обновление или добавь зависимость.

### 34. useMemo vs useCallback `M`
- `useMemo` — мемоизация значения (тяжёлые вычисления)
- `useCallback` — мемоизация функции (стабильность ссылки для memo-чайлда или зависимости useEffect)

Когда НЕ нужно: для простых операций мемоизация дороже пересчёта.

### 35. React.memo не работает — почему `M`
Если передаёшь `style={{...}}` или `onClick={() => {}}` — каждый рендер новая ссылка → memo бесполезен. Решение: useMemo для объектов, useCallback для функций.

### 36. React keys — что будет с index `J`
- Без key / index в динамическом списке → потеря состояния, баги при перестановке, неправильные анимации, лишние ре-рендеры
- Уникальный стабильный key (id из данных) → корректно

### 37. useContext проблема перерендеров `M`
При изменении `value` все потребители ре-рендерятся, даже если им нужна часть. Решения:
1. Разделить на несколько контекстов
2. Мемоизировать value
3. Стейт-менеджер с подпиской на слайсы (Zustand, Jotai)

### 38. Custom Hooks `M`
Функция с именем `use*`, использующая другие хуки. Правило: дублируется в 2+ компонентах → вынеси.

### 39. Controlled vs Uncontrolled `J`
- Controlled — React управляет через value+onChange. Полный контроль, валидация в реальном времени
- Uncontrolled — DOM хранит, доступ через ref. Проще, меньше контроля

### 40. Suspense + lazy `M`
```jsx
const Page = React.lazy(() => import("./Page"));
<Suspense fallback={<Spinner />}><Page /></Suspense>
```
React 18+ — Suspense для data fetching через React Query/SWR.

### 41. Error Boundaries `M`
Классовый компонент с `static getDerivedStateFromError` + `componentDidCatch`. Ловит ошибки рендера. **НЕ ловит**: обработчики событий, async, SSR. Только классы (или библиотека `react-error-boundary`).

### 42. Server Components Next.js `S`
- Server — рендерится на сервере, можно в БД, нельзя useState/useEffect/обработчики, не отправляется JS на клиент
- Client — `"use client"` в начале, обычный React

Правило: максимум на сервере, "use client" только где интерактивность.
