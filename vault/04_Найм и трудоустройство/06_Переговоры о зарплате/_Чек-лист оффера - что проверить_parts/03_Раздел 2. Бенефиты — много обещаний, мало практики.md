## Раздел 2. Бенефиты — много обещаний, мало практики

### ДМС

- [ ] Когда стартует (часто через 1–3 месяца после оформления)
- [ ] Какая клиника (доступна ли в твоём городе)
- [ ] Покрывает ли семью (или только сотрудника)
- [ ] Включает ли стоматологию / ортодонтию (отдельный лимит)
- [ ] Включает ли психотерапию
- [ ] Лимит по сумме покрытия в год

### Обучение

- [ ] Есть ли бюджет (конкретная сумма в рублях/долларах)
- [ ] Что покрывает: курсы / конференции / книги / сертификации
- [ ] «По согласованию» = в реальности отказывают на 80%
- [ ] Нужно ли «отрабатывать» (1–2 года после крупного обучения)
- [ ] Английский — оплачивает компания или нет

### Отпуск

- [ ] Сколько дней (28 — стандарт РФ, 30+ — выше среднего, 25 — ниже)
- [ ] Дополнительные дни за стаж в компании
- [ ] Можно ли копить или сгорает
- [ ] Sick leave — отдельные дни или из общего пула
- [ ] Sabbatical (длительный отпуск раз в N лет)

### Удалёнка / гибрид

- [ ] **Что в трудовом договоре**: «постоянная удалённая работа» или «возможность удалёнки по согласованию»?
- [ ] **Это разные вещи.** Второе — компания может через полгода сказать «возвращаемся в офис»
- [ ] Можно ли работать из другого региона / страны
- [ ] Есть ли требование быть в офисе N дней в месяц/квартал
- [ ] Оплачивает ли оборудование на дом (стол, кресло, монитор)

### Прочие бенефиты — оценить, нужны ли

- [ ] Спортзал / фитнес-абонемент
- [ ] Корпоративные скидки (полезные или нет)
- [ ] Подписки (Spotify, обучающие платформы)
- [ ] Питание / ужины
- [ ] Транспорт / парковка
- [ ] Релокация (если переезд)

**Правило:** Бенефиты, которые ты не используешь = не часть твоей зарплаты. Считай только реально применимые.
