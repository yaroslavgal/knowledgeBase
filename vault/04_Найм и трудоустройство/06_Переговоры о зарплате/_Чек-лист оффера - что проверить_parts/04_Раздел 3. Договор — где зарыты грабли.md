## Раздел 3. Договор — где зарыты грабли

### Испытательный срок

- [ ] Указан срок (стандарт РФ — 3 мес для рядовых, 6 мес для руководителей)
- [ ] Условия прохождения (по умолчанию — никаких, оценка субъективная)
- [ ] Зарплата на испытательном (часто такая же, иногда −10–20%)
- [ ] Срок предупреждения при увольнении в этот период (3 дня по ТК)

### Non-compete (запрет работы у конкурентов)

- [ ] Есть ли пункт
- [ ] Какие компании считаются конкурентами (узкий vs широкий список)
- [ ] На какой срок (6 мес / 12 мес после увольнения)
- [ ] Есть ли компенсация за период non-compete

В РФ юридически слабо работает. Но HR может портить кровь, шантажировать «расскажем новому работодателю». Лучше согласовать формулировку или вообще убрать.

### Non-solicitation (не переманивать)

- [ ] Срок (стандарт 6–12 месяцев)
- [ ] Кого нельзя переманивать (только команду или всю компанию)

Обычно нормально, не торгуйся.

### IP assignment (твой код = их код)

- [ ] Что подпадает: «всё, что написал в рабочее время» — это нормально
- [ ] **ОПАСНО**, если: «всё, что написал в период работы» — твои pet-проекты тоже становятся их
- [ ] Есть ли исключение для open-source контрибуций
- [ ] Есть ли исключение для проектов, начатых ДО найма

### Условия увольнения

- [ ] Срок предупреждения (с твоей стороны / с их стороны)
- [ ] Условия выплаты при сокращении (ТК — 2 оклада минимум)
- [ ] Что происходит с накопленным отпуском при увольнении
- [ ] Гарантии при ликвидации компании / реорганизации

### NDA

- [ ] Что считается конфиденциальной информацией
- [ ] На какой срок после увольнения (часто бессрочно)
- [ ] Можно ли упоминать факт работы в компании в резюме (обычно — да)
