### Скрипты для Типовых Ситуаций

**"Атака на Трудовую" (СБ: "В ПФР нет отчислений от ООО Рога"):**
> "Всё верно. Работал по ГПХ через ИП, проектная занятость. В штат не заводили для оптимизации налогов. Могу предоставить контакты лида для подтверждения хардов, но в ПФР записей и не должно быть."

**"Причина увольнения?" (HR-скрининг):**
> "Закончилось финансирование проекта" / "Стек перестал развиваться, хочу расти"

**"Какие зарплатные ожидания?":**
→ Скрипт 1 (Реверс): "А какая вилка у вас?"

**"Расскажите о себе":**
60 сек: текущая роль → ключевое достижение с цифрами → почему эта компания.

**Деперсонализация отказа:**
Каждый отказ = "легенда требует доработки", не "ты плохой". Собесы = дата-майнинг вопросов.

**Правило 3-х зарплат (при сокращении):**
Выбивать 3 ЗП компенсации. При 300к = 900к. Погасил долги + видел продакшен → следующий оффер сильнее.


# ФИНАЛЬНАЯ СХЕМА УСПЕХА

**1. Подготовка (2-4 месяца):**
- 10+ собесов на YouTube → список тем
- Целевая подготовка только по списку
- 2-3 пет-проекта
- Накрутка резюме + легенда (STAR)
- Claude Code для ускорения

**2. Массовый выход:**
- HH (SEO) + Telegram + LinkedIn + Direct
- 50-100 откликов/неделю
- Трекинг конверсии по каналам

**3. HR-скрининги:**
- Бизнес-value + эффект "ВАУ"
- 20-30 приглашений → 80-90% конверсия в теху

**4. Технические:**
- Тешить эго + диалог + нейросети
- 15-25 собесов → паттерны на автопилоте

**5. Результат:**
- 5-10 офферов
- Торги с каждым (скрипты 1-7)
- Выбор лучшего в последний момент
- Выход на работу через 3-5 месяцев от старта
