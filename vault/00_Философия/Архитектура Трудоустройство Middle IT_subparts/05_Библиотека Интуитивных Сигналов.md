### Библиотека Интуитивных Сигналов

**Красные флаги ученика:**

| Сигнал | Интерпретация | Действие |
|--------|--------------|----------|
| "Мне нужно ещё подготовиться" | Прокрастинация и страх после 2+ мес | Жёстко пинать на собесы |
| "Накручивать — нечестно/опасно" | Иллюзия "честного пути" | Показать реальность рынка: без опыта не позовут |
| "Хочу сначала стать джуном" | Стереотипное мышление | Переориентировать на middle: задачи те же |
| "Учу алгоритмы / CS" | Overprepared, tutorial hell | 10 видео собесов → список → только это |
| "Закрепляю базу по YouTube" | Параллельное обучение вне системы | Объяснить что ментор заменяет YouTube |

**Красные флаги работодателя:**

| Сигнал | Интерпретация | Действие |
|--------|--------------|----------|
| Тестовое задание | Бесплатная работа / не ценят время | Отказаться (если есть варианты). Max 3 часа |
| Офис | Потеря времени, нет свободы, нет 2 работ | Только если 0 других вариантов |
| ЗП ниже рынка | Не ценят / не понимают рынок | Брать если один оффер, параллельно искать |
| Полиграф | Токсичная "галера", неадекватное руководство | БАН. Не идём туда |
| Трекеры (Time Doctor, Hubstaff) | Скриншоты экрана, нельзя AI/гуглить | БАН для накрутчика |
| "Молодой дружный коллектив" | Хаос, нет процессов, мало платят | Проверить отзывы |
| "Конкурентная зарплата" | Низ вилки | Спросить вилку в первом звонке |
