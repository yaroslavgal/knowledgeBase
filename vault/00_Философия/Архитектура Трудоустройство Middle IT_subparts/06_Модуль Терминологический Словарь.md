### Модуль: Терминологический Словарь

**Основные термины:**

| Термин | Значение |
|--------|----------|
| Накрутить опыт | 3-5 лет в резюме, не обман, а адаптация к правилам |
| Разведка рынка | Первые 5 собесов для сбора вопросов, не для оффера |
| Мок-собес | Тренировочное собеседование с ментором |
| Tutorial hell | Бесконечные курсы без выхода на рынок. 85% бросают |
| Overprepared | Учишь лишнее (CS, алгоритмы), теряешь месяцы |
| Легенда | Выдуманная история опыта для резюме. STAR-формат |
| Хрюша (HR) | Первый фильтр. Не разбирается в IT, но решает твою судьбу |
| Скрининг | Короткий созвон с HR 15-20 мин. Soft skills > код |
| Оффер | Бумажка с ЗП. Можно принять три, выйти на три, выбрать лучшую |
| Галера | Аутсорс. Бардак, текучка, всем пофиг. Инкубатор для старта |
| Валютная удалёнка | Святой Грааль. $ зарплата. Высшая цель |
| Онбординг | 2-4 недели. Ничего не требуют. Оплачиваемое доучивание |
| ИС (испытательный) | Не экзамен, а платное обучение. Даже если уволят = 3 ЗП сеньора |
| Легаси | Старый код, который никто не хочет трогать. Берут новичков |
| ATS | Робот HH. Ключевые слова. 80-90% отсеивает автоматически |
| ГПХ | Отмазка для СБ. "Работал по ГПХ" — не отражается в трудовой |
| Тешить эго | Когда поправляет: "Ого, интересно! Расскажи!" |
| Бизнес-value | Язык для HR. Не "архитектура" а "клиенты платят в 2 раза быстрее" |

**Сленг 2026:**

| Термин | Значение |
|--------|----------|
| Ждун | Джун-безработный — *"Была Джуном, стала Ждуном"* (1200 лайков) |
| Духота / душный собес | Избыточные теоретические вопросы о подкапотке |
| Красильщик кнопок | Ироничное самоназвание фронтендера |
| Вайбкодинг / вайбкодер | Разработка через AI без понимания кода |
| Вайбхакер | *"Каждому вайбкодеру найдётся свой вайбхакер"* |
| Слоп | Плохой код от AI — "unmaintainable slop components" |
| Нейронайм | Найм с AI с обеих сторон |
| Формошлёпство / крудошлёб | Рутинная работа (формы, CRUD) |
| Реджект | Отказ |
| Гриндить | Зубрить / механическая практика |
| Вкатиться / вкатун | Войти в IT из другой сферы |
| Перекат | Смена стека (фронт → Go) |
| Палево / спалиться | Быть разоблачённым |
| Инфоцыган | Мошенник-курсодел |
| Контрофер | Встречное предложение работодателя |
| Бэкдор-референс | Тайная проверка через бывших коллег |
| Золотые наручники | Высокая ЗП удерживает на нелюбимой работе |
| Многоработник | Работа на 2+ работах |
| Ghost job | Вакансия для сбора данных / инвесторов |
