### Модуль: Библиотека Аналогий

| Аналогия | Для чего |
|----------|----------|
| IT = социальный лифт | Не "заработать", а свобода: где жить, когда работать |
| Собес = статичный фильтр | Проверяет знания сейчас, не резюме. Прошёл = справишься |
| Junior = Middle (одно и то же) | Разрушение мифа о карьерной лестнице |
| Собес = игра в сапёра | Скажешь не то — сбреют. Правильные ответы, не правда |
| HR = робот за 50к решает позицию за 300к | Абсурд системы |
| Оффер ≠ Трудовой | Просто предложение. До подписания — можно отказаться |
| Резюме = лендинг | 3-секундный value proposition |
