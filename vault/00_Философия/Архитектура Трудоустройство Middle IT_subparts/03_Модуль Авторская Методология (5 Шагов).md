### Модуль: Авторская Методология (5 Шагов)

**Шаг 1: Выбор Стека (1 неделя)**
- Бэкенд (Go): меньше конкуренции, выше зарплаты, дефицит на рынке
- Фронтенд: если любишь визуал. React = ~45% рынка, Vue ~17%, Angular ~17%
- Go Junior 100-160к vs Frontend Junior 50-150к. Go Senior 400-700к vs Frontend 250-500к
- Результат: понимание как работает язык, быстрое вхождение через практику

**Шаг 2: Углублённое Изучение Целевых Тем (1-2 месяца)**
- Видео → статьи → код на практике
- Go: 9 ключевых тем покрывают 80% собесов (горутины, слайсы/мапы, интерфейсы, ошибки, PostgreSQL, Kafka, Docker, SD, сети)
- Frontend: 16 секций (React hooks, TS generics, state management, SSR, bundle optimization, event loop, асинхронность)
- Результат: готовность к мок-собесам

**Шаг 3: Резюме + Легенда + Мок-Собесы (2-3 недели)**
- Накрутить опыт: 3-4 года для middle, 5-6 для senior
- Легенда в STAR-формате (Situation, Task, Action, Result)
- "Работал по ГПХ" / "Проект под NDA"
- Мок-собесы с ментором → когда "готов" → первые 5 реальных для разведки
- Результат: список реальных вопросов, формат собесов, базовая уверенность

**Шаг 4: Целевая Подготовка + Пет-Проекты (2-4 недели)**
- Готовиться к конкретным вопросам из разведки
- Пет-проект базовый (фронт: to-do на React, бэк: API на Go+chi+PostgreSQL)
- Симуляция реальной работы: 2-3 недели в формате спринтов (фичи, баг-фиксы)
- Результат: реальный опыт, понимание рабочего процесса

**Шаг 5: Финальный Штурм Собесов**
- Массовые отклики: 50-100/неделю, многоканальная стратегия
- Каждый следующий собес улучшает качество
- Не останавливаться до оффера
- После 5-10 собесов паттерны повторяются → отвечаешь на автопилоте
- Результат: оффер на middle

# СЛОЙ 3:

Слой методологии: авторские 5 шагов входа в IT и карта критических ошибок. Внутри — пошаговый алгоритм, библиотека интуитивных сигналов и терминологический словарь.
