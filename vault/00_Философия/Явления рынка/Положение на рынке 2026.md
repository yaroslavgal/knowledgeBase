| Грейд | Frontend | Python | Go | Java/Kotlin | DevOps | ML/AI |
|---|---|---|---|---|---|---|
| Junior | 50–150к | 70–130к | 100–160к | 90–160к | 120–200к | 100–180к |

## Карта дефицита

**Дефицит (берут, доплачивают):**
- Go — в Яндексе ~150 вакансий, в Ozon ~25, на международном Getmatch ~45 (от 250к). Берут даже без Go-опыта при наличии другого языка.
- DevOps/SRE — AI пока не автоматизирует инфраструктуру. Спрос растёт.
- ML/AI Engineer — спрос вырос в 3–5 раз за 2023–2025.

**Баланс (нанимают по требованиям):**
- Python (web без ML) — много вакансий, но и много кандидатов
- Java/Kotlin — стабильный энтерпрайз, банки, телеком
- Mobile iOS/Android — устойчивый спрос
- TypeScript Fullstack — медианный сегмент

**Перенасыщение (тяжело войти):**
- React Frontend — в Яндексе 20–25 вакансий, Frontend позиций в 6 раз меньше Go. 18–40 резюме на одну джун-вакансию.
- QA Manual — профессия исчезает к 2028–2030. AI автоматизирует.

## Воронка найма сломана

Это не отдельные жалобы, а массовый паттерн:

- 100+ резюме → 0 ответов — обычная ситуация. «2000 откликов и 0 приглашений» — массовый комментарий, не аномалия.
- 80–90% резюме отсекает ATS до человека.
- Junior-поток: 18–40 резюме на одну вакансию.
- Middle-вакансии с оплатой как junior 80к — обычная практика.
- Фидбэк после отказа не дают принципиально (юр. риски + лень HR).
- 30–60% вакансий — **ghost jobs** (для сбора резюме / показать рост инвесторам).
- Работу находят через networking, не через HH.

## Кому хорошо в 2026

- Senior с архитектурным мышлением и AI-tooling — дефицит, ЗП растут
- Go-разработчики любого грейда (с условием тянут middle-задачи)
- DevOps/SRE с инфраструктурным опытом
- ML/AI Engineers с опытом продакшена
- Те, кто умеет проходить собесы и знает рыночную механику — для них кризис = окно возможностей

## Кому плохо

- Junior без middle-навыков — порог входа вырос, рынок сжался
- Фронтендеры на переполненном рынке без специализации
- QA Manual — профессия исчезает
- Middle на устаревшем стеке без AI-tooling
- Те, кто ждёт «когда восстановится» — зря

## Корпоративные манипуляции (рост внутри не работает)

Сбербанк, типичный пример: max +30%/год. Junior 100к → год 120к → год 144к → год ~170к. За 3 года в одной компании +70к.

Смена компании = сразу +200–300к. Каждая смена = +60–130к (по кейсу Олега Козырева — за 8 лет x17 ЗП).

Манипуляции, которыми удерживают:

| Манипуляция | Механика |
|---|---|
| Dry promotion | Титул «Senior» без денег. «Налепили медальку — опустило вилку для всех» |
| Будущие обещания | «Через полгода пересмотрим». «If it's not in writing, it's not real» |
| Привязка бонусами | «Не ведитесь. Бонусы отменяются, вас увольняют» |
| «Мы ценим тебя» | Комплименты вместо денег |
| Плановые ревью | Критерии меняются задним числом |

Подробнее: `04_Смена работы как инструмент роста.md`.

## LinkedIn из РФ — текущая реальность

- Массовые баны новых аккаунтов из РФ. Палят: webrtc, таймзону, подсети, куки.
- Обычный VPN не спасает. Нужен residential или LTE-прокси под страну.
- Разблок аккаунта — загранпаспорт РФ + видео-селфи с движениями головы.
- Старые аккаунты (5–10 лет) в «белых списках».
- Инфраструктура: Авито (1–2к₽ за регистрацию аккаунта), даркнет (старые), residential proxy сервисы.
- Gmail из РФ с 2025 не регается — только Outlook/Proton.
- У живого профиля SSI 66: 0–3 входящих HR в неделю. После НГ-2026 — падение показов.

## 9 трендов 2026

1. **Нейронайм** — AI с обеих сторон собеса. Кандидаты ChatGPT, наниматели — AI-скрининг
2. **Ghost jobs** — 30–60% вакансий не для найма
3. **Обесценивание ЗП в долларах** — «Сеньор 2015 = $5000 / Сеньор 2025 = $4400»
4. **Срыв честного пути роста** — внутри компаний рост не работает, покупают менторов для перехода
5. **Dry promotion / duck promotion** как норма
6. **Overemployment** (2 работы одновременно) из табу → в тренд
7. **Перекаты из фронта в Go/Python** на +30–40% ЗП
8. **73% разработчиков выгорают** в первый год
9. **Бэкдор-референсы** — тайные проверки через бывших коллег становятся нормой

## Сленг 2026 (понимание языка рынка)

- **Ждун** — джун-безработный
- **Духота / душный собес** — избыточные теоретические вопросы
- **Красильщик кнопок** — фронтендер (самоирония)
- **Вайбкодинг** — разработка через AI без понимания кода
- **Слоп** — плохой код от AI
- **Нейронайм** — найм с AI с обеих сторон
- **Формошлёпство / крудошлёб** — рутинная работа
- **Галера** — аутсорс-компания
- **Реджект** — отказ
- **Гриндить** — зубрить
- **Вкатиться / вкатун** — войти в IT
- **Перекат** — смена стека
- **Палево / спалиться** — быть разоблачённым
- **Инфоцыган** — мошенник-курсодел
- **Контрофер** — встречное предложение
- **Бэкдор-референс** — тайная проверка через бывших коллег
- **Золотые наручники** — высокая ЗП удерживает на нелюбимой работе
- **Многоработник** — 2+ работы одновременно
- **Ghost job** — вакансия для сбора данных / инвесторов

## Итог

Рынок 2026 не «мёртв» — поляризован.

В одном полюсе: дефицит Go, DevOps, ML/AI Engineers с AI-tooling — зарплаты растут.

В другом: переполненный junior-рынок и устаревшие стеки — зарплаты падают.

Выигрывают те, кто понимает новые правила быстрее остальных. Старая дверь («сделаю курс, отправлю резюме, возьмут») закрылась. Новая открыта — она в другом месте: правильный стек + умение проходить собесы + параллельный поиск + AI как инструмент.
