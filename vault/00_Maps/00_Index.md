# Index — главная карта

Контент-база для подготовки видео по IT-карьере. Все области ниже — самостоятельные MOC.

## Области

- [[10_Философия]] — принципы, концепции, роадмапы, типы людей, типы компаний, явления рынка
- [[15_Канал и контент]] — ЦА, конкуренты, сценарии, референсы, методология менторства
- [[20_IT-специальности]] — Backend, Frontend, Fullstack, Mobile, DevOps, Data/ML, QA
- [[30_Зарплаты и грейды]] — цифры по специализациям и грейдам, треки роста
- [[40_Найм и трудоустройство]] — цепочка найма, резюме, собесы, платформы, переговоры, валютная удалёнка
- [[50_Будущее и тренды]] — AI и автоматизация, новые технологии
- [[60_Возражения и истории]] — нарративы к 13 возражениям + автобиографические истории
- [[70_Образование и обучение]] — платформы, академии, YouTube, книги, менторы, AI-обучение
- [[80_Процессы и эффективность]] — AI-инструменты, тайм-менеджмент, автоматизация, коммуникации
- [[85_Soft skills]] — коммуникации, командная работа, управление конфликтами
- [[90_References]] — люди, каналы, площадки, продукты

## Как искать

- название → Quick Switcher
- "найди все мысли про X" → QMD semantic search
- по теме → MOC области → подкластер
- связи между заметками → backlinks + related-блоки

## Conventions

- `parent:` каждой заметки указывает на MOC области.
- inline link приоритетнее related-блока.
- related-блок всегда с коротким комментарием механизма.
