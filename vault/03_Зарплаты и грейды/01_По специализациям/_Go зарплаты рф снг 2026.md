# Go зарплаты РФ / СНГ 2026

Реальные вилки по Go-разработчикам в РФ и СНГ на 2026 — цифры из практики и собесов, не из вакансий. Внутри — таблицы по уровням Junior/Middle/Senior с контекстом каждой вилки.

## Реальные вилки из практики

### РФ-рынок

| Уровень | Вилка | Контекст |
|---|---|---|
| Junior Go | **от 200К ₽** | По SMART (Антон, ментор по бэкенду) — реалистичная цель для вкатуна |
| Junior на криптоскам / стартапы | 250К | «Откуда 250К на руки джуну?» — комментарий из чата |
| **Middle Go** | **300–400К ₽** | Стандартная вилка |
| Middle Сбер | 300К | Сбер на эти деньги хочет задачи джунского уровня |
| Middle сертифицированный | 350К + 50К премия | По комментариям из чата |
| **Senior Go РФ** | **500–700К ₽** | По компаниям |
| Senior frontend BКТech (20 лет) | 300К | Алексей Кириллин, ментор |

## Скрытая зарплатная несправедливость

> «Вася пришёл 2 года назад на 200К, получил +5% рейз. А Петю сейчас берут на ту же позицию через LinkedIn за 350К — потому что рынок вырос. **Но Васе никто не скажет.**»

**Вывод:** раз в 6 месяцев проходи 1–2 собеса для калибровки. Даже если стабильная работа.

## Парадокс: Senior легче чем Middle

> «**95% сеньорных позиций менее «потные» чем мидловые** — давно известный парадокс.»

**Почему:**
- Меньше кандидатов с реальным senior-уровнем
- Компании готовы платить выше, чтобы закрыть
- Скрининг проще (не задают про базу языка которую все знают)

**Вывод:** если технические навыки позволяют — **выходи как Senior**, не зависимо от «официального грейда».

## Карьерные карты grade

| Grade | Обязанности |
|---|---|
| **Junior** | Простые задачи с подробным описанием, требует менторства |
| **Middle** | Оценивает время, понимает другие направления, помогает джунам |
| **Senior** | Архитектура, ментор, декомпозирует задачи на джуновские |
| **Tech Lead** | Технические решения уровня команды, контакт с PM |
| **Staff/Principal** | Системы уровня компании, mentoring сеньоров |
| **Director** | Менеджмент сеньоров и тимлидов |

## Что добавляет к зарплате

### Технические
- **Сертификаты** (AWS / CKA / CKS) → +5–10%
- **Контрибьюции в open source** → косвенно (вышло в LinkedIn → больше входящих)
- **Английский B2+** → +$1–3К/мес на международке
- **System Design** → разница senior vs lead

### Soft
- **Ментор / Tech Lead** опыт → +10–20% к senior-вилке
- **Работа в Big Tech** → +20–30% относительно стартапа
- **Indutry expertise** (FinTech / FAANG / Crypto) → +10–30%

### Параллельные доходы
- **Ментор-консалтинг** (1.5–5К ₽/час)
- **Курсы и контент** (зависит)
- **Overemployment** (J1 + J2) — потенциально ×2 ставки
