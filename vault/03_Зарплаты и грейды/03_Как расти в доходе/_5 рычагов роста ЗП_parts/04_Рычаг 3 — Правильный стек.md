## Рычаг 3 — Правильный стек

**Сколько даёт:** +30–50% сразу при выборе/смене стека.

**Топ стеков по зарплатам РФ-рынок 2026:**

| Место | Стек | Senior |
|-------|------|--------|
| 1 | ML/AI | 500–900к |
| 2 | DevOps/SRE | 450–800к |
| 3 | Go | 400–700к |
| 4 | Java/Kotlin | 350–650к |
| 5 | Python | 300–600к |
| 6 | TypeScript Backend | 350–600к |
| 7 | iOS/Android | 350–650к |
| 8 | React/Frontend | 250–500к |

Frontend — самый переполненный сегмент. 18 резюме на вакансию. Junior фронт — пробка.

**Перекат как стратегия:**
- Frontend → Go: после 3–6 месяцев — +100–150к сразу
- Frontend → Fullstack (Node.js): +20–30% в стартапах
- Backend → DevOps: +50–80к за 6 месяцев
- Любой backend → ML/AI: +100–200к за 1–1.5 года переподготовки

**Премии за редкие скиллы:**
- TypeScript (на фронте) — обязателен, без него −15–20%
- Kubernetes (для backend) — +10–15%
- Реактивное программирование (Spring WebFlux) — +10%
- WebAssembly, WebGL — +20% для нишевых вакансий
