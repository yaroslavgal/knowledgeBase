# OpenCode Adapter

OpenCode loads `AGENTS.md`, this README, installed `.opencode/skills`, `.opencode/agents`, and QMD MCP. Package source skills live in `runtime/core/skills` and are materialized during install.

Skills are primary. Commands are shortcuts:

- `/onboard` -> `onboard-vault`
- `/check` -> `check-vault`
- `/learn` -> `save-lesson`
- `/reflect` -> `update-rules`

Git/GitHub setup goes through `setup-git`.

Read `.vault-agent/RULES.md`, `PROFILE.md`, `STRUCTURE.md`, and `STYLE.md` as needed. Read `LESSONS.md` only for calibration.
